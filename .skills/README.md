# SKILL 使用说明

## 一键启动服务

这个 SKILL 可以帮助你快速启动 BananaSlides 的前后端服务。

### 功能特性

- 🚀 **一键启动**: 同时启动后端和前端服务
- 🔧 **后台运行**: 服务在独立终端中运行,互不干扰
- 📋 **依赖检查**: 自动检查并提示安装依赖
- 🎯 **端口配置**: 后端 1111,前端 1000

### 使用方式

#### 1. 首次使用

首次运行前,需要完成以下准备工作:

```bash
# 安装后端依赖
cd server
npm install

# 安装前端依赖
cd ..
npm install

# 初始化数据库
init_db.bat
```

#### 2. 启动服务

使用 SKILL 配置文件,执行以下步骤:

1. 启动后端服务 (端口 1111)
2. 启动前端应用 (端口 1000)

### 服务地址

- **后端 API**: http://localhost:1111
- **前端界面**: http://localhost:1000

### 注意事项

- 确保端口 1111 和 1000 未被占用
- 首次运行前必须执行 `init_db.bat` 初始化数据库
- 在 `server/.env` 中配置所需的 API Keys

### 常见问题

**Q: 启动失败,提示端口被占用?**
A: 检查端口 1111 和 1000 是否被其他程序占用,关闭占用程序或修改配置

**Q: 数据库连接错误?**
A: 确保已执行 `init_db.bat` 初始化数据库

**Q: 前端无法连接后端?**
A: 检查后端服务是否正常启动,终端是否有错误信息
