## 3. 账号重置说明

### 3.1 重置所有测试账号

**执行命令**:

```bash
cd server
npx ts-node prisma/seed_users.ts
```

**执行结果**:
- 清空现有测试账号数据
- 重新创建5个标准测试账号
- 重置为默认密码和积分

### 3.2 代码实现

```typescript
// server/prisma/seed_users.ts

import { PrismaClient, UserRole, UserStatus } from '@prisma/client';
import bcrypt from 'bcryptjs';

const prisma = new PrismaClient();

async function main() {
    console.log('Seeding test users...');

    // 所有测试账号使用相同密码
    const salt = await bcrypt.genSalt(10);
    const passwordHash = await bcrypt.hash('Test123456!', salt);

    const users = [
        {
            email: 'admin@bananaslides.com',
            username: 'admin',
            nickname: '超级管理员',
            role: UserRole.SUPER_ADMIN,
            points: 999999
        },
        {
            email: 'admin01@local',
            username: 'admin01',
            nickname: '系统管理员',
            role: UserRole.SUPER_ADMIN,
            points: 100000
        },
        {
            email: 'admin123@bananaslides.com',
            username: 'admin123',
            nickname: '业务管理员',
            role: UserRole.ADMIN,
            points: 1000
        },
        {
            email: 'testuser@example.com',
            username: 'user466',
            nickname: '测试用户',
            role: UserRole.USER,
            points: 500
        },
        {
            phone: '13800000000',
            nickname: '手机测试用户',
            role: UserRole.USER,
            points: 100
        }
    ];

    // 清理旧数据
    await cleanupExistingUsers(users);

    // 创建新账号
    for (const user of users) {
        await prisma.user.create({
            data: {
                ...user,
                passwordHash,
                status: UserStatus.ACTIVE
            }
        });
        console.log(`Created: ${user.email || user.phone}`);
    }
}

main()
    .catch(e => {
        console.error(e);
        process.exit(1);
    })
    .finally(async () => {
        await prisma.$disconnect();
    });
```

## 7. 注意事项

### ⚠️ 安全警告

1. **生产环境禁用**: 这些测试账号仅用于开发和测试环境
2. **密码强度**: 虽然测试密码简单，但生产环境必须强制复杂密码
3. **数据隔离**: 测试数据应与生产数据完全隔离
4. **定期更换**: 建议定期更换测试账号密码

### 📝 使用建议

1. **并行测试**: 不同测试人员使用不同账号避免冲突
2. **数据清理**: 测试完成后清理生成的测试数据
3. **日志查看**: 测试时关注后端日志输出
4. **权限验证**: 每次测试都验证权限控制是否生效
