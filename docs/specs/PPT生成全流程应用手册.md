# 🚀 PPT生成全流程应用手册 (Full Workflow Whitepaper)

> **文档版本**: v2.0 (深度重构版)
> **定位**: 场景化全链路实战白皮书
> **核心逻辑**: 文稿解析 -> AI 调度 -> 视觉合成 -> 全端交付

---

## 1. 输入阶段：多源文稿的语义重组

本阶段的核心价值在于利用 **MinerU 原生内核** 解决“信息噪音”问题。

1.  **高保真解析**: 上传调研 PDF/Word。
2.  **MinerU 处理流**: 系统执行 OCR 与结构提取，将原始文档转化为干净的 Markdown。
3.  **Vision 兜底机制**: 若 MinerU 不可用，系统启动图像级视觉提取算法。

## 2. 设计阶段：意图注入与大纲校准

本阶段利用 **GLM-4.7** 的强大逻辑力进行框架搭建。

1.  **大纲生成算法**: 调用 `generateOutline`。系统执行自动页数校准，确保逻辑页序（Cover-Directory-Content-End）严丝合缝。
2.  **视觉指令注入**: 运行 Smart Refine。AI 分析用户偏好，输出符合 **4 层级 Prompt 规范** 的 Markdown 指令集。

## 3. 渲染阶段：4 层级 Prompt 引擎实战

本阶段是视觉生成的“心脏”，调用 **Gemini-3-pro-image** 进行像素级渲染。

- **L1 (视觉语言)**: 通过 Vision 模型解析风格图，锁定配色与构图。
- **L2 (业务核心)**: 将大纲中的 `brief` 转化为画面主体。
- **L3 (合成指令)**: 执行“形神兼备”仲裁，确保无随机文字干扰。
- **L4 (技术规格)**: 锁定 16:9 与 2K 商业级画质。

## 4. 交付阶段：多维资产分发

1.  **PPTX 全编辑链路**: 导出原生 PowerPoint 文件，适合本地精修。
2.  **4K 高清图包**: 导出全套幻灯片背景图，适合微信/移动端极速分享。
3.  **H5 演示流**: 浏览器级全屏演示，支持动效平滑播放。

## 💡 专家建议
- **追求一致性**: 在应用模板后，尽量不要手动频繁修改单页背景，让项目的 `styleMap` 自然驱动全局视觉。
- **巧用版本历史**: 遇到 AI 生成不如意时，与其反复修改单页，不如回溯到“大纲保存”节点，优化 `brief` 后重新渲染。
