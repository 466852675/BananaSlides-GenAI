# 🖼️ 图片生成规范书 (Image Generation Spec)

> **文档版本**: v2.0 (深度重构版)
> **技术对齐**: `server/src/services/ai.service.ts` -> `buildImageGenerationPrompt`
> **核心架构**: 4 层级结构化注入引擎

---

## 1. 核心原理：4 层级结构化 Prompt 引擎

系统放弃了单一的描述词，转而使用逻辑严密的四层结构来重建视觉意图，确保护理感与业务逻辑的统一。

### L1：视觉语言与艺术风格 (Visual Language)
**职责**: 定义“怎么画”。
- **Vision 特征提取**: 通过 `analyzeStyleImage` 函数，系统调用 `gemini-3-flash` 对参考图进行非具象解构。
- **真实指令示例**:
  ```text
  【1. 视觉语言 & 艺术风格 (最高优先级说明书)】
  - 核心视觉指纹: 主体构图为偏左重心，视觉流向为由左向右，背景呈现金属拉丝肌理，色彩逻辑采用高对比度撞色。
  - 构图锁定: 必须严格复刻参考图的几何骨架、色彩权重和视觉平衡感。
  ```

### L2：业务任务核心 (Business Core)
**职责**: 定义“画什么”。
- **智能过滤**: 内部 `extractPageSpecificRequirements` 函数会根据 `pageType` 自动从 Markdown 需求中切片出当前页对应的规范。
- **真实指令示例**:
  ```text
  【2. 业务任务内容 (核心质料)】
  - 页面标题: "2024 全球新能源车市场深度解构"
  - 详细业务描述: "展示市场占有率饼图，核心观点为中国品牌出海势头强劲..."
  ```

### L3：形神兼备合成指令 (Meta-Instruction)
**职责**: 处理视觉与业务的“冲突仲裁”。
- **核心逻辑**: 重申内容隔离，禁止 AI 在背景图中生成干扰业务表达的随机文字或数字。
- **注入逻辑**: `请忽略参考风格图中的任何文字、数字，只提取其设计语言。`

### L4：技术规格 (Technical Spec)
**职责**: 图像质量基座。
- **分辨率**: 2K (1792x1024) 或根据设置动态调整。
- **宽高比**: 支持 `16:9`, `4:3`, `1:1`, `3:4`, `9:16`。由 `getClosestSupportedRatio` 进行硬件级纠偏。

## 2. 页面类型专属指令集 (Page-Specific Rules)

系统通过 `getPageTypeInstructions` 为不同页面赋予特定的视觉灵魂：

| 页面类型 | 视觉要求 (Hard-coded Logic) |
| :--- | :--- |
| **Cover (封面)** | 标题突出醒目，背景视觉大气，标题唯一化校验。 |
| **Directory (目录)** | 根据所有 Slide 标题智能归纳章节列表，条理清晰，严禁偏离主题。 |
| **Content (内容)** | **核心：** 必须在标题下方添加核心总结句，采用提炼式小标题与视觉标签。 |
| **End (结束)** | 严格脱敏，严禁包含任何占位符信息（如：电话、邮箱、网址）。 |

## 3. 视觉匹配降级树 (Style Match Tree)

1.  **Exact (级别 1)**: 精确匹配当前页面类型的风格参考图。
2.  **Fallback (级别 2)**: 若当前页未定义，则按 `cover -> content -> directory -> transition -> end` 顺序检索第一个可用风格图。
3.  **None (级别 3)**: 若全无参考图，降级为纯文本风格描述符。
