# AI图片生成Prompt完整构建规范 (Image Generation Spec)

> **文档版本**: v1.1  
> **更新日期**: 2026-01-19
> **核心一致性**: 严格匹配 `server/src/services/ai.service.ts` 中的 `buildImageGenerationPrompt` 函数实现。

---

## 1. 核心构建架构 (4层级)

系统通过特定的层级结构确保 AI 绘图模型（如 DALL-E 3 或 Gemini Image 2.0）能够完美融合视觉风格与业务逻辑。

### 第一层：视觉语言 & 艺术风格 (Visual Language)
**优先级：最高**
- **来源**: 由 Vision 模型（`gemini-3-flash`）对参考图进行的预解析结果。
- **包含**: 核心视觉指纹（构图骨架、颜色平衡、肌理设计）。
- **如果是精确匹配**: 注入“必须严格复刻参考图的几何骨架、色彩权重和视觉平衡感”的强指令。

### 第二层：业务任务内容 (Business Core)
**内容核心**
- **包含**:
    - **页面标题**: 直接插入。
    - **大纲参考**: 仅针对目录页（Directory），当内容不足时注入本项目所有幻灯片的标题列表，供 AI 智能排版。
    - **详细业务描述**: 基于 `fullContent` 的前 800 字。

### 第三层：形神兼备合成指令 (Synthesized Meta-Instruction)
**逻辑桥梁**
- **任务使命**: 明确告知 AI 使用第一部分的【视觉语言】去重构并描绘第二部分的【业务内容】。
- **深度要求**: 强调生成的图像必须在视觉上看起来与参考图逻辑一致，但在含义和内容上必须精准对应本页面的业务主题。

### 第四层：技术规格 (Technical Specifications)
**执行细节**
- **宽高比**: 如 `16:9`。
- **风格流派**: 如“商务科技”、“极简几何”。
- **配色方案**: 用户自定义的 Palette。
- **用户偏好**: 注入用户在样式编辑器中填写的“设计要求”。
- **画面基调**: 预设为“专业商业演示, 4K 高画质, 文字严禁模糊, 线条精准”。

## 2. 页面类型专属指令 (PageType Presets)

在构建上述层级前，系统会根据 `pageType` 注入特定的前置角色设定：

| 页面类型 | 系统前置指令 (Snapshot) |
| :--- | :--- |
| **Cover (封面)** | 标题突出醒目，背景视觉大气。要求标题去重，文字清晰锐利。 |
| **Directory (目录)** | 章节列表条理清晰，层级分明；支持根据大纲标题智能归纳。 |
| **Transition (过渡)** | 突出显示章节标题，具有承上启下的视觉过渡效果。 |
| **Content (内容)** | **核心：** 标题下方添加核心总结。内容有层次展示（小标题、要素、标签）。避免文字堆叠。 |
| **End (结束)** | 严格根据内容生成，严禁包含通用的联系人占位符（手机/邮箱）。 |

---

## 3. 智能匹配决策树 (Style Match Logic)

系统在处理 `styleRef`（风格参考图）时遵循以下退级逻辑：

1.  **Level 1: 精确匹配** (exact)
    - 使用 `globalStyleMap` 中专门为该 `pageType` 指定的图片。
2.  **Level 2: 降级匹配** (fallback)
    - 若当前页没有风格图，寻找本项目中其他页面（如 Cover 或 Content）已分配的风格图。
3.  **Level 3: 全局描述** (none)
    - 若项目中无任何风格图，直接使用文字描述（风格名+调色板）。

## 4. 示例：典型的 4 层级 Prompt 输出

```text
【1. 视觉语言 & 艺术风格 (最高优先级说明书)】
- 核心视觉指纹: 主体构图为左侧重心，背景呈现磨砂颗粒肌理，色彩逻辑采用深蓝到极光绿的冷色对比。
- 构图锁定: 必须严格复刻参考图的几何骨架、色彩权重和视觉平衡感。

【2. 业务任务内容 (核心质料)】
- 页面标题: "2025年AI基础设施演进"
- 详细业务描述: "随着算力集群规模的扩大，液冷技术与硅光集成成为核心..."

【3. 形神兼备合成要求】
- 任务使命: 请使用第一部分定义的【视觉语言】去重构并描绘第二部分的【业务内容】。
- 深度要求: 生成的图像必须在视觉上看起来与参考图逻辑一致，但在含义和内容上必须精准对应。

【4. 技术规格】
- 宽高比: 16:9
- 风格流派: 商务科技
- 配色方案: 深海蓝
- 画面基调: 专业商业演示, 4K 高画质, 文字严禁模糊, 线条精准。
```
