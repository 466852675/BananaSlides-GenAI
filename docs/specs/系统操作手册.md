# 🍌 BananaSlides 系统操作手册 (User Manual)

> **文档版本**: v2.0 (深度重构版)
> **适用对象**: 设计师、研究员、商务专家
> **手册特色**: 工业级操作流解构

---

## 1. 极速创作：黄金三步法

### 第一步：意图锚定 (Intent Anchoring)
- **核心操作**: 在“创建项目”面板输入 PPT 主题。
- **深度建议**: 利用 **“智能润色 (Smart Refine)”**。系统不仅会美化文字，还会根据您的输入自动在项目 `requirements` 中注入一套完整的 AI 视觉导演指令。

### 第二步：逻辑闭环 (Outline Logic)
- **核心操作**: 设定页数并点击“生成大纲”。
- **进阶技巧**: 在大纲页，您可以根据生成的 `brief` 进行语义修正。记住，这里的每一行文字都是后续图片生成的 **L2 业务质料**。

### 第三步：并行渲染 (Batch Rendering)
- **核心操作**: 点击仪表盘底部的“一键渲染”。
- **监控指标**: 胶囊导航栏将实时播报 `generating` 进度。受系统 **串行生图协议** 保护，第一页通常需要 20-40 秒，请耐心等待呼吸动效停止。

## 2. 核心模块进阶

### 2.1 模板仓库 (The Market)
- **集市模版**: 浏览官方认证的 `isOfficial` 模版，查看其 `usageCount` 以判断流行度。
- **私域沉淀**: 将自己满意的设计点击“收藏”，它们将永久保存在您的 `Favorite` 库中，支持样式瞬间移植。

### 2.2 视觉变体切换 (Variant Switching)
- 每一页幻灯片默认生成 2 个及以上视觉变体。进入单页查看模式，点击下方的小图即可切换。

## 3. 故障排除 (Quick Fix)

- **生成超时**: 检查全局设置中的 API Key 是否失效。系统具备 `.env` 热加载逻辑，您可以直接修改配置文件而无需退出页面。
- **文档导入乱码**: 确保开启了 **MinerU 原生解析**。若 MinerU 无法响应，系统会降级到 Vision 模型，此时文档层级解析精度可能下降。
