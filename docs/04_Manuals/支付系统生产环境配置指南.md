## 配置概览

### 模式切换说明

系统支持两种运行模式：

| 模式 | 环境变量 | 适用场景 | 资金风险 |
|------|----------|----------|----------|
| **Mock 模式** | `WECHAT_MOCK_MODE=true`<br>`ALIPAY_MOCK_MODE=true` | 开发测试 | 无 |
| **生产模式** | `WECHAT_MOCK_MODE=false`<br>`ALIPAY_MOCK_MODE=false` | 真实交易 | 真实资金流动 |

### 快速切换步骤

1. **开发阶段**: 保持 Mock 模式，无需配置证书
2. **测试阶段**: 使用支付平台的沙箱环境
3. **生产阶段**: 配置真实证书，关闭 Mock 模式

## 微信支付配置

### 1. 前置条件

- 微信支付商户号 (mchId)
- 已完成微信支付的实名认证
- 具备 API 证书权限

### 2. 获取证书

登录 [微信支付商户平台](https://pay.weixin.qq.com/)：

```
账户中心 → API安全 → API证书 → 下载证书
```

下载后你会得到：
- `apiclient_cert.pem` - 商户证书
- `apiclient_key.pem` - 商户私钥
- `apiclient_cert.p12` - PKCS#12 格式（备用）

### 3. 获取 API v3 密钥

```
账户中心 → API安全 → APIv3密钥 → 设置密钥
```

⚠️ **重要**: API v3 密钥需要手动设置，不是自动生成的。

### 4. 获取证书序列号

```bash
# 使用 OpenSSL 查看证书序列号
openssl x509 -in apiclient_cert.pem -noout -serial
```

输出去掉 `0x` 前缀即为序列号。

### 5. 配置环境变量

```env
# 微信支付配置
WECHAT_MCH_ID="1234567890"
WECHAT_APP_ID="wx1234567890abcdef"
WECHAT_API_KEY="YourAPIv3KeyHere123456789"
WECHAT_CERT_PATH="./certs/wechat/apiclient_cert.pem"
WECHAT_KEY_PATH="./certs/wechat/apiclient_key.pem"
WECHAT_SERIAL_NO="1234567890ABCDEF1234567890ABCDEF"
WECHAT_MOCK_MODE="false"
```

### 6. 证书目录结构

```
server/
├── certs/
│   └── wechat/
│       ├── apiclient_cert.pem
│       └── apiclient_key.pem
├── .env
└── src/
```

创建证书目录：

```bash
cd server
mkdir -p certs/wechat
# 将下载的证书文件复制到此目录
cp ~/Downloads/apiclient_*.pem certs/wechat/
```

## 支付宝配置

### 1. 前置条件

- 支付宝商家账号
- 已创建应用并签约"电脑网站支付"
- 具备退款接口权限

### 2. 创建应用

登录 [支付宝开放平台](https://open.alipay.com/)：

```
控制台 → 创建应用 → 网页/移动应用
```

签约能力：
- ✅ 电脑网站支付
- ✅ 退款接口

### 3. 生成密钥对

使用支付宝密钥工具：

```bash
# 下载密钥工具
open https://opendocs.alipay.com/open/02kipl

# 或使用 OpenSSL 生成
openssl genrsa -out app_private_key.pem 2048
openssl rsa -in app_private_key.pem -pubout -out app_public_key.pem
```

### 4. 上传公钥

```
应用详情 → 开发设置 → 接口加签方式 → 设置
```

- 选择 "公钥" 模式
- 上传 `app_public_key.pem` 内容
- 获取 **支付宝公钥**（alipayPublicKey）

### 5. 配置环境变量

```env
# 支付宝配置
ALIPAY_APP_ID="2024XXXXXXXXXXXX"
ALIPAY_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----
MIIEpAIBAAKCAQEA0Z3VS5JJcds3xfn/ygWyF8PbnGy0AHB7MQ0G6bMRkVv3VX8Q
...
-----END RSA PRIVATE KEY-----"
ALIPAY_PUBLIC_KEY="-----BEGIN PUBLIC KEY-----
MIIBIjANBgkqhkiG9w0BAQEFAAOCAQ8AMIIBCgKCAQEA0Z3VS5JJcds3xfn/ygWy
...
-----END PUBLIC KEY-----"
ALIPAY_GATEWAY="https://openapi.alipay.com/gateway.do"
ALIPAY_MOCK_MODE="false"
```

### 6. 沙箱环境测试

在正式环境前，建议先在沙箱测试：

```env
ALIPAY_GATEWAY="https://openapi.alipaydev.com/gateway.do"
ALIPAY_APP_ID="沙箱应用的APPID"
```

沙箱账号：[沙箱控制台](https://open.alipay.com/develop/sandbox/account)

## 证书管理

### 安全存储建议

1. **生产环境**
   - 使用密钥管理服务 (KMS)
   - 证书文件设置 600 权限
   - 定期轮换密钥

2. **Docker 部署**
   ```yaml
   # docker-compose.yml
   volumes:
     - ./certs:/app/certs:ro
   ```

3. **环境变量注入**
   ```bash
   # 使用 docker secrets
   echo "证书内容" | docker secret create wechat_cert -
   ```

### 证书权限设置

```bash
# 设置证书文件权限（仅所有者可读写）
chmod 600 certs/wechat/apiclient_*.pem

# 验证权限
ls -la certs/wechat/
# -rw------- 1 user group 1234 Jan 01 00:00 apiclient_cert.pem
```

## Webhook 配置

### 微信支付 Webhook

1. **配置回调地址**
   ```
   商户平台 → 产品中心 → 开发配置 → 支付回调URL
   ```
   
   URL: `https://your-domain.com/webhooks/wechat/refund`

2. **验证消息通知**
   - 系统已集成签名验证
   - 自动解密通知内容
   - 更新退款状态

### 支付宝 Webhook

1. **配置异步通知地址**
   ```
   开放平台 → 应用详情 → 开发设置 → 接口加签方式 → 异步通知地址
   ```
   
   URL: `https://your-domain.com/webhooks/alipay/refund`

2. **验证流程**
   - 使用支付宝公钥验证签名
   - 解析通知数据
   - 更新退款状态

## 故障排查

### 常见问题

#### 1. 证书错误

**错误信息**: `unable to load certificate`

**解决方案**:
```bash
# 检查证书格式
file certs/wechat/apiclient_cert.pem
# 应为: PEM 格式

# 转换证书格式（如需要）
openssl x509 -in apiclient_cert.p12 -out apiclient_cert.pem
```

#### 2. 签名验证失败

**错误信息**: `Invalid signature`

**排查步骤**:
1. 检查 API 密钥是否正确
2. 检查证书序列号是否匹配
3. 检查时间戳是否同步

#### 3. 权限不足

**错误信息**: `NO_AUTH`

**解决方案**:
- 微信：检查商户号是否有退款权限
- 支付宝：检查应用是否签约退款接口

#### 4. 订单不存在

**错误信息**: `ORDERNOTEXIST`

**原因**: 订单超过退款期限（微信 1 年，支付宝 3 个月）

#### 5. 余额不足

**错误信息**: `NOTENOUGH`

**解决方案**: 向微信支付商户号充值

## 安全最佳实践

### 1. 密钥轮换

- 每 90 天轮换一次 API 密钥
- 证书到期前 30 天自动提醒

### 2. 访问控制

```bash
# 限制证书目录访问
chmod 700 certs/
chown -R appuser:appuser certs/
```

### 3. 审计日志

记录所有退款操作：
- 申请人
- 审批人
- 金额
- 时间戳
- 支付平台交易号

### 4. 监控告警

设置监控指标：
- 退款成功率 < 95%
- 退款处理时间 > 5 分钟
- 异常退款数量突增

## 附录

### A. 微信支付错误码对照

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| INVALID_REQUEST | 参数错误 | 检查请求参数格式 |
| OUT_TRADE_NO_USED | 订单号重复 | 更换退款单号 |
| USER_ACCOUNT_ABNORMAL | 用户账户异常 | 联系用户确认 |
| INVALID_TRANSACTIONID | 交易单号无效 | 检查 transaction_id |

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| ACQ.SYSTEM_ERROR | 系统错误 | 稍后重试 |
| ACQ.INVALID_PARAMETER | 参数无效 | 检查参数格式 |
| ACQ.TRADE_NOT_EXIST | 交易不存在 | 检查订单号 |
| ACQ.TRADE_STATUS_ERROR | 交易状态错误 | 检查订单状态 |
