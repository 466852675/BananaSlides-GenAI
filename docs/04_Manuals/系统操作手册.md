> **适用对象**: 设计师、研究员、商务专家
> **手册特色**: 工业级操作流解构

## 1. 极速创作：黄金三步法

### 第一步：意图锚定 (Intent Anchoring)
- **核心操作**: 在“创建项目”面板输入 PPT 主题。
- **深度建议**: 利用 **“智能润色 (Smart Refine)”**。系统不仅会美化文字，还会根据您的输入自动在项目 `requirements` 中注入一套完整的 AI 视觉导演指令。

### 第二步：逻辑闭环 (Outline Logic)
- **核心操作**: 设定页数（封面+目录+内容+结束）并点击“生成大纲”。
- **进阶技巧**: 在大纲阶段，您可以点击每个卡片右上角的 **“✨单页重写”** 按钮进行增量调整。系统会根据当前主题重新生成该页标题与简介，确保逻辑高度对齐。

### 第三步：并行渲染 (Batch Rendering)
- **核心操作**: 点击仪表盘底部的“一键渲染”或进入大纲第三步“生成详细内容”。
- **监控指标**: 系统支持 **高性能并发池**。您可以在 `.env` 中调整 `PERF_TEXT_CONCURRENCY` 以实现多页齐发。渲染完成后，膠囊导航栏将实时反馈各页面的就绪状态。


## 2. 核心模块进阶

### 2.1 模板仓库 (The Market)
- **集市模版**: 浏览官方认证的 `isOfficial` 模版，查看其 `usageCount` 以判断流行度。
- **私域沉淀**: 将自己满意的设计点击“收藏”，它们将永久保存在您的 `Favorite` 库中，支持样式瞬间移植。

### 2.2 视觉变体切换 (Variant Switching)
- 每一页幻灯片支持根据不同 Prompt 生成多个视觉变体。点击页面下方的变体列表即可实现“无缝换装”。

### 2.3 管理端高级操作 (Admin Operations)
- **精准退款**: 在订单管理后台执行退款时，系统将弹出 **自定义 ConfirmDialog** 强制要求输入退款理由，该理由将记录在审计日志中。
- **积分调账**: 支持多维度筛选用户流水，并执行手动增减分操作。


## 3. 故障排除 (Quick Fix)

- **生成超时**: 检查全局设置中的 API Key 是否失效。系统具备 `.env` 热加载逻辑，您可以直接修改配置文件而无需退出页面。
- **文档导入乱码**: 确保开启了 **MinerU 原生解析**。若 MinerU 无法响应，系统会降级到 Vision 模型，此时文档层级解析精度可能下降。
