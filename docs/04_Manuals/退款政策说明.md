# 退款政策说明

## 概述

YH-AI PPT 致力于为用户提供高质量的 AI PPT 生成服务。我们理解在某些情况下您可能需要申请退款。本文档详细说明我们的退款政策、流程和条件。

---

## 退款条件

### 符合退款条件

您可以在以下情况下申请全额退款：

1. **时间限制**
   - 订单支付成功后 **7天内** 可申请退款
   - 超过7天的订单将无法退款

2. **使用限制**
   - 您**尚未创建任何项目**
   - 您**尚未生成任何 PPT 文件**
   - 您**尚未使用充值获得的积分**

3. **订单状态**
   - 订单必须处于"已支付"状态
   - 订单金额大于0元

### 不符合退款条件

以下情况**无法**申请退款：

- 订单已超过7天退款期限
- 您已经创建了项目
- 您已经生成了 PPT 文件
- 您已经使用了充值获得的积分
- 订单未支付或已取消
- 订单金额已被部分或全部使用

---

## 退款流程

### 1. 检查退款资格

在申请退款前，系统会自动检查您的订单是否符合退款条件：

1. 登录您的 YH-AI PPT 账户
2. 进入"我的订单"页面
3. 找到需要退款的订单
4. 点击"申请退款"按钮
5. 系统会显示退款资格检查结果

### 2. 提交退款申请

如果符合退款条件：

1. 填写退款原因（必填）
2. 填写退款说明（选填）
3. 点击"确认申请"
4. 系统生成退款申请单号

### 3. 等待审核

- 退款申请将在 **1-3个工作日** 内完成审核
- 您可以在"退款记录"中查看申请状态
- 审核结果将通过站内信通知您

### 4. 退款到账

**审核通过后：**
- 退款将在 **3-7个工作日** 内原路退回
- 退回到您支付时使用的账户
- 退款金额 = 订单实际支付金额（全额退款）

**审核拒绝后：**
- 您可以查看拒绝原因
- 如有异议可联系客服

---

## 退款状态说明

| 状态 | 说明 |
|------|------|
| **待审核** | 退款申请已提交，等待管理员审核 |
| **处理中** | 退款申请已批准，正在处理退款 |
| **已完成** | 退款已成功处理，款项已退回 |
| **已拒绝** | 退款申请未通过审核 |
| **处理失败** | 退款处理过程中遇到错误，将自动重试 |
| **需人工处理** | 退款遇到特殊情况，需要人工介入 |

---

## 退款金额说明

### 全额退款

在符合退款条件的情况下，您将获得：
- **订单实际支付金额的全额退款**
- 包括：订单金额、任何支付的税费
- 不包括：第三方支付平台可能产生的手续费（如有）

### 积分处理

退款成功后：
- 订单赠送的积分将被**全部扣除**
- 如果积分余额不足，将显示为负值
- 负积分需通过重新充值来补齐

您可以通过以下方式查询退款进度：

1. **网站查询**
   - 登录账户 → 退款记录 → 查看详情

2. **退款单号**
   - 每笔退款申请都有唯一单号（格式：REF-YYYYMMDD-XXX）
   - 凭单号可联系客服查询

## 常见问题

### Q: 退款申请提交后可以取消吗？
**A:** 在管理员审核前，您无法自行取消退款申请。如需取消，请联系客服。

### Q: 退款会退到哪里？
**A:** 退款将原路退回到您支付时使用的账户（微信/支付宝）。

### Q: 退款需要多长时间？
**A:** 审核1-3个工作日，到账3-7个工作日，具体以银行/支付平台处理时间为准。

### Q: 为什么我的退款申请被拒绝了？
**A:** 常见原因包括：已创建项目、已生成PPT、已使用积分、超过退款期限等。具体原因请查看退款详情。

### Q: 部分使用过的订单可以退款吗？
**A:** 不可以。只要使用了订单的任何权益（创建项目、生成PPT、使用积分），就无法退款。

### Q: 退款失败怎么办？
**A:** 系统会自动重试（最多3次）。如果持续失败，状态会变为"需人工处理"，请联系客服。

### Q: 退款后还能恢复订单吗？
**A:** 不可以。退款完成后订单即关闭，无法恢复。如需再次使用服务，需要重新下单。
