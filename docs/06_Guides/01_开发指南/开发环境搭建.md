## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/your-org/yh-ai-ppt.git
cd yh-ai-ppt
```

### 2. 安装依赖

```bash
# 安装前端依赖
npm install

# 安装后端依赖
cd server
npm install
cd ..
```

### 3. 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑 .env 文件，填写必要的配置
```

### 4. 初始化数据库

```bash
cd server
npx prisma db push
npx prisma db seed
cd ..
```

### 5. 启动开发服务器

```bash
# 方式1: 分别启动（推荐）

# 终端1 - 前端
npm run dev

# 终端2 - 后端
cd server
npm run dev

# 方式2: 一键启动（需要 concurrently）
npm run dev:all
```

### 6. 访问应用

- **前端**: http://localhost:1000
- **后端 API**: http://localhost:1111
- **API 文档**: http://localhost:1111/api-docs

## 详细安装步骤

### Node.js 安装

**Windows/macOS**:
1. 访问 https://nodejs.org/
2. 下载 LTS 版本 (v22.x)
3. 运行安装程序
4. 验证安装: `node -v` 和 `npm -v`

**Linux (Ubuntu)**:
```bash
# 使用 nvm 安装
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc
nvm install 22
nvm use 22
node -v
```

### Git 安装

**Windows**:
1. 下载 https://git-scm.com/download/win
2. 运行安装程序
3. 配置 Git:
```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
```

**macOS**:
```bash
# 使用 Homebrew
brew install git
```

**Linux**:
```bash
sudo apt update
sudo apt install git
```

### VS Code 配置（推荐）

**必备插件**:
- ESLint
- Prettier
- Tailwind CSS IntelliSense
- Prisma
- Thunder Client (API 测试)

**推荐配置** (`.vscode/settings.json`):
```json
{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": true
  },
  "typescript.preferences.importModuleSpecifier": "relative"
}
```

## 环境变量配置

### 前端环境变量 (`.env`)

```env
# API 基础 URL
VITE_API_BASE_URL=http://localhost:1111

# 上传文件大小限制（MB）
VITE_MAX_UPLOAD_SIZE=50

# 开发模式
VITE_DEV_MODE=true
```

### 后端环境变量 (`server/.env`)

```env
# 数据库
DATABASE_URL="file:./prisma/dev.db"

# JWT 密钥
JWT_SECRET="your-secret-key-change-in-production"
JWT_EXPIRES_IN="7d"

# 服务器配置
PORT=1111
NODE_ENV=development

# AI 模型配置
GEMINI_API_KEY="your-gemini-api-key"
GEMINI_BASE_URL="https://generativelanguage.googleapis.com"

# 文件上传
UPLOAD_DIR="uploads"
MAX_FILE_SIZE=52428800

# 支付配置（开发环境使用 Mock）
ALIPAY_MOCK_MODE=true
WECHAT_MOCK_MODE=true
```

## 常见问题

### Q1: 安装依赖时卡住

**解决**:
```bash
# 清除缓存
npm cache clean --force

# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
rm -rf node_modules package-lock.json
npm install
```

### Q2: 数据库连接失败

**检查**:
1. `.env` 文件是否正确配置
2. 数据库文件是否存在
3. 权限是否正确

**解决**:
```bash
cd server
# 重新初始化
npx prisma db push
```

### Q3: 端口被占用

**解决**:
```bash
# Windows
netstat -ano | findstr :1000
taskkill /PID <PID> /F

# macOS/Linux
lsof -ti:1000 | xargs kill -9
```

### Q4: AI 生成失败

**检查**:
1. API Key 是否正确配置
2. 网络是否能访问外网
3. 查看后端日志
