## 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/your-org/yh-ai-ppt.git
cd yh-ai-ppt
```

### 2. 安装依赖

```bash
# 安装前端依赖
npm install

# 安装后端依赖
cd server
npm install
cd ..
```

### 3. 配置环境变量

```bash
# 复制环境变量模板
cp server/.env.example server/.env

# 编辑 .env 文件，填写必要的配置
```

### 4. 初始化数据库

```bash
cd server
npx prisma db push
npm run db:seed
cd ..
```

### 5. 启动开发服务器

```bash
# 方式1: 分别启动（推荐）

# 终端1 - 前端
npm run dev

# 终端2 - 后端
cd server
npm run dev

# 方式2: Windows 一键启动
start_app.bat
```

### 6. 访问应用

- **前端**: http://localhost:1000
- **后端 API**: http://localhost:1111
- **WebSocket**: ws://localhost:1111/ws
- **Prisma Studio**: http://localhost:5555 (运行 `npx prisma studio` 后)

## 详细安装步骤

### Node.js 安装

**Windows/macOS**:
1. 访问 https://nodejs.org/
2. 下载 LTS 版本 (v22.x)
3. 运行安装程序

1. 下载 https://git-scm.com/download/win
2. 运行安装程序

**macOS**:
```bash

```

**Linux**:
```bash

sudo apt install git
```

## WebSocket 开发配置

### 连接地址

```
ws://localhost:1111/ws
```

### 认证方式

WebSocket 连接通过 Query Parameter 传递 JWT Token:

```typescript
const ws = new WebSocket(`ws://localhost:1111/ws?token=${jwtToken}`);
```

### 前端 Hook 使用

```typescript
import { useWebSocket } from '@/hooks/useWebSocket';

function MyComponent() {
  const { isConnected, subscribe, sendMessage } = useWebSocket();
  
  useEffect(() => {
    if (isConnected) {
      subscribe('project-uuid', (message) => {
        console.log('Received:', message);
      });
    }
  }, [isConnected]);
}
```

### 消息类型

| 类型 | 方向 | 说明 |
|------|------|------|
| `subscribe` | 客户端→服务端 | 订阅项目房间 |
| `unsubscribe` | 客户端→服务端 | 取消订阅 |
| `slides_update` | 服务端→客户端 | 幻灯片更新广播 |
| `agent_progress` | 服务端→客户端 | Agent 任务进度 |

## SSE 开发配置

### Agent 进度流

```typescript
const eventSource = new EventSource(
  `/api/agent/sessions/${sessionId}/progress?token=${jwtToken}`
);

eventSource.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('Progress:', data);
};

eventSource.onerror = (error) => {
  console.error('SSE Error:', error);
  eventSource.close();
};
```

### Vite 代理配置

SSE 需要禁用缓冲，已在 `vite.config.ts` 中配置:

```typescript
proxy: {
  '/api': {
    target: 'http://127.0.0.1:1111',
    changeOrigin: true,
    // SSE 长连接支持
    configure: (proxy) => {
      proxy.on('proxyReq', (proxyReq) => {
        proxyReq.setHeader('Connection', 'keep-alive');
      });
    }
  }
}
```

## Agent 模式开发

### 数据模型

Agent 模式核心数据表:

| 表名 | 说明 |
|------|------|
| `AgentSession` | 会话，绑定项目 |
| `AgentMessage` | 消息历史 |
| `AgentTask` | 任务队列 |

### API 端点

```
POST   /api/agent/sessions              创建会话
GET    /api/agent/sessions/:id          获取会话详情
POST   /api/agent/sessions/:id/messages 发送消息
GET    /api/agent/sessions/:id/progress SSE 进度流
GET    /api/agent/sessions/:id/tasks    获取任务列表
POST   /api/agent/sessions/:id/tasks/:taskId/confirm 确认任务
```

### 调试技巧

1. **查看 WebSocket 连接状态**: 浏览器 DevTools → Network → WS
2. **查看 SSE 连接**: 浏览器 DevTools → Network → EventStream
3. **后端日志**: 查看 `server/logs/` 目录下的日志文件

## 常见问题

### Q1: 安装依赖时卡住

**解决**:
```bash
# 清除缓存
npm cache clean --force

# 使用淘宝镜像
npm config set registry https://registry.npmmirror.com

# 重新安装
rm -rf node_modules package-lock.json
npm install
```

### Q2: 数据库连接失败

**检查**:
1. `.env` 文件是否正确配置
2. 数据库文件是否存在
3. 权限是否正确

**解决**:
```bash
cd server
# 重新初始化
npx prisma db push
```

### Q3: 端口被占用

**解决**:
```bash
# Windows
netstat -ano | findstr :1000
taskkill /PID <PID> /F

# macOS/Linux
lsof -ti:1000 | xargs kill -9
```

### Q4: AI 生成失败

**检查**:
1. API Key 是否正确配置
2. 网络是否能访问外网
3. 查看后端日志
