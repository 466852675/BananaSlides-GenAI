## 认证方式

所有 API 请求（除登录/注册外）需要在 Header 中携带 JWT Token：

```http
Authorization: Bearer <your-jwt-token>
```

Token 通过登录接口获取，默认有效期 7 天。

## 通用响应格式

### 成功响应

```json
{
  "success": true,
  "data": { ... },
  "meta": {
    "page": 1,
    "limit": 20,
```

### SSE 实时进度 (1接口)

#### 任务进度流

```http
GET /api/agent/sessions/:sessionId/progress
Authorization: Bearer <token>
Accept: text/event-stream
```

**SSE 认证方式**（EventSource 不支持自定义 Header）:
- 方式1: Authorization Header
- 方式2: Query Parameter `?token=<jwt-token>`

**响应格式** (SSE):
```
data: {"status":"RUNNING","currentTask":"outline","progress":45,"message":"正在生成大纲..."}

data: {"status":"COMPLETED","currentTask":"outline","progress":100,"result":{...}}

: heartbeat
```

**心跳机制**: 每 30 秒发送心跳注释 `: heartbeat`，90 秒无响应断开连接。

### WebSocket 实时通信

#### 连接端点

```
ws://localhost:1111/ws
```

#### 认证

连接时通过 Query Parameter 传递 JWT Token:
```
ws://localhost:1111/ws?token=<jwt-token>
```

#### 消息格式

**客户端 → 服务端**:
```json
{
  "type": "subscribe",
  "payload": { "projectId": "project-uuid" }
}
```

**服务端 → 客户端**:
```json
{
  "type": "slides_update",
  "payload": {
    "projectId": "project-uuid",
    "source": "agent",
    "slides": [...]
  },
  "timestamp": 1712345678901
}
```

#### 消息类型

| 类型 | 方向 | 说明 |
|------|------|------|
| `subscribe` | C→S | 订阅项目房间 |
| `unsubscribe` | C→S | 取消订阅 |
| `slides_update` | S→C | 幻灯片更新广播 |
| `agent_progress` | S→C | Agent 任务进度 |
| `task_complete` | S→C | 任务完成通知 |
| `ping` | S→C | 心跳检测 |
| `pong` | C→S | 心跳响应 |

#### 房间机制

- 每个项目为一个房间
- 用户连接后自动加入当前项目房间
- 支持多标签页/多设备同时在线
- 心跳检测：30 秒间隔，自动清理断连客户端

| 创建自动执行模式会话 | PROFESSIONAL |
| 执行任务 | agent.task.execute 权限 |
