# 🪄 系统交互规范书 (System Interaction Spec)

> **文档版本**: v2.0 (深度重构版)
> **技术栈**: React 19 + Framer Motion 12 + Tailwind CSS 4
> **核心哲学**: 响应式动效与呼吸感 UI

---

## 1. 核心 UI 组件规范

### 1.1 胶囊式自适应导航 (Adaptive Capsule)
- **触发逻辑**: 监听 `window.scrollY`，当 `offset > 20px` 时触发从 `full-width` 到 `capsule-style` 的布局转换。
- **视觉标准**: 
    - 背景: `backdrop-blur-md` (毛玻璃效应)。
    - 边框: 实线 `border-white/10` 叠加 `AIGlowContainer` 呼吸辉光。

### 1.2 呼吸式生成反馈 (AI Pulse)
当 Slide 处于 `generating` 状态时，卡片必须应用 `AIGlowContainer` 组件：
- **动效曲线**: `duration: 1.5s`, `repeat: Infinity`, `ease: easeInOut`。
- **视觉寓意**: 表达 AI 正在后台进行深度的视觉计算，替代死板的加载条。

## 2. 动效标准与参数 (Motion Standards)

系统动效统一由 Framer Motion 驱动，禁止使用非受控的 CSS Transition。

| 动效场景 | 推荐参数 (Transition Value) | 动效类型 |
| :--- | :--- | :--- |
| **页面入场** | `initial: { opacity: 0, y: 10 }, animate: { opacity: 1, y: 0 }` | Fade Slide Up |
| **弹窗浮现** | `scale: [0.95, 1], opacity: [0, 1]` | Scale Spring |
| **胶囊收缩** | `layoutId: "nav", transition: { type: "spring", stiffness: 300, damping: 30 }` | Shared Layout |

## 3. 级联式过滤与响应式降级

- **中控面板布局**: 采用 `Left:Sticky Control + Right:Scrollable Grid`。
- **断点策略**: 
    - `>= 1280px`: 全量显示侧边控制树。
    - `< 1024px`: 自动切换为“抽屉式 (Drawer)”或“顶部滑块”模式。
