# 🗃️ 模板管理规范书 (Template & Assets Spec)

> **文档版本**: v2.0 (深度重构版)
> **技术栈**: 样式级联传播模型 (Style Cascade Model)
> **核心概念**: 广场共域与私域资产

---

## 1. 样式级联传播机制 (The Cascade)

系统采用类似 CSS 的层级覆盖逻辑，确保演示文稿的全局视觉统一性。

### 1.1 覆盖层级优先级
1.  **Slide Override (最高)**: 单页幻灯片手动调整的变体。
2.  **Project StyleMap (中)**: 项目级别的风格配置映射。
3.  **Template Config (底座)**: 模板库中定义的原始 `StyleConfig`。

### 1.2 异步传播逻辑
当从模板库选择一个模板并点击“应用”时：
- **数据同步**: 系统将模板的 `config` 与 `styleMap` 原子化写入 `Project` 模型。
- **意图重洗**: 系统自动更新项目的 `requirements` (Markdown 视觉指令)，准备触发 L1-L4 Prompt 引擎。

## 2. 模板市场维度与状态

系统通过 `StyleTemplate` 模型管理多维度的模板属性：
- **isOfficial**: 认证标志，由系统管理员维护。
- **isCustom**: 用户生成的个人私域资产。
- **推荐权重算法 (Usage Meta)**:
    - `usageCount`: 累计被项目引用的总次数。
    - `favoriteCount`: 被用户收藏的总次数。
    - `recommendCount`: 被其他用户点赞/推荐的总次数。

## 3. 资源持久化标准

- **预览图集 (`sampleImages`)**: 以 JSON 数组形式存储多张高清预览图 URL。
- **配置持久化 (`config`)**: 必须符合 `StyleConfig` 接口规范，包含布局比例、配色偏好等原子参数。
