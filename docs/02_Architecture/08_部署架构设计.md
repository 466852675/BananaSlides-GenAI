## 2. 开发环境部署

### 2.1 快速启动

```bash
# 1. 安装依赖
npm install && cd server && npm install

# 2. 初始化数据库
npx prisma db push

# 3. 启动前端 (默认端口 1000)
npm run dev

# 4. 启动后端 (默认端口 1111)
cd server && npm run dev
```

### 2.2 环境变量配置

**前端 (.env)**:
```env
VITE_API_BASE=/api
VITE_WS_URL=ws://localhost:1111
```

**后端 (.env)**:
```env
PORT=1111
DATABASE_URL="file:./prisma/dev.db"
AI_PROVIDER=Volcengine
```

## 3. 生产环境部署

### 3.1 手动部署

```bash
# 1. 构建前端
npm run build

# 2. 编译后端
cd server && npm run build

# 3. 配置 Nginx
# 将 dist 目录配置为静态资源服务

# 4. 使用 PM2 启动后端
cd server && pm2 start dist/index.js --name yhai-ppt-api
```

### 3.2 Nginx 配置示例

```nginx
server {
    listen 80;
    server_name yhai-ppt.com;
    
    # 前端静态资源
    location / {
        root /var/www/yhai-ppt/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }
    
    # API 代理
    location /api {
        proxy_pass http://127.0.0.1:1111;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
    
    # WebSocket
    location /ws {
        proxy_pass http://127.0.0.1:1111;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## 4. Docker 部署

### 4.1 Dockerfile (后端)

```dockerfile
FROM node:22-alpine

WORKDIR /app

COPY package*.json ./
RUN npm ci --only=production

COPY dist ./dist
COPY prisma ./prisma
COPY .env ./

EXPOSE 1111

CMD ["node", "dist/index.js"]
```

### 4.2 Dockerfile (前端)

```dockerfile
FROM node:22-alpine AS builder

WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### 4.3 Docker Compose

```yaml
version: '3.8'

services:
  api:
    build: ./server
    ports:
      - "1111:1111"
    environment:
      - DATABASE_URL=file:/app/data/dev.db
      - NODE_ENV=production
    volumes:
      - ./data:/app/data
    restart: unless-stopped

  web:
    build: ./client
    ports:
      - "1000:80"
    depends_on:
      - api
    restart: unless-stopped
```

## 5. 部署清单

### 5.1 部署前检查

| 检查项 | 说明 |
| :--- | :--- |
| Node.js 版本 | 需 v18+ (推荐 v22 LTS) |
