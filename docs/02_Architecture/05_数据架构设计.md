# 05_数据架构设计

> 本文档描述 YH-AI PPT 系统的数据架构设计，涵盖数据模型、数据域划分、存储方案及关系图谱。
>
> **技术栈**: Prisma ORM v6.19 + SQLite | **数据库文件**: `./server/prisma/dev.db`

---

## 1. 数据架构概览

### 1.1 核心数据域

系统数据按照业务边界划分为 **7大数据域**，共 **28个数据实体**：

| 数据域 | 英文名称 | 实体数量 | 核心功能 |
| :--- | :--- | :---: | :--- |
| **用户域** | User Domain | 3 | 用户账户、第三方登录、消息设置 |
| **项目域** | Project Domain | 3 | 项目管理、幻灯片、版本快照 |
| **商业域** | Commerce Domain | 4 | 订单、产品、积分交易、积分规则 |
| **内容域** | Content Domain | 2 | 样式模板、收藏 |
| **消息域** | Message Domain | 3 | 消息中心、消息模板、消息设置 |
| **权限域** | Permission Domain | 2 | 权限定义、角色权限关联 |
| **增长运营域** | Growth Domain | 4 | 签到、线索(CRM)、邀请关系 |
| **安全域** | Security Domain | 7 | 退款、审计、风控、权益回收 |

## 11. 存储方案

### 11.1 数据库配置

| 项目 | 配置 |
| :--- | :--- |
| 数据库类型 | SQLite |
| ORM框架 | Prisma v6.19 |
| 数据文件 | `./server/prisma/dev.db` |
| 迁移工具 | Prisma Migrate |

### 11.2 索引策略

- **主键**: 所有表使用 UUID 作为主键
- **外键索引**: 关联字段自动创建索引
- **业务索引**: 按查询频率创建组合索引
- **唯一索引**: 关键业务字段 (orderNo, refundNo, email等)

### 11.3 数据一致性

- **外键约束**: 使用 Prisma 关系约束
- **级联删除**: 关联数据自动清理 (onDelete: Cascade)
- **软删除**: 部分实体使用 isDeleted 标志
