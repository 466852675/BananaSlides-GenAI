> 本文档描述 YH-AI PPT 系统的文件存储架构设计，涵盖上传流程、存储策略、文件类型及安全策略。

## 2. 文件类型定义

### 2.1 支持的文件类型

| 分类 | 类型 | 用途 | 大小限制 |
| :--- | :--- | :--- | :--- |
| **图片** | jpg, jpeg, png, gif, webp | 用户上传参考图、PPT导出 | 10MB |
| **文档** | pdf, doc, docx | 文档解析输入 | 50MB |
| **视频** | mp4, webm | 教程/演示视频 | 100MB |
| **音频** | mp3, wav | 配音/旁白 | 50MB |
| **其他** | zip, json | 批量导入/导出 | 20MB |

### 2.2 文件目录结构

```
uploads/
├── images/           # 用户上传的图片
│   ├── {year}/
│   │   └── {month}/
│   │       └── {uuid}.{ext}
├── documents/        # 文档文件 (PDF/Word)
│   └── {year}/
│       └── {month}/
├── exports/          # 导出的文件
│   └── {year}/
│       └── {month}/
├── thumbnails/      # 缩略图
│   └── {year}/
│       └── {month}/
└── temp/            # 临时文件
    └── (自动清理)
```

## 3. 上传流程

### 3.1 API 接口

| 方法 | 路径 | 说明 | 认证 |
| :--- | :--- | :--- | :--- |
| POST | `/api/uploads/image` | 上传图片 | 是 |
| POST | `/api/uploads/document` | 上传文档 | 是 |
| POST | `/api/uploads/avatar` | 上传头像 | 是 |
| DELETE | `/api/uploads/:id` | 删除文件 | 是 |
| GET | `/api/uploads/:id` | 获取文件信息 | 是 |

### 3.2 上传流程

```
用户选择文件 → 前端校验 → POST上传 → 后端校验 → 存储处理 → 返回URL
                  │                                    │
                  ▼                                    ▼
            文件类型/大小                          本地/OSS/S3
```

### 3.3 后端处理逻辑

```typescript
// 1. Multer 配置
const storage = multer.diskStorage({
  destination: (req, file, cb) => {
    const type = getFileType(file.mimetype);
    cb(null, `./uploads/${type}/${year}/${month}`);
  },
  filename: (req, file, cb) => {
    const ext = path.extname(file.originalname);
    cb(null, `${uuid()}${ext}`);
  }
});

// 2. 文件类型过滤
const fileFilter = (req, file, cb) => {
  const allowedTypes = ['image/jpeg', 'image/png', 'application/pdf', ...];
  if (allowedTypes.includes(file.mimetype)) {
    cb(null, true);
  } else {
    cb(new Error('不支持的文件类型'), false);
  }
};
```

## 4. 存储策略

### 4.1 多存储适配器

```typescript
interface StorageAdapter {
  upload(file: Buffer, path: string): Promise<string>;
  delete(path: string): Promise<void>;
  getUrl(path: string): string;
}

class LocalStorageAdapter implements StorageAdapter { ... }
class AliyunOSSAdapter implements StorageAdapter { ... }
class S3Adapter implements StorageAdapter { ... }
```

### 4.2 存储策略选择

| 环境 | 推荐存储 | 原因 |
| :--- | :--- | :--- |
| 开发 | 本地存储 | 简单、无需配置 |
| 测试 | 本地存储 | 快速迭代 |
| 生产 (国内) | 阿里云 OSS | 访问速度快、CDN 加速 |
| 生产 (海外) | AWS S3 | 全球节点覆盖 |
| 私有化 | MinIO | 数据自主可控 |

### 4.3 环境变量配置

```env
# 存储配置
STORAGE_TYPE=aliyun          # 存储类型: local/aliyun/s3/minio

# 阿里云 OSS
ALIYUN_OSS_ACCESS_KEY=your_access_key
ALIYUN_OSS_ACCESS_SECRET=your_secret
ALIYUN_OSS_BUCKET=your_bucket
ALIYUN_OSS_REGION=oss-cn-hangzhou

# AWS S3
AWS_ACCESS_KEY_ID=your_key
AWS_SECRET_ACCESS_KEY=your_secret
AWS_S3_BUCKET=your_bucket
AWS_S3_REGION=us-east-1
```

## 5. 安全策略

### 5.1 文件安全

| 策略 | 说明 |
| :--- | :--- |
| **文件类型白名单** | 只允许预定义的安全类型 |
| **文件大小限制** | 按类型设置不同限制 |
| **文件名随机化** | 使用 UUID 避免文件名冲突 |
| **恶意文件检测** | 检测文件真实 MIME 类型 |

### 5.2 访问控制

| 策略 | 说明 |
| :--- | :--- |
| **私有文件** | 需要登录 Token 才能访问 |
| **签名 URL** | OSS/S3 使用预签名 URL |
| **CDN 鉴权** | 开启 URL 签名防盗链 |
| **IP 限制** | 可配置 IP 白名单 |

### 5.3 数据保护

| 策略 | 说明 |
| :--- | :--- |
| **备份策略** | OSS 自动多副本存储 |
| **生命周期** | 定期清理临时文件和过期导出 |
| **加密存储** | 敏感文件可选加密存储 |
| **日志审计** | 记录所有文件操作日志 |
