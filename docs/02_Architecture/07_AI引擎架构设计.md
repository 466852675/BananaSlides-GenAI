# 07_AI引擎架构设计

> 本文档描述 YH-AI PPT 系统的 AI 引擎架构设计，涵盖多模型路由、Prompt 工程、图像生成策略及文档解析集成。
>
> **技术栈**: Google GenAI SDK | **模式**: Router-Adapter

---

## 1. AI 引擎架构概览

### 1.1 设计理念

- **多模型路由**: 根据任务类型自动选择最优模型
- **适配器模式**: 统一的接口抽象，支持灵活扩展
- **成本优化**: 支持模型热切换，降低调用成本
- **质量保障**: 多模型结果对比，选择最佳输出

## 2. AI 模型提供商

### 2.1 支持的 AI 引擎

| 引擎 | 类型 | 主要用途 | 特点 |
| :--- | :--- | :--- | :--- |
| **Gemini** | 多模态 | 图片生成、视觉分析 | 视觉原生、创意强 |
| **Volcengine** | 生图 | 图片生成 | 并发加速、Seed锁定 |
| **Zhipu (GLM)** | 大语言模型 | 大纲生成、内容生成 | 中文优化、推理能力强 |
| **DeepSeek** | 大语言模型 | 逻辑推理 | 高性价比 |
| **CustomCombo** | 路由 | 多模型组合 | 灵活调度 |
| **MinerU** | 文档解析 | PDF/Word结构化 | 工业级精度 |

### 2.2 模型配置 (AiEngineRule)

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | UUID | 主键 |
| name | String | 规则名称 |
| provider | String | 厂商标识 |
| config | JSON | baseUrl, apiKey, model等 |
| isActive | Boolean | 是否启用 |

## 3. 核心 AI 流程

### 3.1 大纲生成流程 (Outline Generation)

```
用户输入 → 主题润色 → LLM生成 → 结构化解析 → 大纲展示
              │
              ▼
        Zhipu GLM-4.7
        或 DeepSeek
```

**Prompt 示例**:
```
作为PPT大纲生成专家，请根据以下主题生成专业的演示文稿大纲。

主题: {user_input}

要求:
1. 结构清晰，层次分明
2. 包含标题、要点、结论
3. 适合商务演示场景
```

### 3.2 图片生成流程 (Image Generation)

```
PPT页面 → 视觉基因提取 → Prompt合成 → 多模型并发 → 结果选择 → 图片输出
              │                                        │
              ▼                                        ▼
        Gemini Vision                           Volcengine
        (构图/配色分析)                         (并发加速)
```

**4层 Prompt 重组引擎**:

| 层级 | 名称 | 说明 |
| :---: | :--- | :--- |
| L1 | 视觉基因层 | Vision模型解析参考图，提取构图、配色、氛围 |
| L2 | 业务语义层 | 提取标题、关键字、正文内容 |
| L3 | 指令合成层 | 将视觉基因与业务语义有机结合 |
| L4 | 参数标准层 | 16:9画幅、2K/4K分辨率、电影级光效 |

### 3.3 文档解析流程 (Document Parsing)

```
上传文档(PDF/Word) → MinerU解析 → 结构化输出 → 内容导入
                         │
                         ▼
              标题/段落/表格/图片/公式
```

## 4. Router-Adapter 模式

### 4.1 统一接口定义

```typescript
interface AIAdapter {
  // 文本生成
  generateText(prompt: string, options?: TextOptions): Promise<TextResult>;
  
  // 图片生成
  generateImage(prompt: string, options?: ImageOptions): Promise<ImageResult>;
  
  // 视觉分析
  analyzeImage(imageUrl: string, prompt: string): Promise<VisionResult>;
}
```

### 4.2 路由策略

| 任务类型 | 默认模型 | 备选模型 | 适用场景 |
| :--- | :--- | :--- | :--- |
| 大纲生成 | GLM-4.7 | DeepSeek | 逻辑结构化 |
| 内容扩写 | Gemini Flash | GLM-4 | 上下文理解 |
| 图片生成 | Gemini Pro Image | Volcengine | 创意/速度平衡 |
| 视觉分析 | Gemini Flash | - | 参考图解析 |
| 文档解析 | MinerU | - | PDF结构化 |

## 5. 性能优化策略

### 5.1 并发控制

| 场景 | 并发数 | 超时时间 |
| :--- | :---: | :---: |
| 图片生成 | 3 | 60s |
| 大纲生成 | 1 | 30s |
| 文档解析 | 2 | 120s |

### 5.2 缓存策略

- **Prompt 缓存**: 相同任务复用已生成Prompt
- **结果缓存**: 热门模板生成的图片短期缓存
- **模型响应缓存**: 相同输入的响应缓存

### 5.3 错误处理

| 错误类型 | 处理策略 |
| :--- | :--- |
| API超时 | 自动切换备选模型 |
| 配额耗尽 | 切换至免费模型 |
| 内容过滤 | 返回安全提示 |

## 6. 配置管理

### 6.1 环境变量

```env
# AI 提供商配置
AI_PROVIDER="Volcengine"  # 当前激活的提供商
COMBO_TEXT_MODEL="gemini-3-flash"
COMBO_IMAGE_MODEL="gemini-3-pro-image"
COMBO_VISION_MODEL="gemini-3-flash"

# 文档解析
DOC_PARSER_BASE="https://mineru.net"
DOC_PARSER_PROVIDER="MinerU"
```

### 6.2 热更新

- AI引擎配置存储于数据库 (AiEngineRule表)
- 支持后台管理界面实时修改
- 无需重启服务即可生效
