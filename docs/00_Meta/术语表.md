# 📖 YH-AI PPT 术语表

本文档定义 YH-AI PPT 项目中使用的专业术语和缩写，帮助读者理解文档内容。

---

## A

### Agent
智能代理。AI 驱动的对话式交互模式，用户通过自然语言描述需求，由 Agent 自动规划任务、逐步执行，完成从大纲到配图的全流程 PPT 生成。

### Agent 会话 (Agent Session)
Agent 模式的核心数据单元，绑定一个项目，包含对话历史、任务队列、执行状态等。

### Agent 任务 (Agent Task)
Agent 执行的具体操作单元，类型包括：CONFIG_CONFIRM（配置确认）、OUTLINE（大纲生成）、CONTENT（内容生成）、IMAGE（配图生成）。

### AI (Artificial Intelligence)
人工智能。在本项目中指用于生成PPT内容的机器学习模型。

### API (Application Programming Interface)
应用程序接口。系统提供的对外服务接口，使用RESTful风格。

### API Key
API密钥。用于访问第三方AI服务（如Gemini、OpenAI）的认证凭证。

### 自动执行模式 (Auto Execute Mode)
Agent 会话模式之一，用户发送需求后 AI 自动执行所有步骤，无需逐步确认。需要 PROFESSIONAL 及以上权限。

---

## B

### Backend
后端。指服务器端的Express应用程序，处理业务逻辑和数据存储。

### Base64
一种基于64个可打印字符表示二进制数据的编码方式。用于图片传输。

---

## C

### Cache
缓存。用于临时存储数据以提高访问速度，如配置缓存、查询缓存。

### CustomCombo
自定义组合。多模型路由中的一种配置模式，允许为不同任务指定不同的AI模型。

---

## D

### DAN (Do Anything Now)
一种试图绕过AI安全限制的Prompt注入技术。

### Dashboard
仪表盘。项目的主界面，展示项目列表和状态。

### DB (Database)
数据库。本项目使用SQLite作为数据存储。

### Docker
容器化平台。用于打包和部署应用程序。

---

## E

### E2E (End-to-End)
端到端测试。模拟真实用户操作的自动化测试。

### Enum
枚举。一种数据类型，变量的值必须是预定义常量之一。

### ER图 (Entity-Relationship Diagram)
实体关系图。用于展示数据模型之间的关系。

### Express
Node.js Web应用框架。本项目后端使用的框架。

---

## F

### Frontend
前端。指用户界面部分，使用React构建。

### Function Calling
函数调用。OpenAI 定义的 AI 工具调用格式，Agent 使用此格式定义 9 大工具。

---

## G

### Gemini
Google开发的AI模型。本项目主要使用的生图和推理模型。

### GMV (Gross Merchandise Volume)
商品交易总额。商业指标，指所有订单的总金额。

### 引导模式 (Guided Mode)
Agent 会话模式之一，每个关键步骤需要用户确认后才能继续执行。

---

## H

### Hook
钩子。React中的函数，用于在组件中使用状态和其他React特性。

### HTTPS
超文本传输安全协议。HTTP的安全版本，使用SSL/TLS加密。

### 心跳检测 (Heartbeat)
WebSocket/SSE 连接保活机制，定期发送心跳包检测连接状态。

---

## I

### IDE (Integrated Development Environment)
集成开发环境。如VS Code、WebStorm等。

### Index
索引。数据库中用于加速查询的数据结构。

### IP (Internet Protocol)
互联网协议。设备在网络中的唯一标识。

---

## J

### JWT (JSON Web Token)
JSON网络令牌。用于用户认证的开放标准，包含用户信息和签名。

---

## K

### Key
密钥。用于加密、认证或API访问的字符串。

---

## L

### LTS (Long Term Support)
长期支持版本。Node.js等软件的稳定版本。

---

## M

### Middleware
中间件。Express中处理HTTP请求的函数，如认证、日志、限流等。

### MinerU
开源文档解析工具。用于提取PDF等文档的文本和结构。

### Mock
模拟。在开发中模拟真实服务的行为，如模拟支付。

### Mock模式
⚠️ 功能状态标记。表示该功能接口已实现但使用模拟数据而非真实服务（如支付Mock模式）。

### 多模型路由 (Multi-Model Router)
AI引擎架构。支持同时配置多个AI提供商（Gemini/Volcengine/OpenAI等），根据任务类型自动选择最优模型的路由机制。

### MVP (Minimum Viable Product)
最小可行产品。具备核心功能的初步产品版本。

---

## N

### Nginx
高性能Web服务器和反向代理服务器。

### Node.js
基于Chrome V8引擎的JavaScript运行时。

---

## O

### OAuth
开放授权协议。用于第三方登录，如微信、GitHub登录。

### 乐观更新 (Optimistic Update)
前端 UI 优化策略。用户发送消息后立即显示在界面，服务端响应后无缝替换，无需等待。

### ORM (Object-Relational Mapping)
对象关系映射。Prisma就是一种ORM工具，用于简化数据库操作。

---

## P

### P0/P1/P2/P3
优先级标识。P0为最高优先级（紧急），P3为最低优先级。

### Permission
权限。RBAC系统中定义的访问控制单元，如"admin.users.create"。

### PPT (PowerPoint)
演示文稿。Microsoft Office的演示软件，也泛指演示文稿文件。

### Prisma
现代ORM工具。本项目使用的数据库访问工具。

### Project Room (项目房间)
WebSocket 通信机制。每个项目对应一个房间，用户订阅房间后可接收该项目的实时更新广播。

### Prompt
提示词。给AI模型的输入文本，用于指导生成内容。

### Prompt Injection
Prompt注入。一种试图操纵AI模型行为的攻击方式。

---

## Q

### Query
查询。从数据库检索数据的操作，也指URL中的查询参数。

---

## R

### RBAC (Role-Based Access Control)
基于角色的访问控制。权限管理模型，通过角色分配权限。

### React
JavaScript库。用于构建用户界面，本项目前端使用的框架。

### Refund
退款。用户申请退回已支付金额的操作。

### 退款风控 (Refund Risk Control)
退款安全机制。通过7项规则自动检测异常退款行为，防止恶意退款和资金损失。

### 权益回收 (Benefit Revocation)
退款后处理流程。自动收回用户因订单获得的积分、VIP等级等权益，确保财务一致性。

### REST (Representational State Transfer)
表述性状态传递。一种软件架构风格，用于设计网络应用程序。

### Role
角色。RBAC系统中的权限集合，如"ADMIN"、"USER"。

---

## S

### SaaS (Software as a Service)
软件即服务。通过互联网提供软件应用的服务模式。

### Schema
模式。数据库结构定义，包括表、字段、关系等。

### SDK (Software Development Kit)
软件开发工具包。如Google GenAI SDK。

### Seed
随机种子。AI生成中用于控制随机性的数值，相同Seed产生相似结果。

### SSE (Server-Sent Events)
服务器推送事件。基于 HTTP 的单向实时通信协议，用于 Agent 任务进度流式推送。

### 快照版本 (Snapshot Version)
版本控制机制。保存项目在特定时间点的完整状态，支持随时回滚到历史版本。

### 预留接口 (Reserved Interface)
⚠️ 功能状态标记。表示该功能已定义接口规范但后端实现未完成或外部服务未接入（如MinerU解析）。

### Slide
幻灯片。PPT中的单页内容。

### SQL (Structured Query Language)
结构化查询语言。用于管理和操作关系数据库的语言。

### SQLite
嵌入式关系数据库。本项目使用的数据库引擎。

### SSR (Server-Side Rendering)
服务端渲染。在服务器生成HTML页面的技术。

---

## T

### Tailwind CSS
实用优先的CSS框架。本项目使用的样式工具。

### TanStack Query
React数据获取和状态管理库。原名React Query。

### TLS (Transport Layer Security)
传输层安全协议。HTTPS使用的加密协议。

### Token
令牌。用于身份验证的字符串，如JWT Token。

### Transaction
事务。数据库操作的基本单位，保证数据一致性。

### TypeScript
JavaScript的超集，添加了静态类型系统。

---

## U

### UI (User Interface)
用户界面。用户与系统交互的界面。

### URL (Uniform Resource Locator)
统一资源定位符。网页地址。

### UUID (Universally Unique Identifier)
通用唯一识别码。用于标识实体的128位数字。

### UX (User Experience)
用户体验。用户使用产品时的整体感受。

---

## V

### VIP (Very Important Person)
贵宾。系统中的高级会员等级，享有特权。

### Vision
视觉。指AI模型的图像理解能力，如分析图片内容。

### Vite
现代前端构建工具。本项目使用的开发服务器和构建工具。

### Volcengine
火山引擎。字节跳动旗下的云服务平台，提供AI能力。

---

## W

### Webhook
网络钩子。HTTP回调，用于事件通知，如支付回调。

### WebSocket
全双工通信协议。用于实时双向通信，支持项目房间广播、心跳检测、自动重连。

### 工作台模式 (Workbench Mode)
传统 PPT 编辑模式，用户手动配置参数、批量生成，精细控制每一页。

---

## Z

### Zod
TypeScript模式验证库。用于运行时类型检查。

### 智谱AI (Zhipu AI)
国产大模型提供商。支持文本生成和图像生成。

---

## 中文术语

### 白嫖
网络用语。指免费使用服务后不付费的行为。

### 大纲
PPT的内容框架结构，包含标题和简要描述。

### 风控
风险控制。用于识别和防范欺诈、滥用等风险。

### 连续签到算法
增长运营策略。根据用户连续签到天数计算奖励，中断后重置，鼓励用户每日活跃。

### 裂变
增长策略。通过用户邀请实现用户增长的营销方式。

### 轮询
定时查询。前端定期向服务器请求数据的机制。

### 软删除
逻辑删除。标记数据为已删除但不物理删除，便于恢复。

### 薅羊毛
利用规则漏洞获取不当利益的行为。

### 站内信
系统内部消息。不通过邮件等外部渠道的消息通知。

### 双模式架构
工作台模式和 Agent 模式共享同一项目数据层，顶部 Tab 一键切换，两种模式无缝衔接。
