## 📝 文档使用规范

### 文档头部信息

每篇文档都包含以下元信息：

```markdown
---
title: 文档标题
code_version: v1.2.3
last_updated: 2026-02-16
author: 作者名
status: published
---
```

### 文档版本说明

- **published**: 已发布，可放心使用
- **review**: 审核中，内容可能变动
- **draft**: 草稿，不建议使用
- **deprecated**: 已弃用，请查看最新版本

### 如何贡献文档

1. 遵循 [文档同步检查清单](./文档同步检查清单.md)
2. 使用统一的文档头部模板
3. 确保代码示例可运行
4. 提交 PR 时标注文档变更
