| **模块文档引用** | 0个 | **28个** | 新增 |

### 主要更新内容

#### 1. 功能模块扩展
- **用户工作台**: 新增项目管理
- **AI生成能力**: 新增多模型路由、模板概念分析、风格参考图生成
- **文档与文件**: 新增上传文件管理
- **用户增值服务**: 新增收藏功能、消息中心、快照版本、签到系统、邀请返利
- **认证与权限**: 新增认证服务系统
- **管理后台**: 新增数据概览、AI引擎配置、系统设置、落地页系统
- **商业化**: 新增订单管理、商品管理、积分规则管理、退款审核
- **运营增长**: 新增CRM线索系统

#### 2. 数据模型扩展 (9 → 28个实体)
新增实体：
- `SocialAccount` - 第三方社交账号绑定
- `CheckInLog` - 签到记录
- `RefundHistory` - 退款历史
- `RefundRetryLog` - 退款重试日志
- `UserRefundStats` - 用户退款统计
- `BenefitRevokeLog` - 权益回收日志
- `AppSettings` - 应用设置
- `UserMessage` / `MessageTemplate` / `UserMessageSettings` - 消息中心
- `Lead` / `LeadActivity` - CRM线索
- `Permission` / `RolePermission` - 权限管理
- `AiEngineRule` / `GlobalConfig` - AI引擎与系统配置

#### 3. 接口数量统计 (40+ → 196+)
- 认证接口: 8个

- 管理后台接口: **75+**

#### 4. 功能状态标记更新
- **MinerU文档解析**: ⚠️ 从"已实现"改为"预留接口"

## 版本说明

### 版本号规则

采用语义化版本控制 (SemVer):

- **主版本号** (v2.0.0): 重大重构或架构变更
- **次版本号** (v2.1.0): 新增功能或文档
- **修订号** (v2.1.1): 错误修复或小调整

### 变更类型标记

- ✅ 新增 (Added)
- 🔧 修改 (Modified)
- 🗑️ 删除 (Removed)
- 🐛 修复 (Fixed)
