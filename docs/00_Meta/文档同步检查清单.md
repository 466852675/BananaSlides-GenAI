# 📋 YH-AI PPT 文档同步检查清单

> **用途**: 确保代码变更时文档同步更新  
> **使用场景**: PR审查、发布前检查、定期审查  

## PR 文档检查清单

### 通用检查项

- [ ] 代码是否有新增/修改 API 接口？
  - [ ] 已更新 API 文档
  - [ ] 已添加/更新错误码说明
  - [ ] 已更新接口示例

- [ ] 代码是否有新增/修改数据模型？
  - [ ] 已更新数据字典
  - [ ] 已更新 ER 图（如有重大变更）
  - [ ] 已添加迁移说明

- [ ] 代码是否有新增/修改功能？
  - [ ] 已更新功能说明文档
  - [ ] 已添加使用示例
  - [ ] 已更新相关模块文档

- [ ] 代码是否有修改技术方案？
  - [ ] 已更新架构文档
  - [ ] 已更新技术决策记录

- [ ] 代码是否有修改配置？
  - [ ] 已更新配置说明
  - [ ] 已更新环境变量清单
  - [ ] 已更新部署文档

- [ ] **清晰性**: 语言简洁易懂
- [ ] **一致性**: 术语和格式统一

- [ ] 文档头部信息完整（标题/版本/作者/日期）

## 自动化检查

### GitHub Actions 配置

```yaml
# .github/workflows/doc-check.yml
name: 文档一致性检查

on:
  pull_request:
    paths:
      - 'docs/**'
      - 'server/src/**'
      - 'src/**'

jobs:
  doc-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: 检查文档-代码一致性
        run: |
          ./scripts/doc-consistency-check.sh
      
      - name: 检查 API 文档完整性
        run: |
          ./scripts/api-doc-check.sh
      
      - name: 检查链接有效性
        run: |
          npm run check-links
      
      - name: 评论 PR
        uses: actions/github-script@v6
        with:
          script: |
            github.rest.issues.createComment({
              issue_number: context.issue.number,
              owner: context.repo.owner,
              repo: context.repo.repo,
              body: '📚 文档检查完成。请确保所有代码变更都有对应的文档更新。'
            })
```

### 检查脚本

```bash
#!/bin/bash
# scripts/doc-consistency-check.sh

echo "🔍 开始文档一致性检查..."

# 1. 检查 API 路径一致性
echo "📡 检查 API 路径..."
missing_docs=0

# 获取所有路由
routes=$(grep -r "router\.(get|post|put|delete)" server/src/routes/ | grep -o "'[^']*'" | tr -d "'" | sort | uniq)

for route in $routes; do
    if ! grep -q "$route" docs/05_API/; then
        echo "⚠️  未找到 API 文档: $route"
        missing_docs=$((missing_docs + 1))
    fi
done

# 2. 检查数据模型一致性
echo "🗄️  检查数据模型..."
models=$(grep "^model " server/prisma/schema.prisma | awk '{print $2}')
doc_models=$(grep -c "^model " docs/03_Database/)

if [ $doc_models -lt $(echo $models | wc -w) ]; then
    echo "⚠️  数据模型文档不完整 ($doc_models/$(echo $models | wc -w))"
fi

# 3. 检查错误码一致性
echo "🚨 检查错误码..."
error_codes=$(grep -r "code:" server/src/ | grep -o "'[A-Z_]*'" | tr -d "'" | sort | uniq)

for code in $error_codes; do
    if ! grep -q "$code" docs/05_API/03_错误码规范.md; then
        echo "⚠️  未定义错误码: $code"
    fi
done

if [ $missing_docs -eq 0 ]; then
    echo "✅ 文档一致性检查通过"
    exit 0
else
    echo "❌ 发现 $missing_docs 处不一致"
    exit 1
fi
```
