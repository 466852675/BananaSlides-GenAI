## 1. 产品概述

### 1.1 产品定位

YH-AI PPT 是一款**智能演示文稿全链条设计平台**，融合 Google Gemini 的"视觉原生"能力与 GLM/DeepSeek 生态的通用逻辑推理，集成 MinerU 工业级智能文档解析内核，并内置完整的商业化 SaaS 基础设施。

**核心价值主张**：
- 将复杂的 PPT 创作过程降维至分钟级响应
- 通过"意图驱动"的设计哲学实现智能化创作
- 提供零代码的商业变现能力

### 1.2 目标用户

| 用户角色 | 典型场景 | 核心需求 |
|----------|----------|----------|
| 职场精英 | 竞标方案、周月报、战略分析 | 快速冷启动、专业效果 |
| 高校科研 | 学术论文汇报、课题开题 | 高保真转录、公式识别 |
| 教研培训 | 课程讲义、培训课件 | 视觉多样性、快速生成 |
| 开发者 | 技术方案评审、架构分享 | 私有化部署、代码高亮 |
| 运营人员 | 活动策划、数据分析 | 增长工具、邀请返利 |
| 企业管理员 | 权限分配、财务对账 | RBAC权限、审计日志 |

### 2.2 用户工作台模块

#### 2.2.1 项目管理

**需求描述**：用户创建、编辑、管理PPT项目，支持项目列表视图、状态管理和批量操作。

**用户故事**：
> 作为用户，我希望能够管理多个PPT项目，查看项目进度，方便地找到并继续编辑之前的项目。

**功能规格**：
- 项目CRUD：创建、读取、更新、删除项目
- 项目列表：卡片式看板，支持筛选、排序、搜索
- 项目状态：草稿、生成中、已完成、已归档
- 批量操作：删除、归档、导出多个项目
- 置顶功能：重要项目置顶显示
- 项目搜索：按名称、时间、状态筛选
- 实时进度：显示AI生成进度百分比

**参考文档**：
- [项目管理系统设计](../04_Modules/01_用户工作台/项目管理系统设计.md)

### 2.3 智能创作模块

#### 2.3.1 AI主题润色

**需求描述**：用户输入一句话主题，AI进行语义润色和专业修饰，生成更具吸引力的PPT标题。

**用户故事**：
> 作为用户，我希望输入一个简单的主题就能获得专业的PPT标题建议，这样我不需要绞尽脑汁思考标题。

**功能规格**：
- 输入：一句话主题描述（50字以内）
- 输出：5个经过AI润色的标题建议
- 支持语言：中文、英文
- 响应时间：< 3秒

**参考文档**：
- [智能文本润色](../04_Modules/02_AI生成能力/智能文本润色.md)

#### 2.3.2 结构化大纲生成

**需求描述**：基于主题自动生成结构化的大纲，包含章节划分、要点提炼、逻辑串联。

**功能规格**：
- 输入：主题 + 可选参考文档
- 输出：层级化大纲（建议8-15页）
- 支持PPT页数：5-50页
- 大纲结构：封面 → 目录 → 正文 → 总结 → 结尾

#### 2.3.3 批量内容扩写

**需求描述**：根据大纲节点批量生成正文内容，支持深度语境润色。

**功能规格**：
- 输入：大纲节点列表
- 输出：每节点300-800字正文
- 支持风格：正式/活泼/学术/商务
- 支持语言：与输入语言一致

**参考文档**：
- [幻灯片正文生成](../04_Modules/02_AI生成能力/幻灯片正文生成.md)

#### 2.3.4 AI图片生成

**需求描述**：根据页面内容自动生成匹配的封面图、配图、装饰图。

**功能规格**：
- 支持分辨率：2K (2560×1440)、4K (3840×2160)
- 支持比例：16:9、4:3
- Seed锁定：支持保持风格一致性
- 生成模型：Gemini、Volcengine、OpenAI

#### 2.3.5 版本历史/时光机

**需求描述**：保存项目历史版本，支持任意时间点回溯。

**功能规格**：
- 自动保存：每次重要操作生成快照
- 手动保存：支持用户主动保存
- 最大版本数：50个/项目
- 回溯方式：一键恢复 + 差异预览

**参考文档**：
- [快照版本历史](../04_Modules/04_用户增值服务/快照版本历史.md)

#### 2.3.6 多模型路由

**需求描述**：智能调度不同AI模型，根据任务类型选择最优模型资源。

**功能规格**：
- 支持提供商：Gemini、OpenAI、Zhipu、Volcengine、SiliconFlow、ModelScope、Custom
- 任务分类：文本生成、图片生成、视觉分析
- 路由策略：基于任务类型自动路由
- 并发控制：文本/图片独立并发配置
- 故障切换：主模型失败时自动切换备用
- 配置热更新：修改配置即时生效，无需重启

**参考文档**：
- [多模型路由](../04_Modules/02_AI生成能力/多模型路由.md)

### 2.4 文档与文件模块

#### 2.3.1 MinerU文档解析

**需求描述**：上传PDF/Word文档，AI自动解析结构化内容并转化为PPT大纲。

**功能规格**：
- 支持格式：PDF、DOCX（预留接口，待实现）
- 解析能力：文字提取、表格识别、公式识别、多栏版式
- 输出格式：Markdown结构化文本
- 最大文件大小：50MB
- API接口：`POST /api/doc-parser/parse`（预留）

**实现状态**：⚠️ API接口已预留，解析核心功能待开发

**参考文档**：
- [MinerU解析引擎](../04_Modules/03_文档与文件/MinerU解析引擎.md)

#### 2.3.2 上传文件管理

**需求描述**：统一的文件上传服务，支持多类型文件上传和存储。

**功能规格**：
- 支持格式：PNG、JPG、WebP、PDF、DOCX、TXT
- 大小限制：单文件最大50MB
- 存储方式：本地磁盘存储（/uploads/）
- 文件名生成：时间戳+随机数，防重名
- 类型校验：MIME类型和扩展名双重校验
- 访问方式：静态URL直接访问
- 上传限流：每15分钟最多10次

**参考文档**：
- [上传文件管理](../04_Modules/03_文档与文件/上传文件管理.md)

**需求描述**：上传参考图片，AI分析视觉风格并提取"视觉基因"。

**功能规格**：
- 分析维度：构图、配色、背景肌理、空间层级
- 输出：视觉基因向量 + Prompt增强
- 应用场景：模板生成、图片生成
- 双模输入架构：支持参考图+文本描述

**参考文档**：
- [模板概念分析](../04_Modules/02_AI生成能力/模板概念分析.md)

**需求描述**：基于风格配置生成参考预览图，展示模板效果。

**功能规格**：
- 模拟内容生成：使用虚拟标题和正文
- 风格一致性：确保预览图与实际生成效果一致

- [风格参考图生成](../04_Modules/02_AI生成能力/风格参考图生成.md)

### 2.4 商业化模块

#### 2.4.1 积分系统

**需求描述**：平台虚拟货币，用于购买AI生成次数、VIP会员等。

**功能规格**：
- 积分获取：注册赠送、签到奖励、邀请奖励、购买充值
- 积分消耗：AI生成（每次消耗）、模板使用（一次性）
- VIP专属价：VIP用户享受折扣
- 兑换比例：10积分 = 1元人民币

#### 2.4.2 VIP会员体系

**需求描述**：6级会员制度，不同级别享有不同权益。

| 级别 | 名称 | 月费(积分) | 专属权益 |
|------|------|------------|----------|
| 0 | 普通用户 | - | 基础功能 |
| 1 | Basic | 99 | 8折积分价 |
| 2 | Professional | 199 | 7折积分价 |
| 3 | Premium | 399 | 6折积分价 |
| 4 | Enterprise | 799 | 5折积分价 |
| 5 | Admin | - | 管理后台 |

#### 2.4.3 支付系统

**需求描述**：支持支付宝、微信支付购买积分和VIP。

**功能规格**：
- 支付渠道：支付宝、微信支付
- 支付模式：当前为Mock模式，配置密钥后可启用真实支付
- 商品类型：积分充值、VIP订阅

#### 2.4.4 退款系统

**需求描述**：用户申请退款，管理员审核后原路返回。

**功能规格**：
- 退款条件：订单支付7天内、未使用权益
- 退款流程：申请 → 风控检测 → 审核 → 打款 → 权益回收
- 风控规则：7项自动检测（高频退款、大额退款等）
- 审核模式：自动审批（低风险）+ 人工审批（高风险）
- 二审机制：大额退款需超级管理员二审

**参考文档**：
- [退款风控与边缘Case处理](../04_Modules/11_退款审核/退款风控与边缘Case处理.md)

#### 2.4.5 订单管理

**需求描述**：完整的订单生命周期管理，从创建到完成。

**功能规格**：
- 订单创建：选择商品 → 生成订单 → 待支付
- 订单支付：支持多种支付方式
- 订单状态：待支付、已支付、已取消、已退款
- 订单查询：用户查看自己的订单历史
- 管理员操作：查看所有订单、处理异常

**参考文档**：
- [订单管理系统](../04_Modules/08_订单管理/订单管理系统.md)

#### 2.4.6 商品管理

**需求描述**：管理可售卖的积分套餐和VIP会员商品。

**功能规格**：
- 商品CRUD：创建、编辑、上下架商品
- 商品类型：积分充值包、VIP订阅
- 价格策略：原价、折扣价、VIP专属价

### 2.6 权限管理模块

#### 2.6.1 RBAC权限体系

**需求描述**：基于角色的访问控制，精细化管理用户权限。

**功能规格**：
- 角色层级：USER → BASIC → PROFESSIONAL → PREMIUM → ENTERPRISE → ADMIN → SUPER_ADMIN
- 权限粒度：模块级 + 操作级（95个权限代码）
- 权限继承：子角色自动继承父角色权限
- 动态生效：修改权限无需重启

#### 2.6.2 审计日志

**需求描述**：记录所有敏感操作，支持追溯和合规审查。

**功能规格**：
- 记录内容：操作人、操作时间、IP地址、操作类型、操作对象
- 保留期限：默认1年
- 查询维度：时间、用户、操作类型、关键词

#### 2.6.3 角色权限管理

**需求描述**：可视化配置各角色的权限矩阵。

**功能规格**：
- 权限矩阵：表格形式展示角色×权限
- 批量配置：一次性分配多个权限
- 权限查询：查看某角色拥有的所有权限
- 权限校验：实时校验权限配置有效性

**参考文档**：
- [角色权限管理](../04_Modules/13_权限管理/角色权限管理.md)

## 4. 业务流程

### 4.1 核心业务流程图

```
用户注册 → 领取积分 → 创建项目 → 输入主题/上传文档
    ↓
AI生成大纲 → 用户编辑调整 → AI生成内容 → 用户确认
    ↓
AI生成图片 → 用户选择风格 → 批量生成 → 选择最终版本
    ↓
导出PPT → 项目归档（可选）
```

### 4.2 商业化业务流程

```
用户访问 → 选择商品（积分/VIP）→ 创建订单 → 支付（Mock/真实）
    ↓
支付成功 → 积分到账/VIP开通 → 发送通知 → 用户使用
    ↓
（可选）用户退款 → 申请 → 风控检测 → 审核 → 打款 → 权益回收
```
