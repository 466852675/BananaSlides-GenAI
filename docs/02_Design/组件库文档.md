## 1. 概述

YH-AI PPT 组件库是一套基于 React + TypeScript + Tailwind CSS 构建的业务组件库。

### 1.1 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| React | 19.2 | UI框架 |
| TypeScript | 5.9 | 类型系统 |
| Tailwind CSS | 4.1 | 样式方案 |
| Framer Motion | - | 动画 |
| Lucide React | - | 图标 |

### 1.2 目录结构

```
src/
├── components/           # 业务组件
│   ├── admin/          # 管理后台
│   ├── auth/           # 认证相关
│   ├── dashboard/      # 仪表盘
│   ├── landing/        # 落地页
│   ├── message/        # 消息
│   ├── outline/        # 大纲
│   ├── user/           # 用户相关
│   ├── workbench/      # 工作台
│   ├── ui/             # 基础UI组件
│   └── *.tsx           # 通用组件
├── hooks/              # 自定义Hooks
├── contexts/           # React Contexts
├── api/                # API客户端
├── types/              # 类型定义
└── utils/              # 工具函数
```

## 3. Hooks

### 3.1 业务Hooks

| Hook | 文件 | 功能 |
|------|------|------|
| usePermissions | hooks/usePermissions.ts | 权限查询 |
| useMessages | hooks/useMessages.ts | 消息管理 |
| useGenerationResume | hooks/useGenerationResume.ts | 生成恢复 |
| useToast | hooks/useToast.ts | Toast控制 |

### 3.2 使用示例

#### usePermissions

```typescript
const { hasPermission, isLoading } = usePermissions();

// 检查权限
if (hasPermission('admin.users.view')) {
    return <UserList />;
}
```

#### useMessages

```typescript
const { messages, markRead, isLoading } = useMessages({
    type: 'ORDER',
    isRead: false
});

// 获取未读消息
const unreadMessages = messages?.filter(m => !m.isRead) || [];
```

## 5. API客户端

### 5.1 API结构

```
src/api/
├── client.ts           # 基础客户端
├── auth.ts             # 认证API
├── projects.ts         # 项目API
├── ai.ts               # AI生成API
├── orders.ts           # 订单API
├── points.ts           # 积分API
├── messages.ts         # 消息API
└── admin.ts            # 管理API
```

### 5.2 使用示例

```typescript
import { projectsApi } from '@/api/projects';

// 获取项目列表
const { data, isLoading } = useQuery({
    queryKey: ['projects'],
    queryFn: () => projectsApi.list({ status: 'active' })
});

// 创建项目
const mutation = useMutation({
    mutationFn: (data) => projectsApi.create(data),
    onSuccess: () => {
        toast.success('创建成功');
    }
});
```

## 8. 开发规范

### 8.1 组件规范

```typescript
// 1. 使用函数式组件
const MyComponent: React.FC<Props> = ({ title, onClick }) => {
    return (
        <div onClick={onClick}>
            {title}
        </div>
    );
};

// 2. 定义Props接口
interface Props {
    title: string;
    onClick?: () => void;
}

// 3. 导出默认
export default MyComponent;
```

### 8.2 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 组件文件 | PascalCase | UserModal.tsx |
| Hooks | camelCase + use前缀 | usePermissions.ts |
| 类型/接口 | PascalCase | UserInfo |
| 常量 | UPPER_SNAKE_CASE | MAX_FILE_SIZE |
