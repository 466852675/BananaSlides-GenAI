## 1. 概述

本文档详细描述 YH-AI PPT 系统的完整数据架构，包含所有 31 个数据模型、8 个枚举类型、以及完整的索引设计。相比 v2.0 版本，本文档新增了 Agent 对话模式模块的数据模型。

> **与PRD v2.1对齐**: 本文档的31个实体与《产品需求规格 v2.1》第5章数据模型完全一致。

### 1.1 数据库选型

- **数据库**: SQLite 3
- **ORM**: Prisma 6.19
- **文件位置**: `server/prisma/dev.db`（开发）/ `prod.db`（生产）
- **备份策略**: 每日凌晨自动备份到 `backups/` 目录

## 2. 用户系统模块

### 2.1 User（用户表）

核心用户账户表，存储所有用户的基础信息、积分、VIP状态等。

```prisma
model User {
  id                 String          @id @default(uuid())
  email              String?         @unique
  phone              String?         @unique
  username           String?         @unique
  passwordHash       String?
  nickname           String?
  avatar             String?
  bio                String?
  role               UserRole        @default(USER)
  status             UserStatus      @default(ACTIVE)
  points             Int             @default(30)
  pointsUsed         Int             @default(0)
  vipLevel           Int             @default(0)
  vipExpiresAt       DateTime?
  lastLoginAt        DateTime?
  lastLoginIp        String?
  loginFailCount     Int             @default(0)
  lockedUntil        DateTime?
  resetCode          String?
  resetCodeExp       DateTime?
  inviteCode         String?         @unique
  invitedById        String?
  checkInDate        DateTime?
  checkInStreak      Int             @default(0)
  riskScore          Int             @default(0)
  createdAt          DateTime        @default(now())
  updatedAt          DateTime        @updatedAt
  
  // 关联关系
  checkInLogs        CheckInLog[]
  favorites          Favorite[]
  leads              Lead[]
  orders             Order[]
  createdPointsRules PointsRule[]    @relation("RuleCreator")
  createdProducts    Product[]       @relation("ProductCreator")
  projects           Project[]
  socialAccounts     SocialAccount[]
  styleTemplates     StyleTemplate[]
  transactions       Transaction[]
  invitedBy          User?           @relation("Referrals", fields: [invitedById], references: [id])
  referrals          User[]          @relation("Referrals")
  refundRequests     RefundRequest[]
  refundStats        UserRefundStats?
  messages           UserMessage[]
  messageSettings    UserMessageSettings?
  assignedLeads      Lead[]          @relation("LeadAssignee")
  handledMessages    UserMessage[]   @relation("MessageHandler")

  @@index([role])
  @@index([status])
  @@index([createdAt])
}
```

**字段说明：**

| 字段 | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| id | String | uuid | 主键，UUID v4 |
| email | String? | null | 邮箱，唯一约束 |
| phone | String? | null | 手机号，唯一约束 |
| username | String? | null | 用户名，唯一约束 |
| passwordHash | String? | null | bcrypt 加密后的密码 |
| nickname | String? | null | 用户昵称 |
| avatar | String? | null | 头像 URL |
| bio | String? | null | 个人简介 |
| role | UserRole | USER | 用户角色（7级）|
| status | UserStatus | ACTIVE | 账户状态 |
| points | Int | 30 | 当前积分余额 |
| pointsUsed | Int | 0 | 累计消耗积分 |
| vipLevel | Int | 0 | VIP等级（0-10）|
| vipExpiresAt | DateTime? | null | VIP过期时间 |
| lastLoginAt | DateTime? | null | 最后登录时间 |
| lastLoginIp | String? | null | 最后登录IP |
| loginFailCount | Int | 0 | 登录失败次数（风控）|
| lockedUntil | DateTime? | null | 账户锁定至（风控）|
| resetCode | String? | null | 密码重置验证码 |
| resetCodeExp | DateTime? | null | 重置码过期时间 |
| inviteCode | String? | null | 邀请码，唯一 |
| invitedById | String? | null | 邀请人ID |
| checkInDate | DateTime? | null | 最后签到日期 |
| checkInStreak | Int | 0 | 连续签到天数 |
| riskScore | Int | 0 | 风险评分（0-100）|

**索引设计：**
- `role`: 按角色查询（管理员列表）
- `status`: 按状态查询（活跃用户统计）
- `createdAt`: 按注册时间排序

### 3.2 Order（订单表）

用户购买商品的订单记录。

```prisma
model Order {
  id            String      @id @default(uuid())
  orderNo       String      @unique
  userId        String
  productType   String
  productName   String
  productDesc   String?
  quantity      Int         @default(1)
  originalPrice Float
  discountPrice Float?
  finalPrice    Float
  status        OrderStatus @default(PENDING)
  paymentMethod String?
  paymentNo     String?
  paidAt        DateTime?
  refundReason  String?
  refundedAt    DateTime?
  createdAt     DateTime    @default(now())
  updatedAt     DateTime    @updatedAt
  fulfillmentAt DateTime?
  productId     String?
  beforeVipLevel Int?
  afterVipLevel  Int?
  user          User        @relation(fields: [userId], references: [id], onDelete: Cascade)
  refundRequests RefundRequest[]

  @@index([userId])
  @@index([status])
  @@index([createdAt])
}
```

**字段说明：**

| 字段 | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| orderNo | String | - | 订单编号（唯一）|
| productType | String | - | 商品类型 |
| productName | String | - | 商品名称（快照）|
| originalPrice | Float | - | 原价 |
| discountPrice | Float? | null | 折扣价 |
| finalPrice | Float | - | 实付金额 |
| status | OrderStatus | PENDING | 订单状态 |
| paymentMethod | String? | null | 支付方式（alipay/wechat）|
| paymentNo | String? | null | 第三方支付流水号 |
| paidAt | DateTime? | null | 支付时间 |
| fulfillmentAt | DateTime? | null | 订单完成时间（积分到账）|
| beforeVipLevel | Int? | null | 购买前VIP等级 |
| afterVipLevel | Int? | null | 购买后VIP等级 |

**订单状态流转：**
```
PENDING → PAID → (fulfillOrder) → COMPLETED
   ↓         ↓
CANCELLED   REFUNDED
```

## 10. 退款管理模块

### 10.1 RefundRequest（退款申请表）

退款申请主表。

```prisma
model RefundRequest {
  id                String       @id @default(uuid())
  refundNo          String       @unique
  userId            String
  orderId           String
  amount            Float
  status            RefundStatus @default(PENDING)
  reason            String
  description       String?
  remark            String?
  processedAt       DateTime?
  completedAt       DateTime?
  processedBy       String?
  secondApprovedBy  String?
  failReason        String?
  exceptionType     String?
  requireManualAt   DateTime?
  transactionId     String?
  createdAt         DateTime     @default(now())

  user              User         @relation(fields: [userId], references: [id])
  order             Order        @relation(fields: [orderId], references: [id])

  @@index([userId])
  @@index([orderId])
  @@index([status])
  @@index([createdAt])

```

**退款状态（RefundStatus）：**
- PENDING: 待审核

- REJECTED: 已拒绝

## 11. Agent 模式模块

Agent 对话模式的数据模型，支持自然语言驱动的 PPT 生成。

### 11.1 AgentSession（Agent 会话表）

Agent 会话主表，绑定单个项目，记录对话状态和执行进度。

```prisma
model AgentSession {
  id              String             @id @default(cuid())
  projectId       String             @unique
  status          AgentSessionStatus @default(ACTIVE)
  mode            AgentMode          @default(GUIDED)
  isDeleted       Boolean            @default(false)
  deletedAt       DateTime?
  context         String?
  totalTasks      Int                @default(0)
  completedTasks  Int                @default(0)
  failedTasks     Int                @default(0)
  totalPointsUsed Int                @default(0)
  createdAt       DateTime           @default(now())
  updatedAt       DateTime           @updatedAt
  completedAt     DateTime?
  messages        AgentMessage[]
  tasks           AgentTask[]
  project         Project            @relation(fields: [projectId], references: [id], onDelete: Cascade)

  @@index([projectId])
  @@index([status])
  @@index([createdAt])
  @@index([status, createdAt])
  @@index([isDeleted])
}
```

**字段说明：**

| 字段 | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| id | String | cuid | 主键 |
| projectId | String | - | 关联的项目ID（一对一） |
| status | AgentSessionStatus | ACTIVE | 会话状态 |
| mode | AgentMode | GUIDED | 执行模式（引导/自动） |
| context | String? | null | 会话上下文（JSON） |
| totalTasks | Int | 0 | 总任务数 |
| completedTasks | Int | 0 | 已完成任务数 |
| failedTasks | Int | 0 | 失败任务数 |
| totalPointsUsed | Int | 0 | 累计消耗积分 |

**会话状态（AgentSessionStatus）：**
- ACTIVE: 活跃
- PAUSED: 已暂停
- COMPLETED: 已完成
- CANCELLED: 已取消
- FAILED: 失败

**执行模式（AgentMode）：**
- GUIDED: 引导模式（每步需确认）
- AUTO: 自动模式（自动执行）

### 11.2 AgentMessage（Agent 消息表）

对话消息记录，存储用户和 AI 的交互历史。

```prisma
model AgentMessage {
  id        String       @id @default(cuid())
  sessionId String
  role      String
  content   String
  toolCalls String?
  metadata  String?
  isEdited  Boolean      @default(false)
  editedAt  DateTime?
  isDeleted Boolean      @default(false)
  createdAt DateTime     @default(now())
  session   AgentSession @relation(fields: [sessionId], references: [id], onDelete: Cascade)

  @@index([sessionId])
  @@index([createdAt])
  @@index([role])
  @@index([sessionId, createdAt])
}
```

**字段说明：**

| 字段 | 类型 | 说明 |
|-----|------|------|
| role | String | 消息角色（USER/ASSISTANT/SYSTEM） |
| content | String | 消息内容 |
| toolCalls | String? | Function Calling 结果（JSON） |
| metadata | String? | 附加元数据（JSON） |
| isEdited | Boolean | 是否被编辑过 |
| isDeleted | Boolean | 是否被删除（软删除） |

### 11.3 AgentTask（Agent 任务表）

任务队列，记录 AI 执行的具体任务。

```prisma
model AgentTask {
  id          String          @id @default(cuid())
  sessionId   String
  type        AgentTaskType
  status      AgentTaskStatus @default(PENDING)
  priority    Int             @default(0)
  params      String?
  result      String?
  progress    Int             @default(0)
  error       String?
  retryCount  Int             @default(0)
  pointsCost  Int?
  startedAt   DateTime?
  completedAt DateTime?
  createdAt   DateTime        @default(now())
  updatedAt   DateTime        @updatedAt
  session     AgentSession    @relation(fields: [sessionId], references: [id], onDelete: Cascade)

  @@index([sessionId])
  @@index([status])
  @@index([type])
  @@index([priority])
  @@index([createdAt])
  @@index([sessionId, status])
  @@index([status, priority])
}
```

**字段说明：**

| 字段 | 类型 | 说明 |
|-----|------|------|
| type | AgentTaskType | 任务类型 |
| status | AgentTaskStatus | 任务状态 |
| priority | Int | 优先级（数值越大越优先） |
| params | String? | 任务参数（JSON） |
| result | String? | 执行结果（JSON） |
| progress | Int | 进度百分比（0-100） |
| pointsCost | Int? | 消耗积分 |

**任务类型（AgentTaskType）：**
- CONFIG_CONFIRM: 配置确认
- OUTLINE: 大纲生成
- CONTENT: 内容生成
- IMAGE: 配图生成

**任务状态（AgentTaskStatus）：**
- PENDING: 待处理
- RUNNING: 执行中
- COMPLETED: 已完成
- FAILED: 失败
- CANCELLED: 已取消

## 15. 数据迁移指南

### 15.1 开发环境初始化

```bash
cd server
npx prisma db push
npm run db:seed
```

### 15.2 生产环境迁移

```bash
# 备份现有数据库
cp prisma/prod.db backups/prod_$(date +%Y%m%d_%H%M%S).db

# 执行迁移
npx prisma migrate deploy

# 验证数据完整性
npx prisma validate
```

### 15.3 常见迁移场景

**场景1：新增字段**
```prisma
// 1. 在 schema.prisma 中添加字段
model User {
  newField String?  // 新增字段使用 ? 标记为可选
}

// 2. 生成迁移
npx prisma migrate dev --name add_user_new_field
```

**场景2：创建新表**
```bash
# 1. 在 schema.prisma 中定义模型
# 2. 生成迁移
npx prisma migrate dev --name create_new_table

# 3. 创建对应的 seed 数据（如需）
```
