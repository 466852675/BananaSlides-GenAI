# 上传文件管理

## 概述

上传文件管理模块负责处理用户上传的参考图片、文档等文件，提供完整的文件存储、访问控制和安全管理服务。系统支持多类型文件上传，包括图片、PDF、Word文档和文本文件，用于PPT生成中的参考图、内容导入等场景。

## 核心功能

| 功能 | 说明 | 技术实现 |
|------|------|----------|
| 单文件上传 | 支持表单选择文件上传 | Multer中间件 |
| 文件类型校验 | MIME类型和扩展名双重校验 | 白名单机制 |
| 文件大小限制 | 最大50MB单文件限制 | Multer limits配置 |
| 文件名生成 | 时间戳+随机数唯一命名 | 防重名覆盖 |
| 静态访问服务 | 通过URL访问上传文件 | Express静态中间件 |
| 错误处理 | 详细的错误码和提示 | 自定义错误响应 |

## 支持格式

### 图片格式

| 格式 | MIME类型 | 扩展名 | 用途 |
|------|----------|--------|------|
| PNG | image/png | .png | 风格参考图、背景图 |
| JPEG | image/jpeg | .jpg, .jpeg | 照片素材 |
| WebP | image/webp | .webp | 现代浏览器优化 |

### 文档格式

| 格式 | MIME类型 | 扩展名 | 用途 |
|------|----------|--------|------|
| PDF | application/pdf | .pdf | MinerU文档解析 |
| Word | application/vnd.openxmlformats-officedocument.wordprocessingml.document | .docx | 内容导入 |
| Text | text/plain | .txt | 纯文本导入 |

## 技术架构

```
用户选择文件
    ↓
前端 FormData 封装
    ↓
POST /api/upload
    ↓
Multer 中间件处理
    ├── 文件类型校验 (MIME + 扩展名)
    ├── 文件大小校验 (≤50MB)
    └── 文件存储到 /uploads/
    ↓
返回文件访问 URL
    ↓
通过 /uploads/:filename 访问
```

## 核心实现

### Multer 配置

```typescript
// server/src/middlewares/upload.ts

import multer from 'multer';
import path from 'path';
import fs from 'fs';

// 确保上传目录存在
const uploadDir = path.join(process.cwd(), 'uploads');
if (!fs.existsSync(uploadDir)) {
    fs.mkdirSync(uploadDir, { recursive: true });
}

// 磁盘存储配置
const storage = multer.diskStorage({
    destination: function (req, file, cb) {
        cb(null, uploadDir);
    },
    filename: function (req, file, cb) {
        // 唯一文件名: 时间戳 + 随机数 + 扩展名
        const uniqueSuffix = Date.now() + '-' + Math.round(Math.random() * 1E9);
        const ext = path.extname(file.originalname) || '.png';
        cb(null, 'up-' + uniqueSuffix + ext);
    }
});

// 允许的 MIME 类型
const allowedMimeTypes = new Set([
    'image/png',
    'image/jpeg',
    'image/webp',
    'application/pdf',
    'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
    'text/plain'
]);

// 允许的扩展名
const allowedExt = new Set(['.png', '.jpg', '.jpeg', '.webp', '.pdf', '.docx', '.txt']);

// 文件过滤器
const fileFilter: multer.Options['fileFilter'] = (_req, file, cb) => {
    // 1. MIME 类型校验
    if (!allowedMimeTypes.has(file.mimetype)) {
        cb(new Error('UNSUPPORTED_FILE_TYPE'));
        return;
    }
    
    // 2. 扩展名校验
    const ext = (path.extname(file.originalname) || '').toLowerCase();
    if (ext && !allowedExt.has(ext)) {
        cb(new Error('UNSUPPORTED_FILE_EXTENSION'));
        return;
    }
    
    cb(null, true);
};

// 导出配置好的 Multer 中间件
export const uploadMiddleware = multer({
    storage,
    fileFilter,
    limits: {
        fileSize: 50 * 1024 * 1024  // 50MB
    }
});
```

### 路由配置

```typescript
// server/src/routes/upload.routes.ts

import { Router } from 'express';
import { uploadMiddleware } from '../middlewares/upload';
import { handleUpload } from '../controllers/upload.controller';
import { uploadLimiter } from '../middleware/rateLimitMiddleware';

const router = Router();

// POST /api/upload
router.post(
    '/',
    uploadLimiter,  // 上传频率限制
    (req, res, next) => {
        uploadMiddleware.single('file')(req, res, (err: any) => {
            if (err) {
                res.status(400).json({ 
                    success: false, 
                    error: err.message || 'UPLOAD_FAILED' 
                });
                return;
            }
            next();
        });
    },
    handleUpload
);

export default router;
```

### 上传控制器

```typescript
// server/src/controllers/upload.controller.ts

import { Request, Response } from 'express';

export const handleUpload = (req: Request, res: Response): void => {
    if (!req.file) {
        res.status(400).json({ 
            success: false, 
            message: 'No file uploaded' 
        });
        return;
    }
    
    // 返回相对 URL，可通过静态服务访问
    const url = `/uploads/${req.file.filename}`;
    
    // 返回完整的文件信息
    res.json({
        url,
        filename: req.file.filename,
        mimetype: req.file.mimetype,
        size: req.file.size,
        originalname: req.file.originalname
    });
};
```

### 频率限制配置

```typescript
// server/src/middleware/rateLimitMiddleware.ts

import rateLimit from 'express-rate-limit';

// 上传接口限流：每15分钟最多10次上传
export const uploadLimiter = rateLimit({
    windowMs: 15 * 60 * 1000,  // 15分钟
    max: 10,  // 最大请求数
    message: {
        success: false,
        error: 'UPLOAD_RATE_LIMIT_EXCEEDED',
        message: '上传过于频繁，请稍后再试'
    },
    standardHeaders: true,
    legacyHeaders: false
});
```

## API 接口规范

### 上传文件

```
POST /api/upload
Content-Type: multipart/form-data
```

**请求参数：**
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | File | 是 | 要上传的文件 |

**成功响应：**
```json
{
  "success": true,
  "url": "/uploads/up-1676503200000-1234567890.png",
  "filename": "up-1676503200000-1234567890.png",
  "mimetype": "image/png",
  "size": 2048576,
  "originalname": "reference-design.png"
}
```

**错误响应：**
```json
{
  "success": false,
  "error": "UNSUPPORTED_FILE_TYPE",
  "message": "不支持的文件类型"
}
```

```json
{
  "success": false,
  "error": "UPLOAD_RATE_LIMIT_EXCEEDED",
  "message": "上传过于频繁，请稍后再试"
}
```

### 访问文件

上传的文件通过静态文件服务访问：

```
GET /uploads/:filename
```

**示例：**
```
GET /uploads/up-1676503200000-1234567890.png
```

返回文件内容，支持浏览器直接显示。

## 前端组件设计

### 文件上传组件

```tsx
// UploadButton.tsx
import React, { useRef, useState } from 'react';
import { Upload, Loader2, X, FileImage, FileText } from 'lucide-react';
import { toast } from 'react-hot-toast';

interface UploadButtonProps {
  onUpload: (url: string) => void;
  accept?: string;
  maxSize?: number;  // MB
}

export const UploadButton: React.FC<UploadButtonProps> = ({
  onUpload,
  accept = 'image/*,.pdf,.docx',
  maxSize = 50
}) => {
  const inputRef = useRef<HTMLInputElement>(null);
  const [uploading, setUploading] = useState(false);
  const [preview, setPreview] = useState<string | null>(null);

  const handleFileSelect = async (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0];
    if (!file) return;

    // 文件大小校验
    if (file.size > maxSize * 1024 * 1024) {
      toast.error(`文件大小不能超过 ${maxSize}MB`);
      return;
    }

    // 创建本地预览
    if (file.type.startsWith('image/')) {
      const reader = new FileReader();
      reader.onload = (e) => setPreview(e.target?.result as string);
      reader.readAsDataURL(file);
    }

    setUploading(true);

    try {
      const formData = new FormData();
      formData.append('file', file);

      const response = await fetch('/api/upload', {
        method: 'POST',
        body: formData
      });

      const data = await response.json();

      if (data.success) {
        onUpload(data.url);
        toast.success('上传成功');
      } else {
        toast.error(data.message || '上传失败');
      }
    } catch (error) {
      toast.error('网络错误，请重试');
    } finally {
      setUploading(false);
    }
  };

  const clearPreview = () => {
    setPreview(null);
    if (inputRef.current) {
      inputRef.current.value = '';
    }
  };

  return (
    <div className="relative">
      {preview ? (
        <div className="relative group">
          <img
            src={preview}
            alt="Preview"
            className="w-full h-48 object-cover rounded-lg"
          />
          <button
            onClick={clearPreview}
            className="absolute top-2 right-2 p-1 bg-red-500 text-white rounded-full opacity-0 group-hover:opacity-100 transition-opacity"
          >
            <X className="w-4 h-4" />
          </button>
        </div>
      ) : (
        <button
          onClick={() => inputRef.current?.click()}
          disabled={uploading}
          className="w-full h-48 border-2 border-dashed border-gray-300 rounded-lg flex flex-col items-center justify-center gap-2 hover:border-blue-500 hover:bg-blue-50 transition-colors disabled:opacity-50"
        >
          {uploading ? (
            <>
              <Loader2 className="w-8 h-8 text-blue-500 animate-spin" />
              <span className="text-sm text-gray-500">上传中...</span>
            </>
          ) : (
            <>
              <Upload className="w-8 h-8 text-gray-400" />
              <span className="text-sm text-gray-500">点击或拖拽上传</span>
              <span className="text-xs text-gray-400">
                支持 PNG, JPG, PDF 等格式，最大 {maxSize}MB
              </span>
            </>
          )}
        </button>
      )}
      <input
        ref={inputRef}
        type="file"
        accept={accept}
        onChange={handleFileSelect}
        className="hidden"
      />
    </div>
  );
};
```

### 拖拽上传组件

```tsx
// DragDropUpload.tsx
import React, { useState, useCallback } from 'react';

interface DragDropUploadProps {
  onUpload: (files: FileList) => void;
  accept?: string;
  multiple?: boolean;
}

export const DragDropUpload: React.FC<DragDropUploadProps> = ({
  onUpload,
  accept = 'image/*',
  multiple = false
}) => {
  const [isDragOver, setIsDragOver] = useState(false);

  const handleDragOver = useCallback((e: React.DragEvent) => {
    e.preventDefault();
    setIsDragOver(true);
  }, []);

  const handleDragLeave = useCallback((e: React.DragEvent) => {
    e.preventDefault();
    setIsDragOver(false);
  }, []);

  const handleDrop = useCallback((e: React.DragEvent) => {
    e.preventDefault();
    setIsDragOver(false);
    
    const files = e.dataTransfer.files;
    if (files.length > 0) {
      onUpload(files);
    }
  }, [onUpload]);

  return (
    <div
      onDragOver={handleDragOver}
      onDragLeave={handleDragLeave}
      onDrop={handleDrop}
      className={`w-full p-8 border-2 border-dashed rounded-lg text-center transition-colors ${
        isDragOver
          ? 'border-blue-500 bg-blue-50'
          : 'border-gray-300 hover:border-gray-400'
      }`}
    >
      <p className="text-gray-600">
        拖拽文件到此处，或 <span className="text-blue-500">点击上传</span>
      </p>
      <p className="text-sm text-gray-400 mt-2">
        支持 {accept} 格式
      </p>
    </div>
  );
};
```

## 安全考虑

### 文件类型安全

1. **双重校验**：同时使用 MIME 类型和文件扩展名校验
2. **白名单机制**：只允许已知安全的文件类型
3. **禁止可执行文件**：不允许上传 .exe, .js, .php 等可执行文件

### 文件名安全

1. **重命名**：所有上传文件自动重命名，防止特殊字符和路径遍历
2. **随机命名**：使用时间戳+随机数生成唯一文件名
3. **去除原始扩展名风险**：只保留白名单内的扩展名

### 访问控制

1. **速率限制**：每IP每15分钟最多10次上传
2. **文件大小限制**：单文件最大50MB
3. **路径隔离**：上传文件存放在独立的 uploads 目录

## 错误码规范

| 错误码 | HTTP状态 | 说明 | 处理建议 |
|--------|----------|------|----------|
| UNSUPPORTED_FILE_TYPE | 400 | 不支持的MIME类型 | 检查文件格式是否符合要求 |
| UNSUPPORTED_FILE_EXTENSION | 400 | 不支持的扩展名 | 使用支持的文件格式 |
| UPLOAD_RATE_LIMIT_EXCEEDED | 429 | 上传过于频繁 | 等待一段时间后重试 |
| FILE_TOO_LARGE | 413 | 文件过大 | 压缩文件或使用更小的文件 |
| UPLOAD_FAILED | 500 | 服务器上传错误 | 联系管理员 |
