# 产品管理系统

## 概述

产品管理系统是 YH-AI PPT **商业化核心模块**，负责管理平台销售的虚拟商品，包括积分套餐、VIP会员、组合套餐等。系统支持**限时折扣**、**VIP等级关联**、**自定义标签**等营销功能，为运营团队提供灵活的商品配置能力。

## 核心功能特性

| 功能特性 | 说明 | 技术实现 |
|---------|------|---------|
| 商品CRUD | 创建、查询、更新、删除商品 | RESTful API |
| 商品类型 | 积分包/VIP会员/组合套餐 | `type`字段区分 |
| 限时折扣 | 设置折扣结束时间 | `discountEnd`字段 |
| VIP等级关联 | 购买后自动升级VIP | `roleToGrant`字段 |
| 商品排序 | 自定义展示顺序 | `sortOrder`字段 |
| 上下架控制 | 启用/禁用商品 | `isActive`字段 |
| 有效期设置 | 设置商品生效时间 | `effectiveAt`字段 |

## 数据库模型

### 1. 商品表 (Product)

```prisma
model Product {
  id            String    @id @default(uuid())
  type          String                      // 商品类型: 'points' | 'vip' | 'combo'
  name          String                      // 商品名称
  
  // 价格配置
  originalPrice Float?                      // 原价（用于展示折扣）
  price         Float                       // 实际售价
  
  // 权益配置
  points        Int                         // 包含积分数量
  features      String?                     // 权益说明（JSON数组）
  roleToGrant   String?                     // 授予的角色: BASIC/PROFESSIONAL/PREMIUM/ENTERPRISE
  
  // 展示配置
  tags          String?                     // 标签（JSON数组，如["热卖","限时"]）
  displayType   String    @default("public") // 展示类型: public/member/hidden
  desc          String?                     // 商品详细描述
  
  // 有效期配置
  period        String    @default("once")  // 有效期: once/monthly/yearly/permanent
  discountEnd   DateTime?                   // 折扣结束时间
  effectiveAt   DateTime  @default(now())   // 生效时间
  
  // 状态控制
  isActive      Boolean   @default(true)   // 是否上架
  sortOrder     Int       @default(0)      // 排序权重（越小越靠前）
  
  // 关联
  createdById   String?
  createdBy     User?     @relation("ProductCreator", fields: [createdById], references: [id])
  
  createdAt     DateTime  @default(now())
  updatedAt     DateTime  @updatedAt
  
  @@index([type])
  @@index([isActive])
  @@index([sortOrder])
}
```

## 核心算法实现

### 1. 商品列表查询

```typescript
// server/src/services/product.service.ts

export async function getProductList(
  options: {
    type?: string;
    isActive?: boolean;
    page?: number;
    limit?: number;
  }
): Promise<{ items: Product[]; total: number }> {
  const { type, isActive = true, page = 1, limit = 20 } = options;
  
  const where: any = { isActive };
  if (type) where.type = type;
  
  const [items, total] = await Promise.all([
    prisma.product.findMany({
      where,
      orderBy: [
        { sortOrder: 'asc' },   // 按排序权重
        { createdAt: 'desc' }   // 新创建在前
      ],
      skip: (page - 1) * limit,
      take: limit
    }),
    prisma.product.count({ where })
  ]);
  
  return { items, total };
}
```

### 2. 检查折扣状态

```typescript
export function isProductOnDiscount(product: Product): {
  isDiscount: boolean;
  discountPercent?: number;
  remainingTime?: number;  // 剩余时间（秒）
} {
  // 没有原价或不等于实际价格，视为折扣
  if (!product.originalPrice || product.originalPrice <= product.price) {
    return { isDiscount: false };
  }
  
  // 检查折扣是否过期
  if (product.discountEnd && product.discountEnd < new Date()) {
    return { isDiscount: false };
  }
  
  const discountPercent = Math.round(
    ((product.originalPrice - product.price) / product.originalPrice) * 100
  );
  
  const remainingTime = product.discountEnd
    ? Math.floor((product.discountEnd.getTime() - Date.now()) / 1000)
    : undefined;
  
  return {
    isDiscount: true,
    discountPercent,
    remainingTime
  };
}
```

### 3. 创建商品

```typescript
export async function createProduct(
  adminId: string,
  data: {
    type: string;
    name: string;
    price: number;
    originalPrice?: number;
    points?: number;
    roleToGrant?: string;
    period?: string;
    features?: string[];
    tags?: string[];
    desc?: string;
    discountEnd?: Date;
    sortOrder?: number;
  }
): Promise<Product> {
  // 验证必填字段
  if (!data.name || !data.price) {
    throw new Error('商品名称和价格不能为空');
  }
  
  // VIP商品必须指定roleToGrant
  if (data.type === 'vip' && !data.roleToGrant) {
    throw new Error('VIP商品必须指定授予的角色');
  }
  
  const product = await prisma.product.create({
    data: {
      type: data.type,
      name: data.name,
      price: data.price,
      originalPrice: data.originalPrice,
      points: data.points || 0,
      roleToGrant: data.roleToGrant,
      period: data.period || 'once',
      features: data.features ? JSON.stringify(data.features) : null,
      tags: data.tags ? JSON.stringify(data.tags) : null,
      desc: data.desc,
      discountEnd: data.discountEnd,
      sortOrder: data.sortOrder || 0,
      createdById: adminId
    }
  });
  
  return product;
}
```

## API 接口

### 获取商品列表（用户端）

**Endpoint:** `GET /api/products?type=points&page=1&limit=10`

**Query Parameters:**
- `type`: 商品类型过滤 (points/vip/combo)
- `page`: 页码
- `limit`: 每页数量

**Response:**
```typescript
{
  success: true;
  data: {
    items: Array<{
      id: string;
      type: string;
      name: string;
      originalPrice?: number;
      price: number;
      points: number;
      features: string[];  // 已解析的JSON数组
      tags?: string[];     // 已解析的JSON数组
      roleToGrant?: string;
      period: string;
      discountInfo: {
        isDiscount: boolean;
        discountPercent?: number;
        remainingTime?: number;
      };
      desc?: string;
    }>;
    pagination: {
      page: number;
      limit: number;
      total: number;
      totalPages: number;
    }
  }
}
```

### 获取商品详情

**Endpoint:** `GET /api/products/:id`

### 创建商品（管理端）

**Endpoint:** `POST /api/admin/products`

**Request Body:**
```typescript
{
  type: 'points' | 'vip' | 'combo';
  name: string;
  price: number;
  originalPrice?: number;
  points?: number;
  roleToGrant?: 'BASIC' | 'PROFESSIONAL' | 'PREMIUM' | 'ENTERPRISE';
  period?: 'once' | 'monthly' | 'yearly' | 'permanent';
  features?: string[];      // 权益说明列表
  tags?: string[];          // 标签列表
  desc?: string;            // 详细描述
  discountEnd?: string;     // ISO日期格式
  sortOrder?: number;
}
```

### 更新商品

**Endpoint:** `PATCH /api/admin/products/:id`

**Request Body:** 同创建接口（字段可选）

### 删除/下架商品

**Endpoint:** `DELETE /api/admin/products/:id`

**说明:** 软删除，设置`isActive=false`

### 1. 商品卡片组件

```typescript
// src/components/ProductCard.tsx

import { useMemo } from 'react';

interface ProductCardProps {
  product: {
    id: string;
    name: string;
    originalPrice?: number;
    price: number;
    points: number;
    features: string[];
    tags?: string[];
    discountInfo: {
      isDiscount: boolean;
      discountPercent?: number;
      remainingTime?: number;
    };
  };
  onPurchase: (id: string) => void;
}

export const ProductCard: React.FC<ProductCardProps> = ({
  product,
  onPurchase
}) => {
  const formatTime = (seconds?: number) => {
    if (!seconds) return '';
    const hours = Math.floor(seconds / 3600);
    const mins = Math.floor((seconds % 3600) / 60);
    return `${hours}小时${mins}分`;
  };
  
  return (
    <div className="product-card">
      {/* 标签 */}
      {product.tags?.map(tag => (
        <span key={tag} className={`tag tag-${tag}`}>{tag}</span>
      ))}
      
      <h3>{product.name}</h3>
      
      {/* 价格 */}
      <div className="price-section">
        {product.discountInfo.isDiscount && (
          <>
            <span className="original-price">¥{product.originalPrice}</span>
            <span className="discount-badge">
              -{product.discountInfo.discountPercent}%
            </span>
          </>
        )}
        <span className="current-price">¥{product.price}</span>
      </div>
      
      {/* 倒计时 */}
      {product.discountInfo.remainingTime && (
        <div className="countdown">
          限时优惠还剩: {formatTime(product.discountInfo.remainingTime)}
        </div>
      )}
      
      {/* 权益列表 */}
      <ul className="features">
        {product.features.map((feature, i) => (
          <li key={i}>{feature}</li>
        ))}
        {product.points > 0 && (
          <li>赠送 {product.points} 积分</li>
        )}
      </ul>
      
      <button onClick={() => onPurchase(product.id)}>
        立即购买
      </button>
    </div>
  );
};
```

### 2. 商品管理后台表格

```typescript
// src/components/admin/ProductManagement.tsx

import { useState } from 'react';
import { useQuery, useMutation } from '@tanstack/react-query';

export const ProductManagement: React.FC = () => {
  const [editingProduct, setEditingProduct] = useState<Product | null>(null);
  
  const { data: products } = useQuery({
    queryKey: ['admin', 'products'],
    queryFn: async () => {
      const res = await fetch('/api/admin/products?limit=100');
      return res.json();
    }
  });
  
  const toggleStatus = useMutation({
    mutationFn: async ({ id, isActive }: { id: string; isActive: boolean }) => {
      const res = await fetch(`/api/admin/products/${id}`, {
        method: 'PATCH',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ isActive })
      });
      return res.json();
    }
  });
  
  return (
    <div className="product-management">
      <button onClick={() => setEditingProduct({} as Product)}>
        + 新建商品
      </button>
      
      <table>
        <thead>
          <tr>
            <th>排序</th>
            <th>名称</th>
            <th>类型</th>
            <th>价格</th>
            <th>状态</th>
            <th>操作</th>
          </tr>
        </thead>
        <tbody>
          {products?.data?.items.map(product => (
            <tr key={product.id}>
              <td>{product.sortOrder}</td>
              <td>{product.name}</td>
              <td>{product.type}</td>
              <td>
                {product.originalPrice && (
                  <span className="original">¥{product.originalPrice}</span>
                )}
                <span className="price">¥{product.price}</span>
              </td>
              <td>
                <switch
                  checked={product.isActive}
                  onChange={(checked) => 
                    toggleStatus.mutate({ id: product.id, isActive: checked })
                  }
                />
              </td>
              <td>
                <button onClick={() => setEditingProduct(product)}>
                  编辑
                </button>
              </td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
};
```
