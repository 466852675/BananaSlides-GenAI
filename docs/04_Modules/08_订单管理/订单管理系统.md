# 订单管理系统

## 概述

订单管理系统是 YH-AI PPT **商业化核心模块**，处理用户购买流程、支付对接、权益发放和订单生命周期管理。系统采用**双层状态机**设计，支持Mock支付和真实支付渠道(支付宝/微信支付)。

## 核心功能特性

| 功能特性 | 说明 | 技术亮点 |
|---------|------|---------|
| 订单创建 | 根据商品生成待支付订单 | 库存预占、防重复提交 |
| 支付对接 | 支持Mock/支付宝/微信支付 | 统一支付网关、渠道适配器 |
| 权益发放 | 支付成功后自动发放商品 | 事务保证、失败回滚 |
| 订单管理 | 查询、取消、退款 | 状态机驱动、幂等设计 |
| 订单统计 | 收入分析、商品销量 | 聚合查询、数据看板 |
| 防重复支付 | 同一订单防止重复扣款 | 幂等Token、状态锁 |

## 数据库模型

### 1. 订单主表 (Order)

```prisma
model Order {
  id              String      @id @default(uuid())
  orderNo         String      @unique        // 订单编号: ORD-YYYYMMDD-XXXXXX
  
  // 用户信息
  userId          String
  user            User        @relation(fields: [userId], references: [id])
  
  // 商品信息 (快照，防止商品修改后订单信息变化)
  productId       String?
  productType     String                      // 'points' | 'vip' | 'combo'
  productName     String
  productDesc     String?
  quantity        Int         @default(1)
  
  // 价格信息
  originalPrice   Float                       // 原价
  discountPrice   Float?                      // 折扣价
  finalPrice      Float                       // 最终支付价格
  
  // 支付信息
  status          OrderStatus @default(PENDING)
  paymentMethod   String?                     // 'mock' | 'alipay' | 'wechat'
  paymentNo       String?                     // 第三方支付流水号
  paidAt          DateTime?                   // 支付时间
  
  // VIP变更记录 (购买VIP商品时记录)
  beforeVipLevel  Int?
  afterVipLevel   Int?
  
  // 退款信息
  refundReason    String?
  refundedAt      DateTime?
  
  // 权益发放
  fulfillmentAt   DateTime?                   // 权益发放时间
  
  // 时间戳
  createdAt       DateTime    @default(now())
  updatedAt       DateTime    @updatedAt
  
  // 关联
  refundRequests  RefundRequest[]
  
  @@index([userId])
  @@index([status])
  @@index([createdAt])
}

enum OrderStatus {
  PENDING     // 待支付
  PAID        // 已支付
  CANCELLED   // 已取消
  REFUNDED    // 已退款
  FAILED      // 支付失败
}
```

## 订单状态机

```
                    ┌─────────────┐
                    │   PENDING   │
                    │   (待支付)   │
                    └──────┬──────┘
                           │
           ┌───────────────┼───────────────┐
           │               │               │
           ▼               ▼               ▼
    ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
    │   CANCELLED │  │    PAID     │  │    FAILED   │
    │   (已取消)   │  │   (已支付)   │  │   (失败)    │
    └─────────────┘  └──────┬──────┘  └─────────────┘
                            │
                   ┌────────┴────────┐
                   │                 │
                   ▼                 ▼
            ┌─────────────┐   ┌─────────────┐
            │  REFUNDED   │   │  Completed  │
            │   (已退款)   │   │   (已完成)   │
            └─────────────┘   └─────────────┘
```

**状态流转规则：**

| 当前状态 | 可流转到 | 触发条件 |
|---------|---------|---------|
| PENDING | PAID | 支付成功 |
| PENDING | CANCELLED | 用户取消或超时 |
| PENDING | FAILED | 支付失败 |
| PAID | REFUNDED | 退款申请通过 |
| PAID | - | 权益发放完成，订单完成 |

## 核心算法实现

### 1. 订单创建

```typescript
// server/src/services/order.service.ts

export async function createOrder(
  userId: string,
  productId: string,
  quantity: number = 1
): Promise<Order> {
  // 1. 获取商品信息
  const product = await prisma.product.findUnique({
    where: { id: productId }
  });

  if (!product || !product.isActive) {
    throw new Error('商品不存在或已下架');
  }

  // 2. 计算价格
  const originalPrice = product.originalPrice || product.price;
  const finalPrice = product.price * quantity;

  // 3. 生成订单号
  const orderNo = generateOrderNo();

  // 4. 创建订单
  const order = await prisma.order.create({
    data: {
      orderNo,
      userId,
      productId,
      productType: product.type,
      productName: product.name,
      productDesc: product.desc,
      quantity,
      originalPrice,
      finalPrice,
      status: 'PENDING'
    }
  });

  // 5. 设置订单超时 (30分钟)
  scheduleOrderTimeout(order.id, 30 * 60 * 1000);

  return order;
}

// 生成订单号: ORD-YYYYMMDD-XXXXXX
function generateOrderNo(): string {
  const date = new Date();
  const dateStr = date.toISOString().slice(0, 10).replace(/-/g, '');
  const random = Math.floor(Math.random() * 1000000).toString().padStart(6, '0');
  return `ORD-${dateStr}-${random}`;
}
```

### 2. 支付处理

```typescript
export async function processPayment(
  orderId: string,
  paymentMethod: 'mock' | 'alipay' | 'wechat'
): Promise<Order> {
  const order = await prisma.order.findUnique({
    where: { id: orderId }
  });

  if (!order) throw new Error('订单不存在');
  if (order.status !== 'PENDING') throw new Error('订单状态错误');

  // Mock支付模式 (开发测试用)
  if (paymentMethod === 'mock' || process.env.MOCK_PAYMENT === '1') {
    return processMockPayment(order);
  }

  // 真实支付流程
  if (paymentMethod === 'alipay') {
    return processAlipay(order);
  } else if (paymentMethod === 'wechat') {
    return processWechatPay(order);
  }

  throw new Error('不支持的支付方式');
}

// Mock支付处理
async function processMockPayment(order: Order): Promise<Order> {
  // 模拟支付延迟
  await sleep(1000);

  // 更新订单状态
  const updatedOrder = await prisma.order.update({
    where: { id: order.id },
    data: {
      status: 'PAID',
      paymentMethod: 'mock',
      paymentNo: `MOCK-${Date.now()}`,
      paidAt: new Date()
    }
  });

  // 异步发放权益
  setImmediate(() => fulfillOrder(updatedOrder));

  return updatedOrder;
}

// 支付宝支付
async function processAlipay(order: Order): Promise<Order> {
  // 创建支付宝订单
  const alipayOrder = await alipaySdk.exec('alipay.trade.precreate', {
    notify_url: `${process.env.API_BASE_URL}/webhooks/alipay`,
    bizContent: {
      out_trade_no: order.orderNo,
      total_amount: order.finalPrice,
      subject: order.productName
    }
  });

  if (alipayOrder.code !== '10000') {
    throw new Error(`支付宝下单失败: ${alipayOrder.msg}`);
  }

  // 返回支付二维码URL，前端展示
  return {
    ...order,
    qrCode: alipayOrder.qr_code
  };
}
```

### 3. 权益发放

```typescript
export async function fulfillOrder(order: Order): Promise<void> {
  try {
    await prisma.$transaction(async (tx) => {
      // 1. 发放积分
      if (order.productType === 'points') {
        const product = await tx.product.findUnique({
          where: { id: order.productId }
        });
        
        if (product?.points) {
          await tx.user.update({
            where: { id: order.userId },
            data: {
              points: { increment: product.points }
            }
          });

          // 创建积分交易记录
          await tx.transaction.create({
            data: {
              userId: order.userId,
              type: 'recharge',
              amount: product.points,
              balance: (await tx.user.findUnique({ where: { id: order.userId } }))!.points,
              description: `购买${product.name}获得积分`,
              orderId: order.id
            }
          });
        }
      }

      // 2. 发放VIP权益
      if (order.productType === 'vip') {
        const product = await tx.product.findUnique({
          where: { id: order.productId }
        });

        if (product?.roleToGrant) {
          const user = await tx.user.findUnique({
            where: { id: order.userId }
          });

          // 记录购买前等级
          await tx.order.update({
            where: { id: order.id },
            data: { beforeVipLevel: user?.vipLevel || 0 }
          });

          // 计算新的过期时间
          const newVipLevel = ROLE_TO_LEVEL_MAP[product.roleToGrant];
          const durationDays = PERIOD_TO_DAYS[product.period] || 30;
          
          let newExpiresAt: Date;
          if (user?.vipExpiresAt && user.vipExpiresAt > new Date()) {
            // 续费：在原有基础上叠加
            newExpiresAt = new Date(user.vipExpiresAt);
            newExpiresAt.setDate(newExpiresAt.getDate() + durationDays);
          } else {
            newExpiresAt = new Date();
            newExpiresAt.setDate(newExpiresAt.getDate() + durationDays);
          }

          // 更新用户VIP信息
          await tx.user.update({
            where: { id: order.userId },
            data: {
              vipLevel: Math.max(user?.vipLevel || 0, newVipLevel),
              vipExpiresAt: newExpiresAt,
              role: product.roleToGrant as UserRole
            }
          });

          // 记录购买后等级
          await tx.order.update({
            where: { id: order.id },
            data: { 
              afterVipLevel: newVipLevel,
              fulfillmentAt: new Date()
            }
          });
        }
      }
    });

    // 发送通知
    await createMessage({
      userId: order.userId,
      type: 'ORDER',
      title: '订单支付成功',
      content: `您的订单 ${order.orderNo} 已支付成功，权益已发放。`,
      bizType: 'order',
      bizId: order.id
    });

    console.log(`[Order] 订单 ${order.id} 权益发放完成`);
  } catch (error) {
    console.error(`[Order] 订单 ${order.id} 权益发放失败:`, error);
    // 记录失败，人工介入处理
    await createManualReviewTask(order.id, '权益发放失败');
  }
}
```

**Endpoint:** `POST /api/orders/:id/pay`

**Request Body:**

**Response:**
```typescript
{
  success: true;
  data: {
    id: string;
    status: 'PAID';
    paidAt: string;

```

**Endpoint:** `GET /api/orders/my?page=1&limit=10`

**Response:**
```typescript
{
  success: true;
  data: {
    items: Array<{
      id: string;
      orderNo: string;
      productName: string;
      finalPrice: number;
      status: string;
      createdAt: string;
      paidAt?: string;

      page: number;
      limit: number;
      total: number;
```

**Response:**
```typescript

    id: string;
    status: 'CANCELLED';
  }
}
```

### 1. 支付宝回调

```typescript
// server/src/routes/webhook.routes.ts

router.post('/alipay', async (req, res) => {
  try {
    // 验证签名
    const result = alipaySdk.checkNotifySign(req.body);
    if (!result) {
      return res.status(400).send('Invalid signature');
    }

    const { out_trade_no, trade_status, trade_no } = req.body;

    if (trade_status === 'TRADE_SUCCESS') {
      // 更新订单状态
      const order = await prisma.order.updateMany({
        where: { orderNo: out_trade_no },
        data: {
          status: 'PAID',
          paymentMethod: 'alipay',
          paymentNo: trade_no,
          paidAt: new Date()
        }
      });

      // 发放权益
      const updatedOrder = await prisma.order.findFirst({
        where: { orderNo: out_trade_no }
      });
      if (updatedOrder) {
        await fulfillOrder(updatedOrder);
      }
    }

    res.send('success');
  } catch (error) {
    console.error('[Webhook] Alipay callback error:', error);
    res.status(500).send('error');
  }
});
```

## 管理后台功能

### 1. 订单统计

```typescript
// 获取订单统计数据
export async function getOrderStatistics(
  startDate: Date,
  endDate: Date
): Promise<{
  totalOrders: number;
  totalRevenue: number;
  totalRefunded: number;
  statusBreakdown: Record<string, number>;
}> {
  const orders = await prisma.order.findMany({
    where: {
      createdAt: {
        gte: startDate,
        lte: endDate
      }
    }
  });

  const totalRevenue = orders
    .filter(o => o.status === 'PAID')
    .reduce((sum, o) => sum + o.finalPrice, 0);

  const totalRefunded = orders
    .filter(o => o.status === 'REFUNDED')
    .reduce((sum, o) => sum + o.finalPrice, 0);

  const statusBreakdown = orders.reduce((acc, o) => {
    acc[o.status] = (acc[o.status] || 0) + 1;
    return acc;
  }, {} as Record<string, number>);

  return {
    totalOrders: orders.length,
    totalRevenue,
    totalRefunded,
    statusBreakdown
  };
}
```

## 错误处理

| 错误场景 | 处理策略 |
|---------|---------|
| 订单不存在 | 404错误，提示检查订单号 |
