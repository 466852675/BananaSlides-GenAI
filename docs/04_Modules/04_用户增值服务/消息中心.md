# 消息中心系统

## 概述

消息中心系统是 YH-AI PPT 的**用户通信枢纽**，提供站内信、邮件通知等多种消息渠道。系统支持**消息分类管理**、**已读状态追踪**、**消息模板化**等功能，确保用户及时获取订单、VIP、积分等重要信息。

## 核心功能特性

| 功能特性 | 说明 | 技术实现 |
|---------|------|---------|
| 站内信 | 应用内消息通知 | UserMessage模型 |
| 邮件通知 | 邮件渠道推送 | 邮件服务集成 |
| 消息分类 | 8种消息类型 | MessageType枚举 |
| 已读追踪 | 消息已读状态管理 | isRead字段 |
| 消息模板 | 可配置的模板系统 | MessageTemplate模型 |
| 消息设置 | 用户自定义通知偏好 | UserMessageSettings模型 |
| 归档管理 | 消息归档与删除 | isArchived/isDeleted字段 |

## 数据库模型

### 1. 用户消息表 (UserMessage)

```prisma
model UserMessage {
  id            String      @id @default(uuid())
  userId        String
  type          MessageType                 // 消息类型
  title         String                      // 消息标题
  content       String                      // 消息内容
  summary       String?                     // 内容摘要
  
  // 业务关联
  bizType       String?                     // 业务类型: order/refund/vip等
  bizId         String?                     // 业务ID（关联订单/退款等）
  actionUrl     String?                     // 操作链接
  
  // 状态管理
  isRead        Boolean     @default(false)
  readAt        DateTime?                   // 阅读时间
  isImportant   Boolean     @default(false) // 重要标记
  isDeleted     Boolean     @default(false) // 软删除标记
  isArchived    Boolean     @default(false) // 归档标记
  archivedAt    DateTime?
  expiresAt     DateTime?                   // 过期时间
  
  // 处理记录（用于线索等需要处理的消息）
  handledBy     String?                     // 处理人ID
  handledAt     DateTime?                   // 处理时间
  handleAction  String?                     // 处理动作
  
  createdAt     DateTime    @default(now())
  updatedAt     DateTime    @updatedAt
  
  user          User        @relation(fields: [userId], references: [id])
  handler       User?       @relation("MessageHandler", fields: [handledBy], references: [id])
  
  @@index([userId])
  @@index([isRead])
  @@index([type])
  @@index([createdAt])
}
```

## 核心算法实现

### 1. 创建消息

```typescript
// server/src/services/message.service.ts

export async function createMessage(data: {
  userId: string;
  type: MessageType;
  title: string;
  content: string;
  summary?: string;
  bizType?: string;
  bizId?: string;
  actionUrl?: string;
  isImportant?: boolean;
  expiresAt?: Date;
}): Promise<UserMessage> {
  const message = await prisma.userMessage.create({
    data: {
      userId: data.userId,
      type: data.type,
      title: data.title,
      content: data.content,
      summary: data.summary,
      bizType: data.bizType,
      bizId: data.bizId,
      actionUrl: data.actionUrl,
      isImportant: data.isImportant || false,
      expiresAt: data.expiresAt
    }
  });
  
  // 异步检查是否需要发送邮件通知
  checkAndSendEmailNotification(data.userId, data.type, data.title, data.content);
  
  return message;
}

// 批量创建消息
export async function createMessages(
  userIds: string[],
  messageData: Omit<CreateMessageData, 'userId'>
): Promise<number> {
  const messages = userIds.map(userId => ({
    userId,
    ...messageData
  }));
  
  const result = await prisma.userMessage.createMany({
    data: messages
  });
  
  return result.count;
}
```

### 2. 获取消息列表

```typescript
export async function getUserMessages(
  userId: string,
  options: {
    type?: MessageType;
    isRead?: boolean;
    isArchived?: boolean;
    page?: number;
    limit?: number;
  }
): Promise<{ items: UserMessage[]; unreadCount: number; total: number }> {
  const { type, isRead, isArchived = false, page = 1, limit = 20 } = options;
  
  const where: any = {
    userId,
    isDeleted: false,
    isArchived
  };
  
  if (type) where.type = type;
  if (isRead !== undefined) where.isRead = isRead;
  
  // 排除已过期的消息
  where.OR = [
    { expiresAt: null },
    { expiresAt: { gt: new Date() } }
  ];
  
  const [items, unreadCount, total] = await Promise.all([
    prisma.userMessage.findMany({
      where,
      orderBy: [
        { isImportant: 'desc' },
        { createdAt: 'desc' }
      ],
      skip: (page - 1) * limit,
      take: limit
    }),
    prisma.userMessage.count({
      where: {
        userId,
        isRead: false,
        isDeleted: false
      }
    }),
    prisma.userMessage.count({ where })
  ]);
  
  return { items, unreadCount, total };
}
```

### 3. 标记已读

```typescript
export async function markAsRead(
  userId: string,
  messageId?: string  // 不传则标记所有未读
): Promise<void> {
  if (messageId) {
    // 标记单条
    await prisma.userMessage.updateMany({
      where: {
        id: messageId,
        userId  // 确保只能标记自己的消息
      },
      data: {
        isRead: true,
        readAt: new Date()
      }
    });
  } else {
    // 标记全部
    await prisma.userMessage.updateMany({
      where: {
        userId,
        isRead: false,
        isDeleted: false
      },
      data: {
        isRead: true,
        readAt: new Date()
      }
    });
  }
}
```

### 4. 消息模板渲染

```typescript
export async function renderMessageTemplate(
  templateCode: string,
  variables: Record<string, string | number>
): Promise<{ title: string; content: string }> {
  const template = await prisma.messageTemplate.findUnique({
    where: { code: templateCode }
  });
  
  if (!template || !template.isActive) {
    throw new Error(`模板 ${templateCode} 不存在或未启用`);
  }
  
  // 简单的变量替换
  let title = template.title;
  let content = template.content;
  
  for (const [key, value] of Object.entries(variables)) {
    const placeholder = `{{${key}}}`;
    title = title.replace(new RegExp(placeholder, 'g'), String(value));
    content = content.replace(new RegExp(placeholder, 'g'), String(value));
  }
  
  return { title, content };
}

// 使用示例
const { title, content } = await renderMessageTemplate('ORDER_PAID', {
  orderNo: 'ORD-20240101-001',
  productName: 'VIP月度会员',
  price: '29.9'
});
```

## API 接口

### 获取消息列表

**Endpoint:** `GET /api/messages?type=&isRead=&page=1&limit=20`

**Response:**
```typescript
{
  success: true;
  data: {
    items: Array<{
      id: string;
      type: MessageType;
      title: string;
      content: string;
      summary?: string;
      isRead: boolean;
      isImportant: boolean;
      bizType?: string;
      bizId?: string;
      actionUrl?: string;
      createdAt: string;
    }>;
    unreadCount: number;
    total: number;
  }
}
```

### 标记已读

**Endpoint:** `POST /api/messages/:id/read`

**或标记全部已读:** `POST /api/messages/read-all`

### 删除消息

**Endpoint:** `DELETE /api/messages/:id`

**说明:** 软删除，设置isDeleted=true

### 归档消息

**Endpoint:** `POST /api/messages/:id/archive`

### 获取未读数量

**Endpoint:** `GET /api/messages/unread-count`

**Response:**
```typescript
{
  success: true;
  data: {
    total: number;
    byType: Record<MessageType, number>;
  }
}
```

```typescript
// src/components/MessageBell.tsx

import { useState, useEffect } from 'react';
import { useQuery, useMutation } from '@tanstack/react-query';
import { Bell } from 'lucide-react';

export const MessageBell: React.FC = () => {
  const [isOpen, setIsOpen] = useState(false);
  
  const { data: unreadData } = useQuery({
    queryKey: ['messages', 'unread'],
    queryFn: async () => {
      const res = await fetch('/api/messages/unread-count');
      return res.json();
    },
    refetchInterval: 30000  // 30秒刷新一次
  });
  
  const { data: messages } = useQuery({
    queryKey: ['messages', 'recent'],
    queryFn: async () => {
      const res = await fetch('/api/messages?limit=5&isRead=false');
      return res.json();
    },
    enabled: isOpen
  });
  
  const markAsRead = useMutation({
    mutationFn: async (messageId: string) => {
      await fetch(`/api/messages/${messageId}/read`, { method: 'POST' });
    }
  });
  
  const unreadCount = unreadData?.data?.total || 0;
  
  return (
    <div className="message-bell">
      <button onClick={() => setIsOpen(!isOpen)}>
        <Bell />
        {unreadCount > 0 && <span className="badge">{unreadCount}</span>}
      </button>
      
      {isOpen && (
        <div className="message-dropdown">
          <div className="header">
            <span>消息通知</span>
            {unreadCount > 0 && (
              <button onClick={() => markAsRead.mutate('')}>
                全部已读
              </button>
            )}
          </div>
          
          <div className="message-list">
            {messages?.data?.items.map((msg: any) => (
              <div
                key={msg.id}
                className={`message-item ${msg.isImportant ? 'important' : ''}`}
                onClick={() => {
                  markAsRead.mutate(msg.id);
                  if (msg.actionUrl) {
                    window.location.href = msg.actionUrl;
                  }
                }}
              >
                <span className={`type-badge type-${msg.type}`}>
                  {msg.type}
                </span>
                <p className="title">{msg.title}</p>
                <span className="time">
                  {formatDistanceToNow(new Date(msg.createdAt))}

            ))}
          </div>

            查看全部消息

        </div>
      )}
```

## 通知场景详解

| 场景 | 消息类型 | 触发时机 | 通知渠道 |
|-----|---------|---------|---------|
| 订单支付成功 | ORDER | 支付完成 | 站内+邮件 |
| 订单退款完成 | REFUND | 退款处理完成 | 站内+邮件 |
| VIP开通成功 | VIP | VIP权益发放 | 站内+邮件 |
| VIP即将到期 | VIP | 到期前7天/1天 | 站内+邮件 |
| 积分到账 | POINTS | 积分变动 | 站内 |
| 积分不足提醒 | POINTS | 积分<10时 | 站内 |
| AI生成完成 | AI | 异步任务完成 | 站内 |
| 安全登录提醒 | SECURITY | 新设备登录 | 邮件 |
| 系统维护通知 | SYSTEM | 计划维护前 | 站内+邮件 |
