# 积分系统

## 概述

积分系统是 YH-AI PPT 的虚拟货币体系，管理用户积分的获取、消耗和记录。系统支持**VIP折扣**、**风控限流**、**并发安全**等特性，确保积分交易的准确性和安全性。

## 核心功能特性

| 功能 | 说明 | 实现位置 |
|-----|------|---------|
| 积分扣费 | AI功能使用时自动扣除积分 | `points.service.ts` |
| VIP折扣 | 不同VIP等级享受不同价格 | `points.service.ts` |
| 风控限流 | 防止恶意刷积分 | `points.service.ts` |
| 交易记录 | 完整的积分流水记录 | `Transaction`模型 |
| 并发安全 | 数据库事务+乐观锁 | `prisma.$transaction` |
| 积分充值 | 支持购买和奖励发放 | `points.service.ts` |

## 核心算法实现

### 1. VIP折扣计算

```typescript
// server/src/services/points.service.ts

export async function getActionCost(
    actionCode: PointsActionCode, 
    userId?: string
): Promise<number> {
    // 1. 读取积分规则
    const rule = await prisma.pointsRule.findUnique({
        where: { code: actionCode },
    });

    if (!rule || !rule.isActive) {
        console.warn(`[Points] 积分规则 "${actionCode}" 未找到或未启用`);
        return 0; // 规则不存在时免费
    }

    // 2. 无用户ID，返回标准价格
    if (!userId) {
        return rule.costPoints;
    }

    // 3. 检查用户VIP状态
    const user = await prisma.user.findUnique({
        where: { id: userId },
        select: { 
            vipLevel: true, 
            vipExpiresAt: true, 
            role: true 
        }
    });

    if (user && user.vipLevel > 0) {
        // 管理员是永久VIP
        const isAdmin = user.role === 'ADMIN' || user.role === 'SUPER_ADMIN';
        
        const now = new Date();
        let isVipValid: boolean;
        
        if (isAdmin) {
            // 管理员永不过期
            isVipValid = true;
        } else if (user.vipExpiresAt) {
            // 普通用户检查过期时间
            isVipValid = new Date(user.vipExpiresAt) > now;
        } else {
            isVipValid = false;
        }

        // VIP有效且有VIP价格配置
        if (isVipValid && rule.vipCostPoints !== null && rule.vipCostPoints !== undefined) {
            return rule.vipCostPoints;
        }
    }

    return rule.costPoints;
}
```

### 2. 积分扣费（并发安全）

```typescript
export async function deductPoints(
    userId: string,
    actionCode: PointsActionCode,
    projectId?: string,
    description?: string,
    multiplier: number = 1,
    options?: {
        module?: string;
        category?: string;
        subcategory?: string;
        triggerTime?: Date;
        templateId?: string;
    }
): Promise<DeductResult> {
    // 1. 获取规则
    const rule = await prisma.pointsRule.findUnique({
        where: { code: actionCode },
    });

    if (!rule || !rule.isActive) {
        return {
            success: true,
            remainingPoints: 0,
            deductedAmount: 0,
            message: '免费操作（规则未配置）',
        };
    }

    // 2. 计算实际消耗 (支持VIP价格)
    const costPerAction = await getActionCost(actionCode, userId);
    const totalCost = costPerAction * multiplier;

    // 3. 风控检测
    if (totalCost > 0) {
        const rateLimit = await checkRateLimit(userId, actionCode);
        if (!rateLimit.allowed) {
            return {
                success: false,
                remainingPoints: 0,
                deductedAmount: 0,
                message: rateLimit.reason || '操作过于频繁',
            };
        }
    }

    if (totalCost === 0) {
        return { success: true, remainingPoints: 0, deductedAmount: 0, message: '免费操作' };
    }

    // 4. 【核心】数据库事务 + 乐观锁
    const MAX_RETRIES = 3;
    let retryCount = 0;

    while (retryCount < MAX_RETRIES) {
        try {
            const result = await prisma.$transaction(async (tx) => {
                // 获取最新用户数据
                const user = await tx.user.findUnique({
                    where: { id: userId },
                    select: { id: true, points: true }
                });

                if (!user) throw new Error('用户不存在');

                // 双重检查余额
                if (user.points < totalCost) {
                    return {
                        success: false,
                        remainingPoints: user.points,
                        deductedAmount: 0,
                        message: `积分不足 (需要 ${totalCost}, 当前 ${user.points})`,
                    };
                }

                // 乐观锁：条件更新确保余额充足
                const updatedUser = await tx.user.update({
                    where: { 
                        id: userId,
                        points: { gte: totalCost }  // 条件：余额必须 >= 扣费金额
                    },
                    data: {
                        points: { decrement: totalCost },
                        pointsUsed: { increment: totalCost }
                    }
                });

                // 最终验证
                if (updatedUser.points < 0) {
                    throw new Error('并发冲突：余额计算异常');
                }

                // 创建交易记录
                const log = await tx.transaction.create({
                    data: {
                        userId,
                        type: 'consume',
                        amount: -totalCost,
                        balance: updatedUser.points,
                        ruleCode: actionCode,
                        projectId,
                        description: description || rule.name,
                        module: options?.module || rule.module,
                        category: options?.category || rule.category,
                        subcategory: options?.subcategory,
                        triggerTime: options?.triggerTime,
                        templateId: options?.templateId
                    }
                });

                return {
                    success: true,
                    updatedUser,
                    log,
                    deductedAmount: totalCost,
                };
            }, {
                isolationLevel: 'Serializable',  // 串行化隔离级别
                maxWait: 5000,
                timeout: 10000,
            });

            if (!result.success) return result as DeductResult;

            return {
                success: true,
                remainingPoints: result.updatedUser!.points,
                deductedAmount: result.deductedAmount,
                transactionId: result.log!.id,
                message: '扣费成功'
            };

        } catch (error: any) {
            // 检测并发冲突
            if (error.code === 'P2034' || 
                error.message?.includes('concurrent') ||
                error.message?.includes('数据库被锁定')) {
                retryCount++;
                console.warn(`[deductPoints] 检测到并发冲突，第${retryCount}次重试...`);
                
                // 指数退避
                await sleep(100 * Math.pow(2, retryCount - 1));
                continue;
            }
            throw error;
        }
    }

    return { success: false, remainingPoints: 0, deductedAmount: 0, message: '扣费失败' };
}
```

### 3. 风控限流

```typescript
export async function checkRateLimit(
    userId: string, 
    actionCode: PointsActionCode
): Promise<{ allowed: boolean; reason?: string; resetInSeconds?: number }> {
    // 限流配置
    const LIMITS: Record<string, { count: number; windowSeconds: number }> = {
        'slide_image': { count: 30, windowSeconds: 3600 },  // 图片生成：30次/小时
        'default': { count: 100, windowSeconds: 3600 }      // 默认：100次/小时
    };

    const limit = LIMITS[actionCode] || LIMITS.default;
    const now = new Date();
    const windowStart = new Date(now.getTime() - limit.windowSeconds * 1000);

    // 统计窗口期内请求次数
    const count = await prisma.transaction.count({
        where: {
            userId,
            ruleCode: actionCode,
            type: 'consume',
            createdAt: { gte: windowStart }
        }
    });

    if (count >= limit.count) {
        // VIP等级影响限流阈值
        const user = await prisma.user.findUnique({ 
            where: { id: userId }, 
            select: { vipLevel: true } 
        });
        const vipMultiplier = (user?.vipLevel || 0) >= 3 ? 3 : 1;

        if (count < limit.count * vipMultiplier) {
            return { allowed: true };
        }

        return {
            allowed: false,
            reason: `操作过于频繁，请稍后再试 (限制: ${limit.count * vipMultiplier} 次/${limit.windowSeconds / 60}分钟)`,
            resetInSeconds: limit.windowSeconds
        };
    }

    return { allowed: true };
}
```

### 4. 积分充值/奖励

```typescript
export async function addPoints(
    userId: string,
    amount: number,
    type: 'recharge' | 'reward' | 'adjust',
    description: string,
    operatorId?: string,
    orderId?: string
): Promise<{ success: boolean; newBalance: number }> {
    const user = await prisma.user.findUnique({
        where: { id: userId },
        select: { points: true },
    });

    if (!user) return { success: false, newBalance: 0 };

    const newBalance = user.points + amount;

    await prisma.$transaction([
        // 更新余额
        prisma.user.update({
            where: { id: userId },
            data: { points: newBalance },
        }),
        // 创建交易记录
        prisma.transaction.create({
            data: {
                userId,
                type,
                amount,
                balance: newBalance,
                description,
                module: '系统操作',
                category: type === 'reward' ? '奖励' : (type === 'adjust' ? (amount > 0 ? '奖励' : '扣除') : '充值'),
                operatorId,
                orderId,
            },
        }),
    ]);

    console.log(`[Points] 用户 ${userId} 增加 ${amount} 积分 (${type})，新余额 ${newBalance}`);
    return { success: true, newBalance };
}
```

```typescript
export function useDeductPoints() {
    const queryClient = useQueryClient();
    
    return useMutation({
        mutationFn: async (params: {
            actionCode: string;
            projectId?: string;
            description?: string;
        }) => {
            const res = await fetch('/api/points/deduct', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json',
                    'Authorization': `Bearer ${localStorage.getItem('token')}`
                },
                body: JSON.stringify(params)
            });
            
            if (res.status === 402) {
                const error = await res.json();
                throw new Error(error.error.message || '积分不足');
            }
            
            return res.json();
        },
        onSuccess: () => {
            // 扣费成功后刷新余额
            queryClient.invalidateQueries({ queryKey: ['points', 'balance'] });
        }
    });
}
```

## VIP折扣详解

### 1. VIP等级与折扣

| VIP等级 | 折扣比例 | 示例：图片生成(5积分) |
|--------|---------|---------------------|
| 普通用户 | 100% | 5积分 |
| VIP 1-2 | 80% | 4积分 |
| VIP 3-4 | 60% | 3积分 |
| VIP 5 | 0% | 免费 |

### 2. VIP有效期规则

```typescript
// VIP有效期检查逻辑
function isVipValid(user: User): boolean {
    // 管理员永不过期
    if (user.role === 'ADMIN' || user.role === 'SUPER_ADMIN') {
        return true;
    }
    
    // 普通用户检查过期时间
    if (user.vipExpiresAt) {
        return new Date(user.vipExpiresAt) > new Date();
    }
    
    return false;
}
```

## 错误处理

### 1. 常见错误码

| 错误场景 | HTTP状态码 | 错误码 | 处理建议 |
|---------|-----------|--------|---------|
| 积分不足 | 402 | INSUFFICIENT_POINTS | 提示充值或购买VIP |
| 操作频繁 | 429 | RATE_LIMIT_EXCEEDED | 提示稍后再试 |
| 并发冲突 | 500 | CONCURRENT_ERROR | 自动重试 |
| 规则不存在 | 200 | - | 免费处理 |

### 2. 失败回滚机制

```typescript
// AI生成失败时退还积分
try {
    const result = await generateAIContent();
    await completeTransaction(transactionId);

    // 生成失败，退还积分

    }
    throw error;
}
```
