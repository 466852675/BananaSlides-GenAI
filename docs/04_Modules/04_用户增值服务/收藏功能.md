# 收藏功能

## 概述

收藏功能是 YH-AI PPT 的**用户个性化服务模块**，允许用户收藏喜欢的 StyleTemplate（风格模板），方便后续快速访问和使用。系统支持**模板收藏**，并自动统计模板的收藏次数作为推荐排序依据。

## 核心功能特性

| 功能特性 | 说明 | 技术实现 |
|---------|------|---------|
| 收藏模板 | 用户收藏风格模板 | Favorite表关联 |
| 取消收藏 | 移除收藏记录 | 软删除 |
| 收藏列表 | 查看我的收藏 | 分页查询 |
| 收藏统计 | 统计模板收藏次数 | 聚合查询 |
| 重复检测 | 防止重复收藏 | 唯一索引 |

## 数据库模型

### 1. 收藏表 (Favorite)

```prisma
model Favorite {
  id           String         @id @default(uuid())
  templateId   String?        // 关联的模板ID
  name         String         // 收藏时的模板名称（快照）
  config       String         // 收藏时的配置（快照）
  styleMap     String?        // 风格图Map（快照）
  sampleImages String?        // 示例图片
  
  userId       String?
  user         User?          @relation(fields: [userId], references: [id])
  
  template     StyleTemplate? @relation(fields: [templateId], references: [id])
  
  createdAt    DateTime       @default(now())
  updatedAt    DateTime       @updatedAt
  
  @@unique([userId, templateId])  // 同一用户不能重复收藏同一模板
  @@index([userId])
  @@index([templateId])
}
```

### 2. 关联关系

```prisma

}
```

## 核心算法实现

### 1. 收藏模板

```typescript
// server/src/services/favorite.service.ts

export async function createFavorite(
  userId: string,
  templateId: string
): Promise<Favorite> {
  // 1. 检查模板是否存在
  const template = await prisma.styleTemplate.findUnique({
    where: { id: templateId }
  });
  
  if (!template) {
    throw new Error('模板不存在');
  }
  
  // 2. 检查是否已收藏（唯一索引会自动阻止，但提前检查可给出友好提示）
  const existing = await prisma.favorite.findUnique({
    where: {
      userId_templateId: {
        userId,
        templateId
      }
    }
  });
  
  if (existing) {
    throw new Error('您已收藏该模板');
  }
  
  // 3. 创建收藏记录（快照模式，保存当前模板信息）
  const favorite = await prisma.favorite.create({
    data: {
      userId,
      templateId,
      name: template.name,
      config: template.config,
      styleMap: template.styleMap,
      // sampleImages可从template生成
    }
  });
  
  // 4. 更新模板收藏计数
  await prisma.styleTemplate.update({
    where: { id: templateId },
    data: {
      favoriteCount: { increment: 1 }
    }
  });
  
  return favorite;
}
```

### 2. 取消收藏

```typescript
export async function deleteFavorite(
  userId: string,
  favoriteId: string
): Promise<void> {
  // 1. 查找收藏记录
  const favorite = await prisma.favorite.findFirst({
    where: {
      id: favoriteId,
      userId  // 确保只能删除自己的收藏
    }
  });
  
  if (!favorite) {
    throw new Error('收藏记录不存在');
  }
  
  // 2. 删除收藏记录
  await prisma.favorite.delete({
    where: { id: favoriteId }
  });
  
  // 3. 减少模板收藏计数
  if (favorite.templateId) {
    await prisma.styleTemplate.update({
      where: { id: favorite.templateId },
      data: {
        favoriteCount: { decrement: 1 }
      }
    });
  }
}
```

### 3. 获取收藏列表

```typescript
export async function getUserFavorites(
  userId: string,
  page: number = 1,
  limit: number = 20
): Promise<{ items: Favorite[]; total: number }> {
  const [items, total] = await Promise.all([
    prisma.favorite.findMany({
      where: { userId },
      orderBy: { createdAt: 'desc' },
      skip: (page - 1) * limit,
      take: limit,
      include: {
        template: {
          select: {
            id: true,
            name: true,
            isOfficial: true,
            usageCount: true,
            favoriteCount: true
          }
        }
      }
    }),
    prisma.favorite.count({ where: { userId } })
  ]);
  
  return { items, total };
}
```

## API 接口

### 收藏模板

**Endpoint:** `POST /api/favorites`

**Request Body:**
```typescript
{
  templateId: string;  // 模板ID
}
```

**Response:**
```typescript
{
  success: true;
  data: {
    id: string;
    templateId: string;
    name: string;
    createdAt: string;
  }
}
```

**错误码:**
- `TEMPLATE_NOT_FOUND`: 模板不存在
- `ALREADY_FAVORITED`: 已收藏该模板

### 取消收藏

**Endpoint:** `DELETE /api/favorites/:id`

**Response:**
```typescript
{
  success: true;
  message: '取消收藏成功'
}
```

### 获取我的收藏

**Endpoint:** `GET /api/favorites?page=1&limit=20`

**Response:**
```typescript
{
  success: true;
  data: {
    items: Array<{
      id: string;
      name: string;
      config: StyleConfig;
      createdAt: string;
      template?: {
        id: string;
        name: string;
        isOfficial: boolean;
        usageCount: number;
      }
    }>;
    pagination: {
      page: number;
      limit: number;
      total: number;
      totalPages: number;
    }
  }
}
```

### 检查是否已收藏

**Endpoint:** `GET /api/favorites/check?templateId=xxx`

**Response:**
```typescript
{
  success: true;
  data: {
    isFavorited: boolean;
    favoriteId?: string;
  }
}
```

## 前端集成

### 1. 收藏按钮组件

```typescript
// src/components/FavoriteButton.tsx

import { useState } from 'react';
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { Heart } from 'lucide-react';

interface FavoriteButtonProps {
  templateId: string;
  initialCount?: number;
}

export const FavoriteButton: React.FC<FavoriteButtonProps> = ({
  templateId,
  initialCount = 0
}) => {
  const queryClient = useQueryClient();
  const [count, setCount] = useState(initialCount);
  
  // 查询收藏状态
  const { data: checkData } = useQuery({
    queryKey: ['favorite', 'check', templateId],
    queryFn: async () => {
      const res = await fetch(`/api/favorites/check?templateId=${templateId}`);
      return res.json();
    }
  });
  
  const isFavorited = checkData?.data?.isFavorited;
  
  // 收藏mutation
  const favoriteMutation = useMutation({
    mutationFn: async () => {
      if (isFavorited) {
        // 取消收藏
        await fetch(`/api/favorites/${checkData.data.favoriteId}`, {
          method: 'DELETE'
        });
        setCount(c => c - 1);
      } else {
        // 添加收藏
        await fetch('/api/favorites', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ templateId })
        });
        setCount(c => c + 1);
      }
    },
    onSuccess: () => {
      queryClient.invalidateQueries({ queryKey: ['favorite', 'check', templateId] });
      queryClient.invalidateQueries({ queryKey: ['favorites'] });
    }
  });
  
  return (
    <button
      className={`favorite-btn ${isFavorited ? 'active' : ''}`}
      onClick={() => favoriteMutation.mutate()}
      disabled={favoriteMutation.isPending}
    >
      <Heart className={isFavorited ? 'filled' : ''} />
      <span>{count}</span>
    </button>
  );
};
```

```typescript
// src/pages/MyFavorites.tsx

import { useQuery } from '@tanstack/react-query';
import { TemplateCard } from '../components/TemplateCard';

export const MyFavorites: React.FC = () => {
  const { data, isLoading } = useQuery({
    queryKey: ['favorites'],
    queryFn: async () => {
      const res = await fetch('/api/favorites');
      return res.json();
    }
  });

  return (
    <div className="my-favorites-page">
      <h1>我的收藏</h1>
      
      <div className="favorites-grid">
        {data?.data?.items.map(favorite => (
          <TemplateCard
            key={favorite.id}
            template={{
              id: favorite.templateId,
              name: favorite.name,
              config: JSON.parse(favorite.config),
              ...favorite.template
            }}
            isFavorited={true}
            favoriteId={favorite.id}
          />
        ))}
      </div>
    </div>
  );
};
```
