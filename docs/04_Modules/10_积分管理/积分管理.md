# 积分管理

## 概述

积分管理是 YH-AI PPT **商业化运营核心模块**，为管理员提供积分规则的全面配置和管理能力。系统支持**积分消耗规则**、**VIP专属价格**、**手动积分发放**等功能，实现灵活的积分经济体系调控。

## 核心功能特性

| 功能特性 | 说明 | 技术实现 |
|---------|------|---------|
| 积分规则管理 | 配置各项AI功能的积分消耗 | PointsRule表 |
| VIP价格体系 | 为不同VIP等级设置专属价格 | vipCostPoints字段 |
| 规则分类 | 按模块、分类、子分类组织规则 | 三级分类体系 |
| 手动发放 | 管理员手动为用户增减积分 | 调账功能 |
| 规则启停 | 动态启用/禁用积分规则 | isActive字段 |
| 生效时间 | 设置规则的生效时间 | effectiveAt字段 |

## 数据库模型

### 1. 积分规则表 (PointsRule)

```prisma
model PointsRule {
  id                String   @id @default(uuid())
  code              String   @unique           // 规则代码（唯一标识）
  name              String                      // 规则名称
  description       String?                     // 规则描述
  
  // 分类信息
  module            String?                     // 所属模块：创作室/模版间/运营
  category          String?                     // 分类：文本生成/图片生成
  subcategory       String?                     // 子分类：大纲生成/正文生成
  
  // 价格配置
  costPoints        Int                         // 标准消耗积分
  costType          String   @default("fixed") // 计费类型：fixed/variable
  vipCostPoints     Int?                        // VIP价格（null表示与标准价相同）
  
  // 计算逻辑
  calculationMethod String?                     // 计算方式说明
  deductionLogic    String?                     // 扣费逻辑说明
  
  // 状态控制
  isActive          Boolean  @default(true)    // 是否启用
  sortOrder         Int      @default(0)       // 排序权重
  effectiveAt       DateTime @default(now())    // 生效时间
  
  // 审计
  createdById       String?
  createdBy         User?    @relation("RuleCreator", fields: [createdById], references: [id])
  
  @@index([code])
  @@index([isActive])
  @@index([module, category])
}
```

## 核心算法实现

### 1. 积分规则CRUD

```typescript
// server/src/services/points-rule.service.ts

export async function createPointsRule(
  adminId: string,
  data: {
    code: string;
    name: string;
    costPoints: number;
    vipCostPoints?: number;
    description?: string;
    module?: string;
    category?: string;
    subcategory?: string;
    calculationMethod?: string;
    deductionLogic?: string;
  }
): Promise<PointsRule> {
  // 检查code是否已存在
  const existing = await prisma.pointsRule.findUnique({
    where: { code: data.code }
  });
  
  if (existing) {
    throw new Error(`规则代码 ${data.code} 已存在`);
  }
  
  const rule = await prisma.pointsRule.create({
    data: {
      code: data.code,
      name: data.name,
      costPoints: data.costPoints,
      vipCostPoints: data.vipCostPoints,
      description: data.description,
      module: data.module,
      category: data.category,
      subcategory: data.subcategory,
      calculationMethod: data.calculationMethod,
      deductionLogic: data.deductionLogic,
      createdById: adminId
    }
  });
  
  return rule;
}

export async function updatePointsRule(
  ruleId: string,
  data: Partial<PointsRule>
): Promise<PointsRule> {
  const rule = await prisma.pointsRule.update({
    where: { id: ruleId },
    data: {
      ...data,
      // 不能修改code
      code: undefined
    }
  });
  
  return rule;
}

export async function toggleRuleStatus(
  ruleId: string,
  isActive: boolean
): Promise<PointsRule> {
  return prisma.pointsRule.update({
    where: { id: ruleId },
    data: { isActive }
  });
}
```

### 2. 获取规则列表

```typescript
export async function getPointsRules(
  options: {
    module?: string;
    category?: string;
    isActive?: boolean;
  }
): Promise<PointsRule[]> {
  const where: any = {};
  
  if (options.module) where.module = options.module;
  if (options.category) where.category = options.category;
  if (options.isActive !== undefined) where.isActive = options.isActive;
  
  const rules = await prisma.pointsRule.findMany({
    where,
    orderBy: [
      { module: 'asc' },
      { category: 'asc' },
      { sortOrder: 'asc' }
    ]
  });
  
  return rules;
}

// 按模块分组返回
export async function getPointsRulesByModule(): Promise<
  Record<string, PointsRule[]>
> {
  const rules = await prisma.pointsRule.findMany({
    where: { isActive: true },
    orderBy: { sortOrder: 'asc' }
  });
  
  // 按module分组
  const grouped = rules.reduce((acc, rule) => {
    const module = rule.module || '未分类';
    if (!acc[module]) acc[module] = [];
    acc[module].push(rule);
    return acc;
  }, {} as Record<string, PointsRule[]>);
  
  return grouped;
}
```

## API 接口

### 获取积分规则列表

**Endpoint:** `GET /api/admin/points-rules?module=&category=&isActive=true`

**Response:**
```typescript
{
  success: true;
  data: {
    items: Array<{
      id: string;
      code: string;
      name: string;
      module?: string;
      category?: string;
      subcategory?: string;
      costPoints: number;
      vipCostPoints?: number;
      isActive: boolean;
      description?: string;
    }>;
    // 按模块分组
    grouped: Record<string, Array<{
      code: string;
      name: string;
      costPoints: number;
      vipCostPoints?: number;
    }>>;
  }
}
```

### 创建积分规则

**Endpoint:** `POST /api/admin/points-rules`

**Request Body:**
```typescript
{
  code: string;              // 唯一代码，如 'custom_action'
  name: string;              // 显示名称
  costPoints: number;        // 标准价格
  vipCostPoints?: number;    // VIP价格（可选）
  module?: string;           // 所属模块
  category?: string;         // 分类
  description?: string;      // 描述
}
```

### 更新积分规则

**Endpoint:** `PATCH /api/admin/points-rules/:id`

**Request Body:**
```typescript
{
  name?: string;
  costPoints?: number;
  vipCostPoints?: number;
  isActive?: boolean;
  description?: string;
}
```

### 启用/禁用规则

**Endpoint:** `POST /api/admin/points-rules/:id/toggle`

**Request Body:**
```typescript
{
  isActive: boolean;
}
```

### 删除规则

**Endpoint:** `DELETE /api/admin/points-rules/:id`

**限制:** 仅允许删除自定义规则，不能删除系统默认规则

## 前端集成

### 1. 积分规则管理表格

```typescript
// src/components/admin/PointsRuleManagement.tsx

import { useState } from 'react';
import { useQuery, useMutation } from '@tanstack/react-query';

export const PointsRuleManagement: React.FC = () => {
  const [editingRule, setEditingRule] = useState<PointsRule | null>(null);
  
  const { data: rulesData } = useQuery({
    queryKey: ['admin', 'points-rules'],
    queryFn: async () => {
      const res = await fetch('/api/admin/points-rules');
      return res.json();
    }
  });
  
  const toggleMutation = useMutation({
    mutationFn: async ({ id, isActive }: { id: string; isActive: boolean }) => {
      const res = await fetch(`/api/admin/points-rules/${id}/toggle`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ isActive })
      });
      return res.json();
    }
  });
  
  return (
    <div className="points-rule-management">
      <h1>积分规则管理</h1>
      
      <button onClick={() => setEditingRule({} as PointsRule)}>
        + 新建规则
      </button>
      
      {Object.entries(rulesData?.data?.grouped || {}).map(([module, rules]) => (
        <div key={module} className="module-section">
          <h2>{module}</h2>
          <table>
            <thead>
              <tr>
                <th>规则名称</th>
                <th>标准价格</th>
                <th>VIP价格</th>
                <th>状态</th>
                <th>操作</th>
              </tr>
            </thead>
            <tbody>
              {rules.map((rule: any) => (
                <tr key={rule.code}>
                  <td>
                    <div className="rule-name">{rule.name}</div>
                    <div className="rule-code">{rule.code}</div>
                  </td>
                  <td>{rule.costPoints} 积分</td>
                  <td>{rule.vipCostPoints || rule.costPoints} 积分</td>
                  <td>
                    <switch
                      checked={rule.isActive}
                      onChange={(checked) =>
                        toggleMutation.mutate({ id: rule.id, isActive: checked })
                      }
                    />
                  </td>
                  <td>
                    <button onClick={() => setEditingRule(rule)}>
                      编辑
                    </button>
                  </td>
                </tr>
              ))}
            </tbody>
          </table>
        </div>
      ))}
    </div>
  );
};
```
