# 权限体系现状报告

## 概述

YH-AI PPT 权限体系采用 RBAC (Role-Based Access Control，基于角色的访问控制) 模型，实现从粗粒度到细粒度的多层次权限管理。系统包含7个用户角色、模块化权限矩阵、细粒度操作权限和完整的审计日志系统，满足企业级权限管理需求。

## 角色体系

### 角色层级

```
SUPER_ADMIN (超级管理员)
    └── 系统最高权限，可管理所有资源和配置

ADMIN (管理员)
    └── 后台管理权限，可管理用户、订单、内容等

ENTERPRISE (企业会员)
    └── 企业级功能，如团队协作、高级API等

PREMIUM (高级会员)
    └── 高级功能权限，更高积分额度和优先级

PROFESSIONAL (专业会员)
    └── 专业功能权限，中等积分额度

BASIC (基础会员)
    └── 基础功能权限，低积分额度

USER (普通用户)
    └── 基础功能，受限积分额度
```

## 核心实现

### 权限检查中间件

```typescript
// server/src/middlewares/auth.middleware.ts

import { Request, Response, NextFunction } from 'express';
import { verifyToken } from '../utils/jwt';
import { prisma } from '../db';

/**
 * 认证中间件 - 验证JWT Token
 */
export async function authenticate(
  req: Request, 
  res: Response, 
  next: NextFunction
) {
  try {
    const authHeader = req.headers.authorization;
    if (!authHeader?.startsWith('Bearer ')) {
      return res.status(401).json({ 
        success: false, 
        error: 'UNAUTHORIZED',
        message: '缺少认证令牌' 
      });
    }

    const token = authHeader.substring(7);
    const decoded = verifyToken(token);
    
    if (!decoded) {
      return res.status(401).json({ 
        success: false, 
        error: 'INVALID_TOKEN',
        message: '无效的认证令牌' 
      });
    }

    // 检查用户状态
    const user = await prisma.user.findUnique({
      where: { id: decoded.userId },
      select: { id: true, role: true, status: true }
    });

    if (!user || user.status === 'DISABLED') {
      return res.status(403).json({ 
        success: false, 
        error: 'ACCOUNT_DISABLED',
        message: '账号已被禁用' 
      });
    }

    // 将用户信息附加到请求对象
    (req as any).user = {
      userId: user.id,
      role: user.role,
      ...decoded
    };

    next();
  } catch (error) {
    return res.status(401).json({ 
      success: false, 
      error: 'AUTHENTICATION_FAILED',
      message: '认证失败' 
    });
  }
}

/**
 * 要求管理员角色
 */
export function requireAdmin(
  req: Request, 
  res: Response, 
  next: NextFunction
) {
  const userRole = (req as any).user?.role;
  
  if (!['ADMIN', 'SUPER_ADMIN'].includes(userRole)) {
    return res.status(403).json({
      success: false,
      error: 'FORBIDDEN',
      message: '需要管理员权限'
    });
  }
  
  next();
}

/**
 * 要求特定权限
 */
export function requirePermission(permissionCode: string) {
  return async (req: Request, res: Response, next: NextFunction) => {
    const userRole = (req as any).user?.role;
    
    // 超级管理员拥有所有权限
    if (userRole === 'SUPER_ADMIN') {
      return next();
    }
    
    // 查询角色是否拥有该权限
    const hasPermission = await prisma.rolePermission.findFirst({
      where: {
        role: userRole,
        permission: { code: permissionCode }
      }
    });
    
    if (!hasPermission) {
      return res.status(403).json({
        success: false,
        error: 'PERMISSION_DENIED',
        message: `缺少权限: ${permissionCode}`
      });
    }
    
    next();
  };
}

/**
 * 可选认证 - 用于公开接口但支持登录用户
 */
export async function optionalAuth(
  req: Request, 
  res: Response, 
  next: NextFunction
) {
  try {
    const authHeader = req.headers.authorization;
    if (authHeader?.startsWith('Bearer ')) {
      const token = authHeader.substring(7);
      const decoded = verifyToken(token);
      if (decoded) {
        (req as any).user = decoded;
      }
    }
    next();
  } catch {
    next();
  }
}
```

### 权限服务

```typescript
// server/src/services/permission.service.ts

import { prisma } from '../db';
import { UserRole } from '@prisma/client';

export class PermissionService {
  /**
   * 获取角色的所有权限
   */
  static async getRolePermissions(role: UserRole) {
    const permissions = await prisma.rolePermission.findMany({
      where: { role },
      include: { permission: true }
    });
    
    return permissions.map(rp => rp.permission);
  }

  /**
   * 检查角色是否有特定权限
   */
  static async hasPermission(
    role: UserRole, 
    permissionCode: string
  ): Promise<boolean> {
    // 超级管理员拥有所有权限
    if (role === UserRole.SUPER_ADMIN) {
      return true;
    }
    
    const rolePermission = await prisma.rolePermission.findFirst({
      where: {
        role,
        permission: { code: permissionCode }
      }
    });
    
    return !!rolePermission;
  }

  /**
   * 为角色分配权限
   */
  static async assignPermission(
    role: UserRole, 
    permissionCode: string
  ) {
    const permission = await prisma.permission.findUnique({
      where: { code: permissionCode }
    });
    
    if (!permission) {
      throw new Error('权限不存在');
    }
    
    return await prisma.rolePermission.upsert({
      where: {
        role_permissionId: {
          role,
          permissionId: permission.id
        }
      },
      create: {
        role,
        permissionId: permission.id
      },
      update: {}
    });
  }

  /**
   * 移除角色的权限
   */
  static async revokePermission(
    role: UserRole, 
    permissionCode: string
  ) {
    const permission = await prisma.permission.findUnique({
      where: { code: permissionCode }
    });
    
    if (!permission) return;
    
    await prisma.rolePermission.deleteMany({
      where: {
        role,
        permissionId: permission.id
      }
    });
  }

  /**
   * 获取所有权限列表
   */
  static async getAllPermissions() {
    return await prisma.permission.findMany({
      orderBy: [
        { module: 'asc' },
        { sortOrder: 'asc' }
      ]
    });
  }

  /**
   * 创建新权限
   */
  static async createPermission(data: {
    code: string;
    name: string;
    module: string;
    description?: string;
    sortOrder?: number;
  }) {
    return await prisma.permission.create({
      data: {
        code: data.code,
        name: data.name,
        module: data.module,
        description: data.description,
        sortOrder: data.sortOrder ?? 0
      }
    });
  }
}
```

## 审计日志

### 审计日志模型

```prisma
model AuditLog {
  id        String   @id @default(uuid())
  userId    String?  // 操作用户ID
  type      String   // 操作类型
  content   String?  // 操作内容描述
  reason    String?  // 操作原因
  severity  String   // 严重程度: INFO, WARNING, ERROR, CRITICAL
  metadata  String?  // JSON格式额外信息
  ip        String?  // 操作IP地址
  createdAt DateTime @default(now())

  @@index([userId])
  @@index([type])
  @@index([severity])
  @@index([createdAt])
}
```

### 审计日志服务

```typescript
// server/src/services/audit.service.ts

import { prisma } from '../db';

interface AuditLogData {
  userId?: string;
  type: string;
  content?: string;
  reason?: string;
  severity?: 'INFO' | 'WARNING' | 'ERROR' | 'CRITICAL';
  metadata?: Record<string, any>;
  ip?: string;
}

export class AuditService {
  /**
   * 记录审计日志
   */
  static async log(data: AuditLogData) {
    return await prisma.auditLog.create({
      data: {
        userId: data.userId,
        type: data.type,
        content: data.content,
        reason: data.reason,
        severity: data.severity ?? 'INFO',
        metadata: data.metadata ? JSON.stringify(data.metadata) : null,
        ip: data.ip
      }
    });
  }

  /**
   * 查询审计日志
   */
  static async query(params: {
    userId?: string;
    type?: string;
    severity?: string;
    startDate?: Date;
    endDate?: Date;
    page?: number;
    limit?: number;
  }) {
    const { page = 1, limit = 20, ...filters } = params;
    
    const where: any = {};
    if (filters.userId) where.userId = filters.userId;
    if (filters.type) where.type = filters.type;
    if (filters.severity) where.severity = filters.severity;
    if (filters.startDate || filters.endDate) {
      where.createdAt = {};
      if (filters.startDate) where.createdAt.gte = filters.startDate;
      if (filters.endDate) where.createdAt.lte = filters.endDate;
    }

    const [items, total] = await Promise.all([
      prisma.auditLog.findMany({
        where,
        skip: (page - 1) * limit,
        take: limit,
        orderBy: { createdAt: 'desc' },
        include: {
          user: {
            select: { nickname: true, email: true }
          }
        }
      }),
      prisma.auditLog.count({ where })
    ]);

    return { items, total, page, limit };
  }
}
```

## 前端权限控制

### 权限守卫组件

```tsx
// PermissionGuard.tsx
import React from 'react';
import { useAuth } from '../contexts/AuthContext';

interface PermissionGuardProps {
  permission?: string;
  role?: string[];
  fallback?: React.ReactNode;
  children: React.ReactNode;
}

export const PermissionGuard: React.FC<PermissionGuardProps> = ({
  permission,
  role,
  fallback = null,
  children
}) => {
  const { user, hasPermission, hasRole } = useAuth();

  if (!user) {
    return <>{fallback}</>;
  }

  // 检查角色
  if (role && !hasRole(role)) {
    return <>{fallback}</>;
  }

  // 检查权限
  if (permission && !hasPermission(permission)) {
    return <>{fallback}</>;
  }

  return <>{children}</>;
};
```


## 安全最佳实践

### 1. 最小权限原则

- 只分配完成任务所需的最小权限
- 定期审查和回收不必要的权限
- 使用临时权限提升机制

### 2. 权限分离

- 读权限和写权限分离
- 管理权限和业务权限分离
- 敏感操作需要二次确认

### 3. 审计追踪

- 所有权限变更记录日志
- 定期审计权限分配
- 异常权限使用告警
