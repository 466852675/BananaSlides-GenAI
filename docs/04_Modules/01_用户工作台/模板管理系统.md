# 模板管理系统

## 概述

模板管理系统是 YH-AI PPT 的**视觉资产管理核心模块**，负责管理 StyleTemplate（风格模板）的全生命周期。系统支持**官方模板**和**用户自定义模板**两种类型，提供模板创建、推荐、收藏、使用统计等功能，是AI生成PPT时的重要风格输入源。

## 核心功能特性

| 功能特性 | 说明 | 技术实现 |
|---------|------|---------|
| 模板CRUD | 创建、查询、更新、删除模板 | RESTful API |
| 官方模板 | 系统预设的高质量模板 | `isOfficial=true` |
| 自定义模板 | 用户基于已有项目创建的模板 | `isCustom=true` |
| 模板推荐 | 标记为推荐模板展示在首页 | `isRecommended` |
| 使用统计 | 统计模板被使用次数 | `usageCount` |
| 收藏功能 | 用户可收藏喜欢的模板 | Favorite关联 |
| 风格预览 | 生成模板预览图 | AI生成预览 |

## 数据库模型

### 1. 风格模板表 (StyleTemplate)

```prisma
model StyleTemplate {
  id             String     @id @default(uuid())
  name           String                              // 模板名称
  config         String                              // 风格配置JSON
  styleMap       String?                             // 风格图Map JSON
  
  // 模板类型标记
  isCustom       Boolean    @default(true)          // 是否自定义
  isOfficial     Boolean    @default(false)         // 是否官方
  isRecommended  Boolean    @default(false)         // 是否推荐
  
  // 统计数据
  usageCount     Int        @default(0)             // 使用次数
  favoriteCount  Int        @default(0)             // 收藏次数
  recommendCount Int        @default(0)             // 被推荐次数
  
  // 关联
  userId         String?
  user           User?      @relation(fields: [userId], references: [id])
  favorites      Favorite[]                          // 收藏记录
  
  createdAt      DateTime   @default(now())
  updatedAt      DateTime   @updatedAt
  
  @@index([isOfficial])
  @@index([isRecommended])
  @@index([userId])
}
```

### 2. StyleConfig 结构

```typescript
interface StyleConfig {
  styleName: string;           // 风格名称
  colorPalette: string;        // 配色方案
  requirements: string;        // AI视觉指令(Markdown)
  aspectRatio: string;         // 宽高比: 16:9/4:3/1:1
  targetPageCount: number;     // 推荐页数
  pageStructure: {             // 页面结构
    cover: number;
    directory: number;
    transition: number;
    content: number;
    end: number;
  };
}

// 存储为JSON字符串
template.config = JSON.stringify({
  styleName: "科技蓝",
  colorPalette: "#0A192B,#64FFDA,#8892B0",
  requirements: "# 科技蓝 AI 视觉指令\n\n## 1. 核心定位...",
  aspectRatio: "16:9",
  targetPageCount: 15,
  pageStructure: { cover: 1, directory: 1, transition: 2, content: 10, end: 1 }
});
```


## 核心算法实现

### 1. 模板列表查询

```typescript
// server/src/services/template.service.ts

export async function getTemplateList(
  options: {
    type?: 'official' | 'custom' | 'all';
    userId?: string;
    isRecommended?: boolean;
    page?: number;
    limit?: number;
  }
): Promise<{ items: StyleTemplate[]; total: number }> {
  const { type = 'all', userId, isRecommended, page = 1, limit = 20 } = options;
  
  const where: any = {};
  
  // 按类型筛选
  if (type === 'official') {
    where.isOfficial = true;
  } else if (type === 'custom' && userId) {
    where.isCustom = true;
    where.userId = userId;
  }
  
  // 推荐模板
  if (isRecommended) {
    where.isRecommended = true;
  }
  
  const [items, total] = await Promise.all([
    prisma.styleTemplate.findMany({
      where,
      orderBy: [
        { isRecommended: 'desc' },
        { usageCount: 'desc' },
        { createdAt: 'desc' }
      ],
      skip: (page - 1) * limit,
      take: limit,
      include: {
        user: {
          select: { nickname: true, email: true }
        },
        _count: {
          select: { favorites: true }
        }
      }
    }),
    prisma.styleTemplate.count({ where })
  ]);
  
  return { items, total };
}
```

### 2. 从项目创建模板

```typescript
export async function createTemplateFromProject(
  userId: string,
  projectId: string,
  name: string
): Promise<StyleTemplate> {
  // 1. 获取项目信息
  const project = await prisma.project.findUnique({
    where: { id: projectId },
    select: { globalConfig: true, styleMap: true, userId: true }
  });
  
  if (!project) throw new Error('项目不存在');
  if (project.userId !== userId) throw new Error('无权操作');
  
  // 2. 解析项目配置
  const config: StyleConfig = JSON.parse(project.globalConfig);
  
  // 3. 创建模板
  const template = await prisma.styleTemplate.create({
    data: {
      name,
      config: JSON.stringify({
        styleName: config.styleName || name,
        colorPalette: config.colorPalette,
        requirements: config.requirements,
        aspectRatio: config.aspectRatio,
        targetPageCount: config.targetPageCount,
        pageStructure: config.pageStructure
      }),
      styleMap: project.styleMap,
      isCustom: true,
      isOfficial: false,
      userId
    }
  });
  
  return template;
}
```

### 3. 使用统计更新

```typescript
export async function incrementTemplateUsage(templateId: string): Promise<void> {
  await prisma.styleTemplate.update({
    where: { id: templateId },
    data: {
      usageCount: { increment: 1 }
    }
  });
}
```

## API 接口

### 获取模板列表

**Endpoint:** `GET /api/templates?type=official&page=1&limit=20`

**Query Parameters:**
- `type`: 'official' | 'custom' | 'all'
- `isRecommended`: true | false
- `page`: 页码
- `limit`: 每页数量

**Response:**
```typescript
{
  success: true;
  data: {
    items: Array<{
      id: string;
      name: string;
      isOfficial: boolean;
      isRecommended: boolean;
      usageCount: number;
      favoriteCount: number;
      createdAt: string;
      user?: {
        nickname: string;
      };
      // 解析后的配置
      config: {
        styleName: string;
        colorPalette: string;
        aspectRatio: string;
      };
    }>;
    total: number;
    page: number;
    limit: number;
  }
}
```

### 创建模板

**Endpoint:** `POST /api/templates`

**Request Body:**
```typescript
{
  name: string;           // 模板名称
  config: StyleConfig;    // 风格配置
  styleMap?: StyleMap;    // 风格图Map
  isCustom?: boolean;     // 是否自定义
}
```

### 从项目创建

**Endpoint:** `POST /api/templates/from-project`

**Request Body:**
```typescript
{
  projectId: string;      // 源项目ID
  name: string;           // 模板名称
}
```

### 删除模板

**Endpoint:** `DELETE /api/templates/:id`

**限制:** 只能删除自己创建的模板 (`isCustom=true`)

## 前端组件

### 1. 模板卡片组件

```typescript
// src/components/TemplateCard.tsx

interface TemplateCardProps {
  template: {
    id: string;
    name: string;
    config: {
      styleName: string;
      colorPalette: string;
    };
    isOfficial: boolean;
    isRecommended: boolean;
    usageCount: number;
  };
  onSelect: (id: string) => void;
  onFavorite?: (id: string) => void;
}

export const TemplateCard: React.FC<TemplateCardProps> = ({
  template,
  onSelect,
  onFavorite
}) => {
  const colors = template.config.colorPalette.split(',');
  
  return (
    <div className="template-card" onClick={() => onSelect(template.id)}>
      {template.isRecommended && (
        <span className="recommended-badge">推荐</span>
      )}
      {template.isOfficial && (
        <span className="official-badge">官方</span>
      )}
      
      <div className="color-preview">
        {colors.slice(0, 4).map((color, i) => (
          <div
            key={i}
            className="color-swatch"
            style={{ backgroundColor: color }}
          />
        ))}
      </div>
      
      <h3>{template.name}</h3>
      <p className="style-name">{template.config.styleName}</p>
      
      <div className="stats">
        <span>使用 {template.usageCount} 次</span>
      </div>
      
      {onFavorite && (
        <button
          className="favorite-btn"
          onClick={(e) => {
            e.stopPropagation();
            onFavorite(template.id);
          }}
        >
          收藏
        </button>
      )}
    </div>
  );
};
```

### 2. 模板选择器

```typescript
// src/components/TemplateSelector.tsx

import { useQuery } from '@tanstack/react-query';

export const TemplateSelector: React.FC<{
  onSelect: (template: StyleTemplate) => void;
}> = ({ onSelect }) => {
  const [activeTab, setActiveTab] = useState<'official' | 'custom'>('official');
  
  const { data: templates } = useQuery({
    queryKey: ['templates', activeTab],
    queryFn: async () => {
      const res = await fetch(`/api/templates?type=${activeTab}`);
      return res.json();
    }
  });
  
  return (
    <div className="template-selector">
      <div className="tabs">
        <button
          className={activeTab === 'official' ? 'active' : ''}
          onClick={() => setActiveTab('official')}
        >
          官方模板
        </button>
        <button
          className={activeTab === 'custom' ? 'active' : ''}
          onClick={() => setActiveTab('custom')}
        >
          我的模板
        </button>
      </div>
      
      <div className="template-grid">
        {templates?.data?.items.map(template => (
          <TemplateCard
            key={template.id}
            template={template}
            onSelect={() => onSelect(template)}
          />
        ))}
      </div>
    </div>
  );
};
```
