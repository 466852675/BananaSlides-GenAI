# 模板概念分析

## 概述

模板概念分析是 YH-AI PPT 的**视觉风格提取引擎**，通过AI分析用户提供的参考图片或文本描述，自动提取视觉风格特征，生成结构化的设计规范（StyleConfig）。系统支持**双模输入**（图片+文本），实现"一张参考图 = 整套设计风格"的智能转换。

## 核心功能特性

| 功能特性 | 说明 | 技术亮点 |
|---------|------|---------|
| Vision分析 | 使用Vision模型解析参考图 | 提取颜色、构图、风格 |
| 文本理解 | 分析用户描述生成规范 | 自然语言理解 |
| 双模融合 | 图片+文本联合分析 | 互补信息融合 |
| 结构化输出 | 生成标准化StyleConfig | 可直接用于生成 |
| 多场景适配 | BUSINESS/ACADEMIC/CREATIVE | 场景化Prompt |
| 积分扣费 | 视觉分析2积分/次 | VIP享折扣 |

## 系统架构

### 1. 双模输入架构

```
用户输入
    ├── 图片上传 → Vision模型分析
    │               ├── 主色调提取
    │               ├── 构图分析
    │               ├── 风格识别
    │               └── 元素提取
    │
    └── 文本描述 → 语义理解
                    ├── 场景识别
                    ├── 情感分析
                    └── 需求抽取
                          ↓
                    信息融合引擎
                          ↓
                    StyleConfig生成
```

### 2. 输出结构

```typescript
interface StyleConfig {
  // 基础信息
  styleName: string;           // 风格名称 (如: "科技蓝", "极简白")
  scenarioType: string;        // 场景类型: BUSINESS/ACADEMIC/CREATIVE
  
  // 视觉规范
  colorPalette: string;        // 配色方案 (JSON字符串)
  requirements: string;        // AI视觉指令 (Markdown格式)
  aspectRatio: string;         // 宽高比: 16:9/4:3/1:1/9:16
  
  // 页面配置
  targetPageCount: number;     // 推荐页数: 10-30
  pageStructure: {
    cover: number;             // 封面页数
    directory: number;         // 目录页数
    transition: number;        // 过渡页数
    content: number;           // 内容页数
    end: number;               // 结束页数
  };
  
  // 高级配置
  fontFamily?: string;         // 字体方案
  imageStyle?: string;         // 图片风格
  animationHint?: string;      // 动画建议
}
```

## 核心算法实现

### 1. Vision图片分析

```typescript
// server/src/services/ai.service.ts

async analyzeTemplateConcept(
    input: string | { path: string; mimeType: string },
    settings?: AppSettings
): Promise<StyleConfig> {
    
    const config = await resolveActiveConfig(settings, 'vision');
    
    // 判断输入类型
    const isImageInput = typeof input === 'object' && 
        input.mimeType?.startsWith('image/');
    
    if (isImageInput) {
        // 图片模式：Vision分析
        return analyzeImageStyle(input.path, config, settings);
    } else {
        // 文本模式：直接生成
        return analyzeTextStyle(input as string, config, settings);
    }
}

/**
 * Vision图片风格分析
 */
async function analyzeImageStyle(
    imagePath: string,
    config: ModelConnection,
    settings?: AppSettings
): Promise<StyleConfig> {
    
    const base64 = await resourceToBase64(imagePath);
    
    const prompt = `
Role: 顶级PPT视觉分析师
Task: 分析这张参考图片，提取完整的视觉风格规范

分析维度：
1. 【风格命名】: 给这个风格起一个专业名称（2-4个字）
2. 【场景类型】: 最适合的应用场景 (BUSINESS/ACADEMIC/CREATIVE)
3. 【主色调】: 提取主要颜色（背景色、主色、强调色、文字色）
4. 【设计风格】: 描述整体设计风格（如：极简主义、科技感、商务风）
5. 【视觉元素】: 识别关键视觉元素（线条、图形、纹理）
6. 【字体风格】: 建议的字体类型（衬线/无衬线、粗体/细体）
7. 【适用场景】: 这种风格最适合什么类型的演示

输出格式（JSON）:
{
  "styleName": "风格名称",
  "scenarioType": "BUSINESS",
  "colorPalette": {
    "background": "#0A192B",
    "primary": "#64FFDA",
    "accent": "#8892B0",
    "text": "#CCD6F6"
  },
  "designStyle": "详细风格描述",
  "visualElements": ["元素1", "元素2"],
  "fontStyle": "字体建议",
  "suitableFor": ["场景1", "场景2"]
}
`;

    if (shouldUseGeminiNative(config, settings)) {
        const ai = createGoogleClient(config);
        const contents = [
            { inlineData: { mimeType: 'image/png', data: base64 } },
            { text: prompt }
        ];
        
        const response = await ai.models.generateContent({
            model: config.model,
            contents: { parts: contents } as any,
            config: {
                responseMimeType: "application/json"
            }
        });
        
        const analysis = JSON.parse(response.text || '{}');
        return convertAnalysisToStyleConfig(analysis);
    } else {
        // OpenAI Compatible Vision API
        const messages = [
            {
                role: "user",
                content: [
                    { type: "text", text: prompt },
                    { type: "image_url", image_url: { url: `data:image/png;base64,${base64}` } }
                ]
            }
        ];
        
        const result = await callOpenAICompatible(config, messages, 0.7, true, 'vision');
        const analysis = JSON.parse(result);
        return convertAnalysisToStyleConfig(analysis);
    }
}
```

```typescript
async function analyzeTextStyle(

用户需求: "${description}"

请生成以下内容的StyleConfig：
1. 风格名称 (简洁有力)
2. 场景类型 (BUSINESS/ACADEMIC/CREATIVE)
3. 配色方案 (4个核心颜色)
4. AI视觉指令 (详细的Markdown格式设计规范)
5. 推荐页面配置 (总页数、页面结构)

输出格式（JSON）:
{
  "styleName": "...",
  "scenarioType": "...",
  "colorPalette": "#color1,#color2,#color3,#color4",
  "requirements": "Markdown格式的详细视觉规范",
  "targetPageCount": 15,
  "pageStructure": { "cover": 1, "directory": 1, "transition": 2, "content": 10, "end": 1 }
}
`;

    const messages = [{ role: "user", content: prompt }];
    const result = await callOpenAICompatible(config, messages, 0.7, true, 'text');
    return JSON.parse(result);
}
```

### 3. 分析结果转换

```typescript
/**
 * 将Vision分析结果转换为StyleConfig
 */
function convertAnalysisToStyleConfig(analysis: any): StyleConfig {
    // 构建颜色调色板
    const colorPalette = [
        analysis.colorPalette?.background || '#FFFFFF',
        analysis.colorPalette?.primary || '#333333',
        analysis.colorPalette?.accent || '#666666',
        analysis.colorPalette?.text || '#000000'
    ].join(',');

    // 构建AI视觉指令
    const requirements = buildVisualRequirements(analysis);

    // 推荐页面结构
    const pageStructure = getRecommendedStructure(analysis.scenarioType);

    return {
        styleName: analysis.styleName || '自定义风格',
        scenarioType: analysis.scenarioType || 'BUSINESS',
        colorPalette,
        requirements,
        aspectRatio: '16:9',
        targetPageCount: pageStructure.total,
        pageStructure: pageStructure.breakdown
    };
}

/**
 * 构建视觉指令Markdown
 */
function buildVisualRequirements(analysis: any): string {
    return `# ${analysis.styleName} AI 视觉指令

## 1. 核心定位
* **角色设定**: ${analysis.designStyle}风格设计师
* **应用场景**: ${analysis.suitableFor?.join('、') || '通用演示'}
* **视觉关键词**: ${analysis.visualElements?.join('、') || '专业、简洁'}

## 2. 总体视觉规范
* **设计美学**: ${analysis.designStyle}
* **色彩方案 (${analysis.styleName})**:
    * **背景色**: ${analysis.colorPalette?.background}
    * **核心主色**: ${analysis.colorPalette?.primary}
    * **强调色**: ${analysis.colorPalette?.accent}
    * **文字色**: ${analysis.colorPalette?.text}
* **字体建议**: ${analysis.fontStyle || '无衬线字体，层次分明'}

## 3. 页面类型详细指令
### [封面页] 
* **布局**: 根据${analysis.designStyle}风格设计，突出主题
* **元素**: ${analysis.visualElements?.[0] || '简洁图形'}作为背景装饰
* **氛围**: ${analysis.suitableFor?.[0] || '专业'}、大气

### [内容页]
* **布局**: 模块化设计，信息层次清晰
* **图表**: 与整体风格一致的配色
* **特点**: 保持${analysis.designStyle}的视觉统一性
`;
}
```

## API 接口

### 分析模板概念

**Endpoint:** `POST /api/ai/analyze-template-concept`

**Request Body (图片模式):**
```typescript
{
  input: {
    path: string;        // 图片路径 (如: /uploads/style-ref.png)
    mimeType: string;    // image/png
  };
  projectId?: string;
  triggerTime?: string;
}
```

**Request Body (文本模式):**
```typescript
{
  input: string;         // 描述文本 (如: "科技公司年会，蓝色主调")
  projectId?: string;
  triggerTime?: string;
```

**Response:**
```typescript
{
  success: true;
```

## 前端集成

### 1. 参考图上传组件

```typescript
// src/components/StyleReferenceUploader.tsx

import { useState } from 'react';

export const StyleReferenceUploader: React.FC<{
  onAnalyzed: (config: StyleConfig) => void;
}> = ({ onAnalyzed }) => {
  const [uploading, setUploading] = useState(false);

  const handleUpload = async (file: File) => {
    setUploading(true);
    
    // 1. 上传图片
    const formData = new FormData();
    formData.append('file', file);
    
    const uploadRes = await fetch('/api/upload', {
      method: 'POST',
      body: formData
    });
    const { path } = await uploadRes.json();
    
    // 2. Vision分析
    const analyzeRes = await fetch('/api/ai/analyze-template-concept', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        input: { path, mimeType: file.type }
      })
    });
    
    const result = await analyzeRes.json();
    onAnalyzed(result.data);
    setUploading(false);
  };

  return (
    <div className="style-reference-uploader">
      <input
        type="file"
        accept="image/*"
        onChange={(e) => e.target.files?.[0] && handleUpload(e.target.files[0])}
        disabled={uploading}
      />
      {uploading && <span>分析中...</span>}
    </div>
  );
};
```
