# 大纲生成

## 概述

大纲生成是 YH-AI PPT 智能演示文稿创作的核心入口功能，负责将用户输入的主题转换为结构化的 PPT 页面大纲。系统采用**智能页面序列算法**，根据用户指定的总页数和页面结构配比，自动生成符合演示逻辑的完整大纲。

## 核心功能特性

| 功能特性 | 说明 | 实现位置 |
|---------|------|---------|
| 主题输入 | 支持用户输入主题描述或上传文档 | `ai.controller.ts` |
| 页面配置 | 支持自定义总页数、页面结构配比 | `ai.service.ts` |
| AI 生成 | 调用大语言模型生成结构化大纲 JSON | `ai.service.ts` |
| 单页重写 | 支持对大纲中的单个页面进行重新生成 | `ai.controller.ts` |
| 积分扣费 | 登录用户消耗 1 积分，未登录免费 | `points.service.ts` |

**Endpoint:** `POST /api/ai/generate-outline`

**Headers:**
```
Authorization: Bearer <token>  // 可选，未登录也能访问
Content-Type: application/json
```

**Request Body:**
```typescript
{
  topic: string;        // 主题描述
  configStyle: {
    targetPageCount: number;  // 目标页数 (默认10)
    pageStructure: {

      directory: number;  // 目录页数量 (默认1)
      transition: number; // 过渡页数量 (默认0)
```

**Response:**
```typescript

  pointsDeducted: number; // 扣除积分
```

## 核心算法实现

### 1. 页面结构自动校准算法

```typescript
// server/src/services/ai.service.ts

async generateOutline(topic: string, configStyle: StyleConfig, settings: AppSettings): Promise<OutlineItem[]> {
    const { targetPageCount, pageStructure } = configStyle;
    const structure = { ...(pageStructure || { cover: 1, directory: 1, transition: 0, content: 7, end: 1 }) };

    // 【核心算法】自动校准正文页数，确保总数一致
    const fixedSum = (structure.cover || 0) 
                   + (structure.directory || 0) 
                   + (structure.transition || 0) 
                   + (structure.end || 0);
    
    // content页数 = 总页数 - 固定页面数，至少保证1页内容
    structure.content = Math.max(1, targetPageCount - fixedSum);

    // 生成页面序列
    const seq: Array<'cover' | 'directory' | 'transition' | 'content' | 'end'> = [];
    for (let i = 0; i < (structure.cover || 0); i++) seq.push('cover');
    for (let i = 0; i < (structure.directory || 0); i++) seq.push('directory');
    for (let i = 0; i < (structure.transition || 0); i++) seq.push('transition');
    for (let i = 0; i < (structure.content || 0); i++) seq.push('content');
    for (let i = 0; i < (structure.end || 0); i++) seq.push('end');

    // 截取到目标页数
    const sliced = seq.slice(0, targetPageCount || seq.length);
    
    // 调用AI生成每个页面的标题和摘要
    return await generateWithAI(topic, sliced);
}
```

```typescript
    }

    1. 封面和结束页首尾呼应
    2. 目录页涵盖所有正文章节
    3. 正文页之间有逻辑递进关系
    4. 过渡页在主要章节之间插入
`;
```

### 3. 页面序列生成逻辑

```typescript
// 默认页面序列生成顺序
const generatePageSequence = (structure: PageStructure): PageType[] => {
    const sequence: PageType[] = [];
    
    // 1. 封面页 (必须)
    for (let i = 0; i < structure.cover; i++) {
        sequence.push('cover');
    }
    
    // 2. 目录页 (必须)
    for (let i = 0; i < structure.directory; i++) {
        sequence.push('directory');
    }
    
    // 3. 正文+过渡交替
    const contentPerTransition = Math.ceil(
        structure.content / (structure.transition + 1)
    );
    let contentCount = 0;
    let transitionCount = 0;
    
    for (let i = 0; i < structure.content; i++) {
        // 每隔一定内容页插入过渡页
        if (contentCount > 0 && 
            contentCount % contentPerTransition === 0 && 
            transitionCount < structure.transition) {
            sequence.push('transition');
            transitionCount++;
        }
        sequence.push('content');
        contentCount++;
    }
    
    // 4. 结束页 (必须)
    for (let i = 0; i < structure.end; i++) {
        sequence.push('end');
    }
    
    return sequence;
};
```

### 2. 后端扣费逻辑

```typescript
// server/src/controllers/ai.controller.ts

export const handleGenerateOutline = async (req: Request, res: Response) => {
    const { topic, configStyle, projectId, triggerTime } = req.body;
    
    try {
        // 1. 积分扣费（登录用户扣费，未登录免费）
        if (req.user && process.env.MOCK_AI !== '1') {
            const deductResult = await PointsService.deductPoints(
                req.user.id,
                'outline_generation',  // 积分规则代码
                projectId,
                undefined,             // 描述
                1,                     // 倍数
                {
                    module: '创作室',
                    category: '文本生成',
                    subcategory: '大纲生成',
                    triggerTime: triggerTime ? new Date(triggerTime) : undefined
                }
            );
            
            if (!deductResult.success) {
                // 402 Payment Required
                res.status(402).json({
                    success: false,
                    error: { 
                        code: 'INSUFFICIENT_POINTS', 
                        message: deductResult.message 
                    }
                });
                return;
            }
            
            // 记录扣费信息用于后续回滚
            (res as any).deductedPoints = deductResult.deductedAmount;
            (res as any).transactionId = deductResult.transactionId;
        }

        // 2. 调用AI服务生成大纲
        const settings = await getServerSettings();
        const result = await AIService.generateOutline(topic, configStyle, settings);

        // 3. 标记交易完成
        if ((res as any).transactionId) {
            await PointsService.completeTransaction((res as any).transactionId);
        }

        res.json({ 
            success: true, 
            data: result, 
            pointsDeducted: (res as any).deductedPoints 
        });
        
    } catch (error: any) {
        // 4. 失败时退还积分
        if (req.user && (res as any).deductedPoints > 0) {
            await PointsService.refundPoints(
                req.user.id, 
                (res as any).deductedPoints, 
                (res as any).transactionId
            );
        }
        res.status(500).json({ success: false, error: error.message });
    }
};
```

## 前端组件

### 1. 大纲生成器组件

```typescript
// src/components/OutlineGenerator.tsx

import React, { useState } from 'react';
import { useAuth } from '../contexts/AuthContext';

interface OutlineGeneratorProps {
  onOutlineGenerated: (outline: OutlineItem[]) => void;
  initialTopic?: string;
}

export const OutlineGenerator: React.FC<OutlineGeneratorProps> = ({
  onOutlineGenerated,
  initialTopic = ''
}) => {
  const { user } = useAuth();
  const [topic, setTopic] = useState(initialTopic);
  const [config, setConfig] = useState({
    targetPageCount: 10,
    pageStructure: {
      cover: 1,
      directory: 1,
      transition: 0,
      content: 7,
      end: 1
    }
  });
  const [loading, setLoading] = useState(false);

  const handleGenerate = async () => {
    if (!topic.trim()) {
      toast.error('请输入主题');
      return;
    }

    // 检查积分（前端预检）
    if (user && user.points < 1) {
      toast.error('积分不足，请充值');
      return;
    }

    setLoading(true);
    try {
      const response = await fetch('/api/ai/generate-outline', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          'Authorization': `Bearer ${localStorage.getItem('token')}`
        },
        body: JSON.stringify({
          topic,
          configStyle: config,
          triggerTime: new Date().toISOString()
        })
      });

      if (response.status === 402) {
        const error = await response.json();
        toast.error(error.error.message || '积分不足');
        return;
      }

      const result = await response.json();
      if (result.success) {
        onOutlineGenerated(result.data);
        toast.success(`大纲生成成功${result.pointsDeducted ? `，消耗 ${result.pointsDeducted} 积分` : ''}`);
      }
    } catch (error) {
      toast.error('生成失败，请重试');
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="outline-generator">
      <input
        value={topic}
        onChange={(e) => setTopic(e.target.value)}
        placeholder="输入PPT主题..."
      />
      
      <div className="page-config">
        <label>总页数: {config.targetPageCount}</label>
        <input
          type="range"
          min="5"
          max="30"
          value={config.targetPageCount}
          onChange={(e) => setConfig({
            ...config,
            targetPageCount: parseInt(e.target.value)
          })}
        />
      </div>

      <button onClick={handleGenerate} disabled={loading}>
        {loading ? '生成中...' : '生成大纲'}
      </button>
    </div>
  );
};
```

## 页面类型详解

### 1. 封面页 (cover)

**功能：** 展示演示主题，建立第一印象

**AI生成要点：**
- 标题简洁有力，突出核心主题
- 副标题补充说明背景或视角
- 配合大纲主题生成相关视觉描述

**示例输出：**
```json
{
  "title": "AI人工智能发展趋势：2024年度洞察",
  "brief": "从技术突破到产业应用，全面解析AI如何重塑商业格局",
  "pageType": "cover"
}
```

### 2. 目录页 (directory)

**功能：** 展示整体结构，帮助观众建立认知地图

**AI生成要点：**
- 从正文页面标题中提取章节名
- 确保涵盖所有主要章节
- 层次分明，逻辑清晰

### 3. 过渡页 (transition)

**功能：** 章节之间的视觉和逻辑过渡

**AI生成要点：**
- 承上启下，总结前一章节
- 预告下一章节核心内容
- 保持与整体风格一致

### 4. 内容页 (content)

**功能：** 详细阐述核心观点和论据

**AI生成要点：**
- 每个页面聚焦一个核心论点
- 提供3-5个支撑要点
- 预留数据可视化空间

### 5. 结束页 (end)

**功能：** 总结核心观点，留下深刻印象

**AI生成要点：**
- 提炼3个核心结论
- 呼应封面主题
- 避免使用占位符信息（电话、邮箱等）

## 错误处理

### 1. 常见错误码

| 错误码 | HTTP状态码 | 说明 | 处理建议 |
|--------|-----------|------|---------|
| INSUFFICIENT_POINTS | 402 | 积分不足 | 提示用户充值或购买VIP |
| AI_SERVICE_ERROR | 500 | AI服务异常 | 自动重试或切换模型 |
| TIMEOUT | 504 | 生成超时 | 提示用户简化主题或稍后重试 |
| INVALID_TOPIC | 400 | 主题无效 | 提示用户输入更详细的主题描述 |

### 2. 容错机制

