# 幻灯片正文生成

## 概述

幻灯片正文生成是 YH-AI PPT 的**核心内容生成能力**，负责将大纲中的简要描述（brief）扩展为结构完整、内容丰富的幻灯片正文。系统采用**上下文感知生成策略**，根据页面在整体演示中的位置、页面类型和主题背景，生成符合场景的专业内容。

## 核心功能特性

| 功能特性 | 说明 | 技术亮点 |
|---------|------|---------|
| 内容扩写 | 将50字brief扩展为200字专业内容 | 上下文感知、语义保持 |
| 智能分段 | 自动划分要点、论据、结论 | 结构化输出 |
| 设计建议 | 生成可视化排版建议 | 分离内容与表现 |
| 页面适配 | 根据页面类型调整内容深度 | 动态长度控制 |
| 批量生成 | 支持多页面并行生成 | 异步队列处理 |
| 积分扣费 | 每页消耗1积分 | VIP享折扣 |

### 1. 数据流

```
用户点击"生成正文"
    ↓
前端: 收集页面上下文
  ├── 主题上下文 (Topic Context)
  ├── 页面标题 (Title)
  ├── 内容摘要 (Brief)
  ├── 页面序号 (Index/Total)
  └── 页面类型 (PageType)
    ↓
POST /api/ai/generate-slide-detail
    ↓
ai.service.ts → generateSlideDetail()
    ↓
构建Prompt (含上下文信息)
    ↓
AI模型生成内容
    ↓
解析内容与分离设计建议
    ↓
返回: { content: string, designSuggestion: string }
    ↓
前端: 更新SlideEditor内容
```

## 核心算法实现

### 1. Prompt构建策略

```typescript
// server/src/services/ai.service.ts

async generateSlideDetail(
    title: string,
    brief: string,
    topicContext: string,
    index: number,
    total: number,
    pageType: string,
    settings?: AppSettings
): Promise<string> {
    
    const config = await resolveActiveConfig(settings, 'text');
    
    // 构建上下文感知的Prompt
    const prompt = `Topic Context: ${topicContext}
        Slide Title: ${title}
        Slide Intent: ${brief}
        
        Structural Context:
        - This is slide ${index} of ${total} in the entire presentation.
        - Page Type: ${pageType}
        
        Task: Write the full, detailed content for this slide.
        
        Requirements:
        1. Language: Strictly Simplified Chinese (简体中文).
        2. Include bullet points, key arguments, or data placeholders.
        3. Use a professional tone.
        4. Content length: ${pageType === 'content' ? '150-250' : '50-100'} words.
        
        [CRITICAL VISUAL INSTRUCTION]:
        At the end of your response (after the content), you MUST append a specific design suggestion field:
        
        Format:
        ---DESIGN_SUGGESTION_START---
        **设计建议：** <Your suggestion here>
        
        Instructions for this field:
        - Act as a Senior Art Director.
        - FOCUS ONLY on Layout, Structure, Charts, Shapes, and Icons.
        - [STRICTLY FORBIDDEN]: Do NOT mention colors, palettes, art styles, or lighting.
        - [Layout]: Suggest the best layout (e.g., 'Left-Right Split', 'Timeline', '3-Column Card').
        - [Hierarchy]: Define visual weight (e.g., "Make the Central Concept 2x larger than supporting points").
        - [Logic]: Define connection logic (e.g., "Use arrows to show flow A -> B").
        - [Shapes]: Suggest visual metaphors (e.g., 'Funnel', 'Honeycomb', 'Pyramid').
        `;

    // 调用AI模型
    if (shouldUseGeminiNative(config, settings)) {
        const ai = createGoogleClient(config);
        const response = await ai.models.generateContent({
            model: config.model,
            contents: prompt,
        });
        return response.text?.trim() || "";
    } else {
        const messages = [{ role: "user", content: prompt }];
        return await callOpenAICompatible(config, messages, 0.7, false, 'text');
    }
}
```

### 2. 内容与建议分离

```typescript
/**
 * 从生成的内容中分离正文和设计建议
 */
function parseSlideContent(rawContent: string): {
    content: string;
    designSuggestion: string;
} {
    const SEPARATOR = "---DESIGN_SUGGESTION_START---";
    
    if (rawContent.includes(SEPARATOR)) {
        const parts = rawContent.split(SEPARATOR);
        return {
            content: parts[0].trim(),
            designSuggestion: parts[1]
                .replace(/\*\*设计建议：?\*\*/, '')
                .trim()
        };
    } else {
        // 回退：尝试正则提取
        const suggestionMatch = rawContent.match(/\*\*设计建议：?\*\*[\s\S]*$/);
        if (suggestionMatch) {
            return {
                content: rawContent.substring(0, suggestionMatch.index).trim(),
                designSuggestion: suggestionMatch[0]
                    .replace(/\*\*设计建议：?\*\*/, '')
                    .trim()
            };
        }
        
        // 无建议，全部作为内容
        return {
            content: rawContent.trim(),
            designSuggestion: ""
        };
    }
}
```

### 3. 批量生成优化

```typescript
/**
 * 批量生成多个幻灯片的正文
 * 使用Promise.allSettled实现并行生成
 */
async function batchGenerateSlideDetails(
    slides: Array<{
        id: string;
        title: string;
        brief: string;
        index: number;
    }>,
    topicContext: string,
    settings?: AppSettings
): Promise<Array<{
    slideId: string;
    content: string;
    designSuggestion: string;
    status: 'fulfilled' | 'rejected';
}>> {
    
    const total = slides.length;
    
    // 并行生成所有幻灯片
    const promises = slides.map((slide, idx) => 
        generateSlideDetail(
            slide.title,
            slide.brief,
            topicContext,
            slide.index,
            total,
            'content',
            settings
        ).then(content => {
            const parsed = parseSlideContent(content);
            return {
                slideId: slide.id,
                ...parsed,
                status: 'fulfilled' as const
            };
        }).catch(error => ({
            slideId: slide.id,
            content: '',
            designSuggestion: '',
            status: 'rejected' as const,
            error: error.message
        }))
    );
    
    return Promise.allSettled(promises).then(results => 
        results.map((result, idx) => 
            result.status === 'fulfilled' 
                ? result.value 
                : {
                    slideId: slides[idx].id,
                    content: '',
                    designSuggestion: '',
                    status: 'rejected' as const,
                    error: result.reason?.message || '生成失败'
                }
        )
    );
}
```

## 页面类型适配策略

### 1. 内容页 (content)

**内容长度**: 150-250字

**生成策略**:
- 提供3-5个核心论点
- 每个论点包含论据支撑
- 添加数据占位符 (如: [插入市场份额图])
- 总结句提炼核心价值

**示例输出**:
```markdown
## 核心观点
AI技术正在重塑企业运营模式

## 关键论据
- **效率提升**: 自动化流程减少人工操作80%，释放员工创造力
- **成本优化**: 智能决策系统降低运营成本平均达35%
- **精准营销**: 基于用户行为的个性化推荐，转化率提升3-5倍
- **风险管控**: 实时监控系统识别潜在风险，响应时间缩短至分钟级

## 数据支撑
[建议插入: AI adoption rate chart showing 60% enterprise adoption in 2024]

## 核心结论
企业应将AI视为战略投资而非成本中心，早期布局者将在未来3年获得显著竞争优势。
```

### 2. 封面页 (cover)

**内容长度**: 50-100字

**生成策略**:
- 突出主题和副标题
- 简洁的背景介绍
- 演讲者/公司信息占位

### 3. 目录页 (directory)

**内容长度**: 50-100字

**生成策略**:
- 列出所有章节标题
- 简要说明各章节逻辑关系
- 预计时长分配

### 4. 过渡页 (transition)

**内容长度**: 50-100字

**生成策略**:
- 总结前一章节核心观点
- 预告下一章节内容
- 承上启下的过渡语句

### 5. 结束页 (end)

**内容长度**: 50-100字

**生成策略**:
- 3个核心结论
- 行动号召 (Call to Action)
- 避免使用占位符信息

## 设计建议规范

### 1. 布局建议 (Layout)

| 布局类型 | 适用场景 | 示例描述 |
|---------|---------|---------|
| 左右分栏 | 对比分析 | "左侧放核心概念，右侧放3个支撑要点" |
| 时间轴 | 发展历程 | "横向时间轴展示3个发展阶段" |
| 中心放射 | 核心概念 | "中心放主概念，四周放射状分布4个子模块" |
| 三栏卡片 | 并列观点 | "三等分布局，每栏一个观点+图标" |
| 上下分层 | 因果关系 | "上半部分原因分析，下半部分结果展示" |

### 2. 层级建议 (Hierarchy)

```
层级定义规范:
- 层级1 (Hero): 页面核心概念，尺寸最大，位置最醒目
- 层级2 (Supporting): 支撑论点，尺寸中等，环绕核心
- 层级3 (Details): 细节说明，小尺寸，辅助信息
```

### 3. 逻辑可视化 (Logic)

| 逻辑关系 | 可视化方式 | 示例 |
|---------|-----------|------|
| 流程关系 | 箭头连接 | "A → B → C 流程图" |
| 对比关系 | 左右对比框 | "左侧传统方案 vs 右侧AI方案" |
| 包含关系 | 同心圆/嵌套框 | "大圆包含3个小圆" |
| 并列关系 | 并列卡片/列表 | "3个等宽卡片横向排列" |
| 递进关系 | 阶梯/金字塔 | "从下到上的3层金字塔" |

### 4. 形状建议 (Shapes)

| 视觉隐喻 | 形状 | 适用内容 |
|---------|------|---------|
| 流程转化 | 漏斗 | 销售转化、数据筛选 |
| 结构组织 | 蜂窝 | 模块化架构、生态系统 |
| 层级关系 | 金字塔 | 马斯洛需求、优先级 |
| 循环迭代 | 环形 | 闭环流程、持续改进 |
| 发散思维 | 思维导图 | 头脑风暴、关联分析 |

## API 接口

### 生成幻灯片正文

**Endpoint:** `POST /api/ai/generate-slide-detail`

**Request Body:**
```typescript
{
  title: string;           // 页面标题
  brief: string;           // 内容摘要
  topicContext: string;    // 整体主题上下文
  index: number;           // 当前页码 (1-based)
  total: number;           // 总页数
  pageType: string;        // content/cover/directory/transition/end
  projectId?: string;
  triggerTime?: string;
}
```

**Response:**
```typescript
{
  success: true;
  data: {
    content: string;           // 正文内容 (Markdown)
    designSuggestion: string;  // 设计建议
  };
  pointsDeducted: number;
}
```

## 前端集成

### 1. SlideEditor 组件集成

```typescript
// src/components/SlideEditor.tsx

import { useMutation } from '@tanstack/react-query';

export const SlideEditor: React.FC<{
  slide: Slide;
  project: Project;
}> = ({ slide, project }) => {
  const generateDetail = useMutation({
    mutationFn: async () => {
      const res = await fetch('/api/ai/generate-slide-detail', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          title: slide.title,
          brief: slide.brief,
          topicContext: project.title,
          index: slide.index,
          total: project.items.length,
          pageType: slide.pageType,
          projectId: project.id
        })
      });
      return res.json();
    },
    onSuccess: (data) => {
      // 更新编辑器内容
      setContent(data.data.content);
      // 保存设计建议到slide
      setDesignSuggestion(data.data.designSuggestion);
    }
  });

  return (
    <div className="slide-editor">
      <button 
        onClick={() => generateDetail.mutate()}
        disabled={generateDetail.isPending}
      >
        {generateDetail.isPending ? '生成中...' : 'AI扩写正文'}
      </button>
      
      <textarea 
        value={content}
        onChange={(e) => setContent(e.target.value)}
      />
      
      {designSuggestion && (
        <div className="design-suggestion">
          <h4>设计建议</h4>
          <p>{designSuggestion}</p>
        </div>
      )}
    </div>
  );
};
```

### 2. 批量生成按钮

```typescript
// 批量生成所有幻灯片正文
const batchGenerate = useMutation({
  mutationFn: async () => {
    const slidesWithoutContent = project.items.filter(
      slide => !slide.content || slide.content.length < 50
    );
    
    const res = await fetch('/api/ai/batch-generate-details', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        slides: slidesWithoutContent.map(s => ({
          id: s.id,
          title: s.title,
          brief: s.brief,
          index: s.index,
          pageType: s.pageType
        })),
        topicContext: project.title,
        projectId: project.id
      })
    });
    
    return res.json();
  },
  onSuccess: (data) => {
    // 批量更新所有slide
    data.data.forEach((result: any) => {
      updateSlide(result.slideId, {
        content: result.content,
        designSuggestion: result.designSuggestion
      });
    });
  }
});
```
