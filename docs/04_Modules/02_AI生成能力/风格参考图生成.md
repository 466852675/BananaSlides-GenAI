# 风格参考图生成

## 概述

风格参考图生成是 YH-AI PPT 的**视觉预览系统**，基于已解析的 StyleConfig 生成单页示例图，让用户在正式生成整套PPT前直观预览视觉风格效果。系统支持**5种页面类型**的风格预览，采用**模拟内容生成策略**，确保预览图既展示风格特征又符合页面类型特点。

## 核心功能特性

| 功能特性 | 说明 | 技术亮点 |
|---------|------|---------|
| 5页面预览 | 封面/目录/过渡/内容/结束 | 全场景覆盖 |
| 模拟内容 | AI生成页面类型适配的示例内容 | 真实感强 |
| 快速预览 | 单页生成，速度更快 | 用户体验优化 |
| 风格复用 | 内部复用幻灯片生成逻辑 | 代码复用 |
| 积分扣费 | 5积分/张（与图片生成一致） | VIP享折扣 |

## 系统架构

### 1. 数据流

```
用户选择页面类型 (如: cover)
    ↓
构建模拟内容
  ├── 页面类型 → 示例标题
  ├── StyleConfig → 风格参数
  └── 生成模拟正文
    ↓
调用 generateStyleReference()
    ↓
复用 generateSlideVariant() 逻辑
    ↓
返回风格参考图URL
    ↓
前端展示预览
```

## 核心算法实现

### 1. 风格参考图生成服务

```typescript
// server/src/services/ai.service.ts

/**
 * 生成风格参考图
 * 复用幻灯片变体生成逻辑，但使用模拟内容
 */
async generateStyleReference(
    configStyle: StyleConfig,
    pageType: 'cover' | 'directory' | 'transition' | 'content' | 'end',
    settings?: AppSettings
): Promise<string> {
    
    // 1. 构建模拟内容
    const mockContent = buildMockContent(pageType, configStyle);
    
    // 2. 复用幻灯片生成逻辑
    // 注意：不传递风格参考图(styleFile=null)，让AI基于configStyle生成
    return await this.generateSlideVariant(
        mockContent.text,           // 模拟文本内容
        null,                       // 无风格参考图（关键区别）
        configStyle,                // 风格配置
        `style-ref-${pageType}`,    // 变体标签
        mockContent.title,          // 标题
        settings,
        'text',                     // 内容类型
        undefined,                  // MIME类型
        pageType                    // 页面类型
    );
}

/**
 * 构建页面类型适配的模拟内容
 */
function buildMockContent(
    pageType: string,
    configStyle: StyleConfig
): { title: string; text: string } {
    
    switch (pageType) {
        case 'cover':
            return {
                title: configStyle.styleName || "示例标题",
                text: `演示主题：${configStyle.styleName}风格示例\n副标题：AI驱动的专业演示文稿`
            };
            
        case 'directory':
            return {
                title: "目录",
                text: `第一章：背景与概述\n第二章：核心方案\n第三章：实施计划\n第四章：总结展望`
            };
            
        case 'transition':
            return {
                title: "章节过渡",
                text: `第一部分总结\n\n第二部分预告：深入解析`
            };
            
        case 'content':
            return {
                title: "核心要点",
                text: `• 要点一：示例内容展示\n• 要点二：风格特征体现\n• 要点三：排版布局预览\n\n详细说明：这段文字用于展示${configStyle.styleName || '该风格'}下的正文排版效果。`
            };
            
        case 'end':
            return {
                title: "谢谢观看",
                text: `核心结论：风格预览完成\n\n感谢您的关注`
            };
            
        default:
            return {
                title: "示例页面",
                text: "这是一个风格参考示例页面。"
            };
    }
}
```

### 2. 与正式生成的区别

```typescript
/**
 * 关键区别对比

// 正式幻灯片生成：有内容 + 有风格参考图
async generateSlideVariant(
    contentSource: string,      // ✅ 真实内容
    styleFile: string,          // ✅ 风格参考图路径
    configStyle: StyleConfig,
    ...
)

// 风格参考图生成：模拟内容 + 无风格参考图
async generateStyleReference(
    configStyle: StyleConfig,
    pageType: string
) {
    return generateSlideVariant(
        mockContent,             // ✅ 模拟内容
        null,                    // ✅ 无风格参考图（让AI基于configStyle生成）
        configStyle,
        ...
    );
}
```

## API 接口

### 生成风格参考图

**Endpoint:** `POST /api/ai/generate-style-reference`

**Request Body:**
```typescript
{
  configStyle: {
    styleName: string;        // 风格名称
    colorPalette: string;     // 配色方案
    requirements: string;     // AI视觉指令
    aspectRatio: string;      // 宽高比
  };
  pageType: 'cover' | 'directory' | 'transition' | 'content' | 'end';
  projectId?: string;
  triggerTime?: string;
}
```

**Response:**
```typescript
{
  success: true;
  data: string;              // 生成的图片URL
  pointsDeducted: number;    // 5积分（VIP享折扣）
}
```

## 页面类型设计要点

### 1. 封面页 (cover)

**设计目标**: 展示风格的整体视觉冲击力

**模拟内容**:
- 大标题：风格名称或示例主题
- 副标题：简短描述
- 背景：充分体现风格特征

**Prompt要点**:
```
生成专业PPT封面页。
要求：
- 标题突出醒目
- 背景视觉大气
- 充分体现风格特征
- 适合作为风格展示样例
```

### 2. 目录页 (directory)

**设计目标**: 展示导航结构和信息层级

**模拟内容**:
- 标题："目录"
- 3-4个章节条目
- 体现排版和列表样式

### 3. 过渡页 (transition)

**设计目标**: 展示章节切换的视觉过渡

**模拟内容**:
- 章节编号
- 章节标题
- 简短的过渡语

### 4. 内容页 (content)

**设计目标**: 展示正文排版和信息密度

**模拟内容**:
- 标题
- 3-5个要点（带项目符号）
- 一段简短说明

### 5. 结束页 (end)

**设计目标**: 展示收尾页面的简洁设计

**模拟内容**:
- "谢谢观看"
- 简短总结或号召
- 联系方式占位

## 前端集成

### 1. 风格预览组件

```typescript
// src/components/StylePreview.tsx

import { useState } from 'react';

const PAGE_TYPES = [
  { key: 'cover', label: '封面', icon: 'CoverIcon' },
  { key: 'content', label: '内容', icon: 'ContentIcon' },
  { key: 'transition', label: '过渡', icon: 'TransitionIcon' },
];

export const StylePreview: React.FC<{
  configStyle: StyleConfig;
}> = ({ configStyle }) => {
  const [activeType, setActiveType] = useState('cover');
  const [previewUrl, setPreviewUrl] = useState<string | null>(null);
  const [loading, setLoading] = useState(false);

  const generatePreview = async (pageType: string) => {
    setLoading(true);
    setActiveType(pageType);
    
    const res = await fetch('/api/ai/generate-style-reference', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        configStyle,
        pageType
      })
    });
    
    const result = await res.json();
    if (result.success) {
      setPreviewUrl(result.data);
    }
    
    setLoading(false);
  };

  return (
    <div className="style-preview">
      <div className="page-type-tabs">
        {PAGE_TYPES.map(type => (
          <button
            key={type.key}
            className={activeType === type.key ? 'active' : ''}
            onClick={() => generatePreview(type.key)}
            disabled={loading}
          >
            {type.label}
          </button>
        ))}
      </div>
      
      <div className="preview-area">
        {loading ? (
          <div className="loading">生成预览中...</div>
        ) : previewUrl ? (
          <img src={previewUrl} alt={`${activeType}预览`} />
        ) : (
          <div className="placeholder">
            点击上方标签生成预览
          </div>
        )}
      </div>
      
      <div className="hint">
        生成预览消耗5积分/张（VIP享折扣）
      </div>
    </div>
  );
};
```

async function pregeneratePreviews(configStyle: StyleConfig) {
