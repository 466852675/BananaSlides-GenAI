# 智能文本润色

## 概述

智能文本润色是 YH-AI PPT 的**AI辅助写作功能**，对用户输入的文本进行专业化、流畅化的优化处理。系统支持**三种润色模式**，并内置**多重安全防护机制**，确保生成内容的质量和安全性。

## 核心功能特性

| 功能特性 | 说明 | 适用场景 |
|---------|------|---------|
| 需求润色 | 将零散关键词扩展为流畅的需求描述 | 主题输入、需求描述 |
| 视觉指令 | 生成结构化的AI视觉设计规范 | 模板风格配置 |
| 内容润色 | 优化演示文稿正文表达 | 幻灯片内容编辑 |
| 内容审核 | 自动检测违规内容 | 全场景防护 |
| Prompt防护 | 防止注入攻击和恶意输入 | 安全防护 |
| 积分扣费 | 登录用户1积分/次 | 商业化控制 |

## 润色模式详解

### 1. requirement_polish (需求润色)

**功能**: 将用户零散的关键词或简单描述，扩展为流畅、专业的段落文本。

**输入示例**:
```
输入: "小学语文 生动 小学生 沉浸式"
```

**输出示例**:
```
该模版专为小学语文教学设计，采用生动有趣的视觉风格，以适应小学生的审美偏好，
旨在打造沉浸式的语文课堂体验，帮助学生更好地理解教学内容。
```

**Prompt构建**:
```typescript
const prompt = `
Task: Rewrite the user's input into ONE single fluent paragraph of plain text.
Input: "${cleanText}"

[STRICT RULES]
1. NO Markdown (no **, #, etc).
2. NO Bullet points or lists (*, -).
3. NO Newlines. Return exactly one line of text.
4. Keep the original intent but make it sound professional and descriptive.
5. Language: Simplified Chinese (简体中文).
6. If the input is keywords, expand them into full sentences.

Example Output:
"该模版专为小学语文教学设计，采用生动有趣的视觉风格，以适应小学生的审美偏好，
旨在打造沉浸式的语文课堂体验，帮助学生更好地理解教学内容。"
`;
```

## 安全机制

### 1. 内容审核 (Content Filter)

```typescript
// server/src/utils/content-filter.ts

export const contentFilter = {
    check(text: string): { riskLevel: 'low' | 'medium' | 'high'; reason?: string } {
        // 敏感词检测
        const sensitiveWords = [
            // 政治敏感词...
            // 色情内容...
            // 暴力内容...
        ];
        
        for (const word of sensitiveWords) {
            if (text.toLowerCase().includes(word)) {
                return {
                    riskLevel: 'high',
                    reason: `检测到敏感内容: ${word}`
                };
            }
        }
        
        return { riskLevel: 'low' };
    }
};
```

### 2. Prompt注入检测

```typescript
// server/src/utils/prompt-security.ts

export const injectionDetector = {
    // 检测注入模式
    injectionPatterns: [
        /ignore previous instructions/i,
        /disregard.*prompt/i,
        /you are now.*mode/i,
        /system.*override/i,
        /<<|>>|\{\{|\}\}/,  // 特殊字符
        /\\n\\n.*?:/  // 尝试添加新角色
    ],
    
    isInjectionAttempt(text: string): boolean {
        return this.injectionPatterns.some(pattern => pattern.test(text));
    },
    
    detectPatterns(text: string): string[] {
        return this.injectionPatterns
            .filter(pattern => pattern.test(text))
            .map(pattern => pattern.toString());
    }
};
```

### 3. Prompt清理

```typescript
export const promptSanitizer = {
    sanitize(text: string): { cleanedText: string; wasSanitized: boolean; detectedPatterns: string[] } {
        let cleaned = text;
        const detectedPatterns: string[] = [];
        
        // 移除控制字符
        cleaned = cleaned.replace(/[\x00-\x1F\x7F]/g, '');
        
        // 检测并记录可疑模式
        if (injectionDetector.isInjectionAttempt(cleaned)) {
            detectedPatterns.push(...injectionDetector.detectPatterns(cleaned));
        }
        
        // 限制长度
        if (cleaned.length > 5000) {
            cleaned = cleaned.substring(0, 5000);
            detectedPatterns.push('Length exceeded 5000 chars');
        }
        
        return {
            cleanedText: cleaned,
            wasSanitized: detectedPatterns.length > 0,
            detectedPatterns
        };
    }
};
```

## 核心算法实现

### 1. 智能润色服务

```typescript
// server/src/services/ai.service.ts

async smartRefine(
    text: string, 
    type: 'requirement' | 'content' | 'requirement_polish',
    settings?: AppSettings,
    userId?: string
): Promise<string> {
    
    // Mock模式直接返回
    if (process.env.MOCK_AI === '1') {
        return text.trim();
    }

    // 1. 内容审核
    const contentCheck = contentFilter.check(text);
    if (contentCheck.riskLevel === 'high') {
        await AuditService.log({
            type: 'CONTENT_VIOLATION',
            reason: contentCheck.reason || 'High risk content detected',
            severity: 'high',
            content: text.substring(0, 200),
            userId,
        });
        throw new Error(`内容审核失败: ${contentCheck.reason}`);
    }

    // 2. Prompt注入检测
    if (injectionDetector.isInjectionAttempt(text)) {
        const patterns = injectionDetector.detectPatterns(text);
        await AuditService.log({
            type: 'PROMPT_INJECTION',
            reason: `Detected injection patterns: ${patterns.join(', ')}`,
            severity: 'critical',
            content: text.substring(0, 200),
            userId,
        });
        throw new Error('检测到不安全的输入内容，请修改后重试');
    }

    // 3. 清理输入
    const sanitized = promptSanitizer.sanitize(text);
    if (sanitized.wasSanitized) {
        console.log('[AI] User input sanitized:', sanitized.detectedPatterns);
    }
    const cleanText = sanitized.cleanedText;

    // 4. 构建对应类型的Prompt
    const config = await resolveActiveConfig(settings, 'text');
    let prompt = '';
    
    switch (type) {
        case 'requirement_polish':
            prompt = buildRequirementPolishPrompt(cleanText);
            break;
        case 'requirement':
            prompt = buildRequirementPrompt(cleanText);
            break;
        case 'content':
            prompt = buildContentPolishPrompt(cleanText);
            break;
        default:
            prompt = buildContentPolishPrompt(cleanText);
    }

    // 5. 调用AI模型
    if (shouldUseGeminiNative(config, settings)) {
        const ai = createGoogleClient(config);
        const response = await ai.models.generateContent({
            model: config.model,
            contents: prompt,
        });
        return response.text?.trim() || text;
    } else {
        const messages = [{ role: "user", content: prompt }];
        return await callOpenAICompatible(config, messages, 0.7, false, 'text');
    }
}
```

## API 接口

### 智能润色

**Endpoint:** `POST /api/ai/smart-refine`

**Request Body:**
```typescript
{
  text: string;              // 待润色文本
  type: 'requirement_polish' | 'requirement' | 'content';
  projectId?: string;
  triggerTime?: string;
}
```

**Response:**
```typescript
{
  success: true;
  data: string;              // 润色后的文本
  pointsDeducted: number;
}
```

**错误响应**:
```typescript
// 内容审核失败
{
  success: false;
  error: {
    code: 'CONTENT_VIOLATION',
    message: '内容审核失败: 检测到敏感内容'

}

// Prompt注入检测
{
  success: false;
  error: {
    code: 'PROMPT_INJECTION',
    message: '检测到不安全的输入内容，请修改后重试'
  }
}
```

## 前端集成

### 1. 润色按钮组件

```typescript
// src/components/SmartRefineButton.tsx

import { useMutation } from '@tanstack/react-query';

interface SmartRefineButtonProps {
  text: string;
  type: 'requirement_polish' | 'requirement' | 'content';
  onRefined: (refinedText: string) => void;
}

export const SmartRefineButton: React.FC<SmartRefineButtonProps> = ({
  text,
  type,
  onRefined
}) => {
  const refine = useMutation({
    mutationFn: async () => {
      const res = await fetch('/api/ai/smart-refine', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ text, type })
      });
      
      if (!res.ok) {
        const error = await res.json();
        throw new Error(error.error?.message || '润色失败');
      }
      
      return res.json();
    },
    onSuccess: (data) => {
      onRefined(data.data);
    },
    onError: (error: Error) => {
      // 特殊错误处理
      if (error.message.includes('内容审核')) {
        toast.error('内容包含敏感信息，请修改后重试');
      } else if (error.message.includes('不安全')) {
        toast.error('检测到不安全输入，请删除特殊符号后重试');
      } else {
        toast.error(error.message);
      }
    }
  });

  return (
    <button 
      onClick={() => refine.mutate()}
      disabled={refine.isPending || !text.trim()}
    >
      {refine.isPending ? '润色中...' : 'AI润色'}
    </button>
  );
};
```
