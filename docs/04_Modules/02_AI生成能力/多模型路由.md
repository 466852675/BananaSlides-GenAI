# 多模型路由

## 概述

多模型路由架构支持灵活切换不同的 AI 服务提供商，实现成本、速度与质量的最优平衡。系统采用**动态配置解析 + 智能协议适配**架构，支持7种AI提供商的统一接入。

## 支持的模型提供商

| 提供商 | 代码 | 支持类型 | 协议类型 | 特点 |
|--------|------|----------|---------|------|
| Google Gemini | gemini | text/image/vision | Native SDK | 官方SDK，视觉分析能力强 |
| OpenAI | openai | text/image | OpenAI Compatible | 行业标准，生态完善 |
| 智谱 AI | zhipu | text/image | OpenAI Compatible | 国产大模型，CogView生图 |
| 硅基流动 | siliconflow | text/image | OpenAI Compatible | 国内API聚合平台 |
| 魔搭社区 | modelscope | text/image | Async Task API | 阿里系，异步任务模式 |
| 火山引擎 | volcengine | text/image | OpenAI Compatible | 字节系，即梦/Doubao生图 |
| 自定义组合 | customcombo | all | Mixed | 支持按任务类型配置不同模型 |

## 核心算法实现

### 1. 动态配置解析器

```typescript
// server/src/services/ai.service.ts

async function resolveActiveConfig(
    settings?: AppSettings, 
    task: 'text' | 'image' | 'vision' = 'text'
): Promise<ModelConnection> {
    const cacheKey = `active_config_${task}`;
    const cached = configCache.get(cacheKey);
    
    // 检查缓存是否有效
    if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
        return cached.config;
    }
    
    try {
        const { prisma } = await import('../db');
        const activeRule = await prisma.aiEngineRule.findFirst({
            where: { isActive: true }
        });

        if (activeRule) {
            const config = JSON.parse(activeRule.config);
            
            // 1. 检查 CustomCombo 配置
            if (activeRule.provider === 'CustomCombo' && 
                config.combo && 
                config.combo[task] && 
                config.combo[task].model) {
                const comboConfig = config.combo[task];
                const connection = {
                    apiKey: comboConfig.apiKey || config.apiKey,
                    baseUrl: comboConfig.baseUrl || config.baseUrl,
                    model: comboConfig.model
                };
                configCache.set(cacheKey, { config: connection, timestamp: Date.now() });
                return connection;
            }

            // 2. 标准模式配置
            const taskModelMap = {
                text: config.textModel || config.model,
                image: config.imageModel,
                vision: config.visionModel || 'gemini-1.5-flash'
            };

            const connection = {
                apiKey: config.apiKey,
                baseUrl: config.baseUrl || settings?.ai.baseUrl,
                model: taskModelMap[task]
            };
            
            configCache.set(cacheKey, { config: connection, timestamp: Date.now() });
            return connection;
        }
    } catch (e) {
        console.warn('[AIService] Failed to load active rule from DB', e);
    }

    // 回退到默认配置
    return getTaskConfig(settings, task);
}
```

### 2. 协议检测与适配

```typescript
function shouldUseGeminiNative(
    config: ModelConnection, 
    settings?: AppSettings
): boolean {
    const url = config.baseUrl?.toLowerCase().trim() || '';
    const model = config.model?.toLowerCase() || '';

    // 优先级1: Google官方API使用Gemini Native
    if (url.includes('googleapis.com') || url.includes('generativelanguage')) {
        return true;
    }

    // 优先级2: OpenAI兼容模式 (v1/v3/Volcengine)
    if (url.includes('/v1') || url.includes('/v3') || url.includes('volces.com')) {
        return false;
    }

    // 优先级3: 自定义URL(非Google) → 假设为OpenAI兼容
    if (url.length > 5 && !url.includes('google')) {
        return false;
    }

    // 优先级4: 根据模型名判断
    if (model.includes('gemini') || model.includes('googlegemini')) {
        return true;
    }

    // 优先级5: 全局配置
    if (settings?.ai.provider === 'Gemini') {
        return true;
    }

    return false;
}
```

```typescript
// Gemini Native SDK 调用
async function callGeminiNative(config: ModelConnection, prompt: string): Promise<string> {
    const ai = new GoogleGenAI({ apiKey: config.apiKey });
    const response = await ai.models.generateContent({
        model: config.model,
        contents: prompt
    });
    return response.text?.trim() || "";
}

// OpenAI Compatible API 调用
async function callOpenAICompatible(
    config: ModelConnection,
    messages: any[],
    temperature: number = 0.7,
    jsonMode: boolean = false,
    taskType: 'text' | 'image' | 'vision' = 'text'
): Promise<string> {
    const headers = {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${config.apiKey}`
    };

    const body = {
        model: config.model,
        messages: messages,
        temperature: temperature,
        max_tokens: 4096
    };
    
    if (jsonMode) body.response_format = { type: "json_object" };

    const url = config.baseUrl.endsWith('/chat/completions') 
        ? config.baseUrl 
        : `${config.baseUrl}/chat/completions`;

    // 根据任务类型设置超时
    const timeout = AI_TIMEOUTS[taskType] || AI_TIMEOUTS.text;
    
    let retries = 5;
    while (retries > 0) {
        try {
            const response = await axios.post(url, body, { headers, timeout });
            return response.data.choices[0]?.message?.content || "";
        } catch (error: any) {
            const statusCode = error.response?.status;
            const isQuotaExceeded = error.message?.toLowerCase().includes('quota');
            
            // 可重试错误: 429/500/502/503/504
            const shouldRetry = !statusCode || 
                ([429, 500, 502, 503, 504].includes(statusCode) && !isQuotaExceeded);
            
            if (shouldRetry && retries > 1) {
                retries--;
                const delay = statusCode === 429 ? 3000 : 1000;
                await sleep(delay * (5 - retries) + Math.random() * 3000);
                continue;
            }
            
            throw error;
        }
    }
}
```

## 图片生成特殊处理

### 1. 分辨率计算

```typescript
function calculateFinalResolution(
    qualitySetting: string | undefined, 
    aspectRatio: string, 
    isZhipu: boolean = false
): string {
    // 智谱AI特殊分辨率
    const zhipuMap: Record<string, string> = {
        '16:9': '1728x960',
        '4:3': '1344x1024',
        '1:1': '1280x1280',
        '3:4': '1024x1344',
        '9:16': '960x1728'
    };

    if (isZhipu) {
        return zhipuMap[aspectRatio] || '1280x1280';
    }

    // 标准分辨率映射 (1K/2K/4K)
    const map: Record<string, Record<string, string>> = {
        '1K': {
            '16:9': '1280x736',
            '4:3': '1024x768',
            '1:1': '1024x1024',
            '3:4': '768x1024',
            '9:16': '736x1280'
        },
        '2K': {
            '16:9': '1920x1088',
            '4:3': '2048x1536',
            '1:1': '2048x2048',
            '3:4': '1536x2048',
            '9:16': '1088x1920'
        },
        '4K': {
            '16:9': '3840x2176',
            '4:3': '4096x3072',
            '1:1': '2176x2176',
            '3:4': '3072x4096',
            '9:16': '2176x3840'
        }
    };

    let tier = '4K';
    if (qualitySetting?.includes('1024') || qualitySetting?.includes('1280')) tier = '1K';
    else if (qualitySetting?.includes('2048') || qualitySetting?.includes('1920')) tier = '2K';

    return map[tier][aspectRatio] || map['2K']['16:9'];
}
```

```typescript
// ModelScope 需要异步轮询
if (isModelScope && response.data?.task_id) {
    const taskId = response.data.task_id;
    
    // 轮询任务状态
    let polls = 0;

        const taskResp = await axios.get(pollUrl, {
            headers: {
                'Authorization': headers['Authorization'],
                'X-ModelScope-Task-Type': 'image_generation'
            }
        });
        
        const taskData = taskResp.data.output || taskResp.data;
        const taskStatus = taskData.task_status;
        
        if (taskStatus === 'SUCCEEDED' || taskStatus === 'SUCCEED') {
            // 提取图片URL并下载
            const imageUrl = taskData.results?.[0]?.url || 
                           taskData.output_images?.[0];
            if (imageUrl) {
                const imageResponse = await axios.get(imageUrl, { 
                    responseType: 'arraybuffer' 
                });
                return saveImage(imageResponse.data);
            }
        } else if (taskStatus === 'FAILED') {
            throw new Error(`ModelScope Task Failed`);
        }
    }
```

## 错误处理与重试

### 1. 错误分类

| 错误类型 | HTTP状态码 | 处理策略 |
|---------|-----------|---------|
| 配额超限 | 429 | 提示切换模型或等待 |
| 服务不可用 | 502/503/504 | 自动重试，指数退避 |
| 认证失败 | 401 | 检查API Key配置 |
| 请求超时 | - | 根据任务类型设置不同超时 |

### 2. 重试策略

```typescript
const AI_TIMEOUTS = {
    text: 30000,    // 文本生成 30秒
    image: 180000,  // 图片生成 3分钟
    vision: 90000   // 视觉分析 1.5分钟
};

// 指数退避重试
let retries = 5;
while (retries > 0) {
    try {
        return await apiCall();
    } catch (error) {
        retries--;
        const delay = (1000 * Math.pow(2, 5 - retries)) + Math.random() * 3000;
        await sleep(delay);
    }
}
```
