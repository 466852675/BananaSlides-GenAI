# 用户管理前端文档

## 概述

用户管理是 YH-AI PPT 管理后台的**核心治理模块**，负责平台用户的全生命周期管理，包括增删改查、角色权限分配、账户状态管理、积分操作等。前端采用**表格+弹窗**的交互模式，支持批量操作和高级筛选。

## 核心功能特性

| 功能特性 | 说明 | 技术实现 |
|---------|------|---------|
| 用户列表 | 分页展示所有用户 | TanStack Table + 虚拟滚动 |
| 高级搜索 | 多字段组合筛选 | 条件构建器 |
| 批量操作 | 批量启用/禁用/删除 | 行选择器 |
| 角色分配 | RBAC权限角色管理 | 下拉选择器 |
| 积分管理 | 查看和调整用户积分 | 数字输入框 |
| VIP管理 | 查看和调整VIP等级 | 日期选择器 |
| 用户详情 | 展示完整用户信息 | Drawer组件 |

### 2. 核心组件代码

#### 2.1 用户表格组件

```typescript
// src/components/admin/UserManagement.tsx

import { useState } from 'react';
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import {
  useReactTable,
  getCoreRowModel,
  getPaginationRowModel,
  getFilteredRowModel,
  flexRender,
} from '@tanstack/react-table';

interface User {
  id: string;
  email: string;
  nickname?: string;
  role: string;
  status: 'ACTIVE' | 'DISABLED' | 'PENDING';
  points: number;
  vipLevel: number;
  vipExpiresAt?: string;
  createdAt: string;
  lastLoginAt?: string;
}

export const UserManagement: React.FC = () => {
  const [page, setPage] = useState(1);
  const [pageSize, setPageSize] = useState(10);
  const [filters, setFilters] = useState({
    search: '',
    role: '',
    status: '',
    startDate: '',
    endDate: ''
  });
  const [selectedRows, setSelectedRows] = useState<string[]>([]);
  
  const queryClient = useQueryClient();
  
  // 获取用户列表
  const { data, isLoading } = useQuery({
    queryKey: ['admin', 'users', page, pageSize, filters],
    queryFn: async () => {
      const params = new URLSearchParams({
        page: String(page),
        limit: String(pageSize),
        ...filters
      });
      const res = await fetch(`/api/admin/users?${params}`);
      return res.json();
    }
  });
  
  // 定义表格列
  const columns = [
    {
      id: 'select',
      header: ({ table }: any) => (
        <input
          type="checkbox"
          checked={table.getIsAllRowsSelected()}
          onChange={table.getToggleAllRowsSelectedHandler()}
        />
      ),
      cell: ({ row }: any) => (
        <input
          type="checkbox"
          checked={row.getIsSelected()}
          onChange={row.getToggleSelectedHandler()}
        />
      ),
    },
    {
      accessorKey: 'userInfo',
      header: '用户信息',
      cell: ({ row }: any) => {
        const user = row.original;
        return (
          <div className="user-info-cell">
            <div className="nickname">{user.nickname || user.email}</div>
            <div className="email">{user.email}</div>
            {user.vipLevel > 0 && (
              <span className="vip-badge">VIP{user.vipLevel}</span>
            )}
          </div>
        );
      },
    },
    {
      accessorKey: 'role',
      header: '角色',
      cell: ({ row }: any) => {
        const roleMap: Record<string, { label: string; color: string }> = {
          'USER': { label: '普通用户', color: 'gray' },
          'BASIC': { label: '基础', color: 'blue' },
          'PROFESSIONAL': { label: '专业', color: 'purple' },
          'PREMIUM': { label: '高级', color: 'orange' },
          'ENTERPRISE': { label: '企业', color: 'gold' },
          'ADMIN': { label: '管理员', color: 'red' },
          'SUPER_ADMIN': { label: '超级管理员', color: 'red' },
        };
        
        const role = roleMap[row.original.role] || roleMap['USER'];
        
        return (
          <Tag color={role.color}>{role.label}</Tag>
        );
      },
    },
    {
      accessorKey: 'points',
      header: '积分',
      cell: ({ row }: any) => (
        <div className="points-cell">
          <span>{row.original.points}</span>
          <Button 
            size="small" 
            onClick={() => openPointsModal(row.original)}
          >
            调整
          </Button>
        </div>
      ),
    },
    {
      accessorKey: 'status',
      header: '状态',
      cell: ({ row }: any) => {
        const statusMap = {
          'ACTIVE': { label: '正常', color: 'green' },
          'DISABLED': { label: '禁用', color: 'red' },
          'PENDING': { label: '待验证', color: 'orange' },
        };
        
        const status = statusMap[row.original.status];
        
        return (
          <Badge 
            status={row.original.status === 'ACTIVE' ? 'success' : 'error'}
            text={status.label}
          />
        );
      },
    },
    {
      accessorKey: 'createdAt',
      header: '注册时间',
      cell: ({ row }: any) => formatDate(row.original.createdAt),
    },
    {
      id: 'actions',
      header: '操作',
      cell: ({ row }: any) => (
        <div className="action-buttons">
          <Button size="small" onClick={() => viewDetail(row.original)}>
            详情
          </Button>
          <Button size="small" onClick={() => openEditModal(row.original)}>
            编辑
          </Button>
          <Button 
            size="small" 
            danger
            onClick={() => confirmDisable(row.original)}
          >
            {row.original.status === 'DISABLED' ? '启用' : '禁用'}
          </Button>
        </div>
      ),
    },
  ];
  
  const table = useReactTable({
    data: data?.data?.items || [],
    columns,
    getCoreRowModel: getCoreRowModel(),
    getPaginationRowModel: getPaginationRowModel(),
    onRowSelectionChange: setSelectedRows,
    state: {
      rowSelection: selectedRows,
    },
  });
  
  return (
    <div className="user-management">
      <FilterBar filters={filters} onChange={setFilters} />
      
      <ActionBar 
        selectedCount={selectedRows.length}
        onBatchDisable={() => batchDisable(selectedRows)}
        onBatchDelete={() => confirmBatchDelete(selectedRows)}
      />
      
      <Table
        loading={isLoading}
        columns={columns}
        dataSource={data?.data?.items}
        pagination={{
          current: page,
          pageSize,
          total: data?.data?.pagination?.total,
          onChange: (p, ps) => {
            setPage(p);
            setPageSize(ps || 10);
          },
        }}
      />
    </div>
  );
};
```

#### 2.2 创建用户弹窗

```typescript
// src/components/admin/UserCreateModal.tsx

import { Modal, Form, Input, Select, message } from 'antd';
import { useMutation, useQueryClient } from '@tanstack/react-query';

interface UserCreateModalProps {
  visible: boolean;
  onClose: () => void;
}

export const UserCreateModal: React.FC<UserCreateModalProps> = ({
  visible,
  onClose,
}) => {
  const [form] = Form.useForm();
  const queryClient = useQueryClient();
  
  const createUser = useMutation({
    mutationFn: async (values: any) => {
      const res = await fetch('/api/admin/users', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(values)
      });
      return res.json();
    },
    onSuccess: (data) => {
      if (data.success) {
        message.success('用户创建成功');
        queryClient.invalidateQueries({ queryKey: ['admin', 'users'] });
        form.resetFields();
        onClose();
      } else {
        message.error(data.error?.message || '创建失败');
      }
    }
  });
  
  const handleSubmit = () => {
    form.validateFields().then(values => {
      createUser.mutate(values);
    });
  };
  
  return (
    <Modal
      title="创建用户"
      open={visible}
      onOk={handleSubmit}
      onCancel={onClose}
      confirmLoading={createUser.isPending}
    >
      <Form form={form} layout="vertical">
        <Form.Item
          name="email"
          label="邮箱"
          rules={[
            { required: true, message: '请输入邮箱' },
            { type: 'email', message: '邮箱格式不正确' }
          ]}
        >
          <Input placeholder="user@example.com" />
        </Form.Item>
        
        <Form.Item
          name="password"
          label="密码"
          rules={[
            { required: true, message: '请输入密码' },
            { min: 8, message: '密码至少8位' }
          ]}
        >
          <Input.Password placeholder="设置登录密码" />
        </Form.Item>
        
        <Form.Item
          name="nickname"
          label="昵称"
        >
          <Input placeholder="用户昵称（选填）" />
        </Form.Item>
        
        <Form.Item
          name="role"
          label="角色"
          initialValue="USER"
        >
          <Select>
            <Select.Option value="USER">普通用户</Select.Option>
            <Select.Option value="BASIC">基础</Select.Option>
            <Select.Option value="PROFESSIONAL">专业</Select.Option>
            <Select.Option value="PREMIUM">高级</Select.Option>
            <Select.Option value="ADMIN">管理员</Select.Option>
          </Select>
        </Form.Item>
        
        <Form.Item
          name="initialPoints"
          label="初始积分"
          initialValue={30}
        >
          <Input type="number" min={0} />
        </Form.Item>
      </Form>
    </Modal>
  );
};
```

#### 2.3 积分调整弹窗

```typescript
// src/components/admin/PointsEditModal.tsx

import { Modal, Form, InputNumber, Select, message } from 'antd';
import { useMutation, useQueryClient } from '@tanstack/react-query';

interface PointsEditModalProps {
  user: User | null;
  visible: boolean;
  onClose: () => void;
}

export const PointsEditModal: React.FC<PointsEditModalProps> = ({
  user,
  visible,
  onClose,
}) => {
  const [form] = Form.useForm();
  const queryClient = useQueryClient();
  
  const adjustPoints = useMutation({
    mutationFn: async (values: any) => {
      const res = await fetch(`/api/admin/users/${user?.id}/points`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(values)
      });
      return res.json();
    },
    onSuccess: (data) => {
      if (data.success) {
        message.success('积分调整成功');
        queryClient.invalidateQueries({ queryKey: ['admin', 'users'] });
        onClose();
      } else {
        message.error(data.error?.message || '调整失败');
      }
    }
  });
  
  return (
    <Modal
      title={`调整积分 - ${user?.nickname || user?.email}`}
      open={visible}
      onOk={() => form.submit()}
      onCancel={onClose}
    >
      <div className="current-points">
        当前积分: <strong>{user?.points}</strong>
      </div>
      
      <Form 
        form={form} 
        layout="vertical"
        onFinish={adjustPoints.mutate}
      >
        <Form.Item
          name="type"
          label="操作类型"
          rules={[{ required: true }]}
          initialValue="add"
        >
          <Select>
            <Select.Option value="add">增加积分</Select.Option>
            <Select.Option value="subtract">扣除积分</Select.Option>
            <Select.Option value="set">设置为</Select.Option>
          </Select>
        </Form.Item>
        
        <Form.Item
          name="amount"
          label="积分数额"
          rules={[
            { required: true, message: '请输入积分数额' },
            { type: 'number', min: 1, message: '数额必须大于0' }
          ]}
        >
          <InputNumber style={{ width: '100%' }} placeholder="输入积分数额" />
        </Form.Item>
        
        <Form.Item
          name="reason"
          label="调整原因"
          rules={[{ required: true, message: '请输入调整原因' }]}
        >
          <Input.TextArea rows={3} placeholder="例如：活动奖励、补偿、违规扣除等" />
        </Form.Item>
      </Form>
    </Modal>
  );
};
```

## API 接口

### 获取用户列表

**Endpoint:** `GET /api/admin/users?page=1&limit=10&search=&role=&status=`

**Response:**
```typescript
{
  success: true;
  data: {
    items: User[];
    pagination: {
      page: number;
      limit: number;
      total: number;
      totalPages: number;
    }
  }
}
```

### 创建用户

**Endpoint:** `POST /api/admin/users`

**Request Body:**
```typescript
{
  email: string;
  password: string;
  nickname?: string;
  role: string;
  initialPoints?: number;
}
```

### 更新用户信息

**Endpoint:** `PATCH /api/admin/users/:id`

**Request Body:**
```typescript
{
  nickname?: string;
  role?: string;
  status?: 'ACTIVE' | 'DISABLED';
  vipLevel?: number;
  vipExpiresAt?: string;
}
```

### 调整积分

**Endpoint:** `POST /api/admin/users/:id/points`

**Request Body:**
```typescript
{
  type: 'add' | 'subtract' | 'set';
  amount: number;
  reason: string;
}
```

### 批量禁用/启用

**Endpoint:** `POST /api/admin/users/batch-status`

**Request Body:**
```typescript
{
  userIds: string[];
  status: 'ACTIVE' | 'DISABLED';
  reason?: string;
}
```
